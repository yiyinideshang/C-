# 一、树的基本概念与术语
- **节点**：数据单元，包含值、子节点指针（有时含父指针）。
- **边**：连接父子节点。
- **根节点**：无父节点的节点。
- **叶子节点**：无子节点的节点。
- **高度**：从节点到最远叶子经过的边数；树的高度 = 根节点高度。
- **深度**：从根到节点的边数。
- **度**：节点的子树个数；树的度 = max(所有节点度)。
- **二叉树**：每个节点最多两个子节点（左、右）。
- **满二叉树**：所有层节点数均最大，且叶子都在同一层。
- **完全二叉树**：除最后一层外全满，最后一层节点向左对齐。
- **平衡二叉树**：任一节点左右子树高度差 ≤ 1（AVL）或满足其他平衡条件。

> **C++ 表示法（二叉树为例）**  
> 常用结构体 + 指针或数组（用于完全二叉树的堆）。
>
> ```cpp
> struct TreeNode {
>  int val;
>  TreeNode *left;
>  TreeNode *right;
>  TreeNode() : val(0), left(nullptr), right(nullptr) {}
>  TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
>  TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
> };
> ```

## 二叉树的基本性质

- 设完全二叉树节点数为 **n**，深度/高度为：  
  - **h/k=⌊log~2~n⌋+1**

- **第 i 层最多节点数**：
  - **2^i-1^（i>=1**，即根节点为第1层）个节点数

- **深度为 h 的二叉树总节点数最多有**：
  - **2^h^-1（h>=1）**个节点数
  - 当正好等于时，说明是一个 **满二叉树**；如当深度为4的满二叉树的节点数之和为：2^0^+2^1^+2^2^+2^3^=2^4^-1=15个节点
- **任意二叉树**，n0、n1、n2分别代表节点的度数为0、1、2。n为总结点数：
  - **n~0~=n~2~+1**（度为0的叶子节点数 n~0~ = 度为2的节点数 n~2~ + 1）
  - **n = n~0~ + n~1~ + n~2~**

# 二、二叉树的遍历 (重点)
## 1. 深度优先遍历 (DFS)
- **前序**（根左右）：递归/栈模拟 
  应用：序列化，复制树。
  
  ```cpp
  void preorder(TreeNode* root) {
      if (!root) return;
      // visit(root)
      preorder(root->left);
      preorder(root->right);
  }
  ```
- **中序**（左根右）：二叉搜索树可得到有序序列。
- **后序**（左右根）：计算子树高度、删除树（先删子节点再删根）。

**迭代版统一模板**（栈 + nullptr 标记）：
```cpp
vector<int> inorderTraversal(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    if (root) st.push(root);
    while (!st.empty()) {
        TreeNode* node = st.top(); st.pop();
        if (node) {
            // 中序：右、根（加标记）、左  入栈顺序与遍历相反
            if (node->right) st.push(node->right);
            st.push(node);
            st.push(nullptr);  // 标记位
            if (node->left) st.push(node->left);
        } else {
            node = st.top(); st.pop();
            res.push_back(node->val);
        }
    }
    return res;
}
```
- **Morris遍历**：O(1) 空间复杂度，利用空闲指针，面试亮点。

## 2. 广度优先遍历 (BFS)
- **层序遍历**：队列实现，可分层输出。
  ```cpp
  vector<vector<int>> levelOrder(TreeNode* root) {
      vector<vector<int>> ans;
      if (!root) return ans;
      queue<TreeNode*> q;
      q.push(root);
      while (!q.empty()) {
          int sz = q.size();
          vector<int> level;
          for (int i = 0; i < sz; ++i) {
              TreeNode* t = q.front(); q.pop();
              level.push_back(t->val);
              if (t->left) q.push(t->left);
              if (t->right) q.push(t->right);
          }
          ans.push_back(level);
      }
      return ans;
  }
  ```

# 三、二叉搜索树 (BST)
**性质**：左子树所有节点值 < 根节点值 < 右子树所有节点值（一般无重复）。
**操作及复杂度**：平均 O(log n)，最坏 O(n)（退化成链）。

## 1. 查找/插入
```cpp
TreeNode* searchBST(TreeNode* root, int val) {
    while (root) {
        if (root->val == val) return root;
        root = val < root->val ? root->left : root->right;
    }
    return nullptr;
}

TreeNode* insertIntoBST(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    TreeNode* cur = root;
    while (true) {
        if (val < cur->val) {
            if (!cur->left) { cur->left = new TreeNode(val); break; }
            cur = cur->left;
        } else {
            if (!cur->right) { cur->right = new TreeNode(val); break; }
            cur = cur->right;
        }
    }
    return root;
}
```

## 2. 删除（难点）
三种情况：
- 叶子：直接删。
- 仅单子节点：用子节点替代。
- 有双子节点：用**后继**（右子树最小节点）或前驱替换值，再删除后继节点。
```cpp
TreeNode* deleteNode(TreeNode* root, int key) {
    if (!root) return root;
    if (key < root->val) root->left = deleteNode(root->left, key);
    else if (key > root->val) root->right = deleteNode(root->right, key);
    else {
        if (!root->left) return root->right;
        if (!root->right) return root->left;
        TreeNode* succ = root->right;
        while (succ->left) succ = succ->left;
        root->val = succ->val;
        root->right = deleteNode(root->right, succ->val);
    }
    return root;
}
```
**验证BST**：中序遍历是否递增，或用递归区间 (min, max)。

# 四、平衡二叉树
## 1. AVL 树
**平衡因子** = 左子树高 - 右子树高，绝对值 ≤ 1。
**旋转**：
- LL (右旋)、RR (左旋)、LR (左旋左子树再右旋)、RL (右旋右子树再左旋)
- 插入/删除后从修改点向上更新高度并检查平衡，进行相应旋转。复杂度 O(log n)。

面试手写 AVL 插入较多，重点在四种旋转和高度维护。

## 2. 红黑树 (Red-Black Tree)
C++ STL 中 `std::map`、`std::set` 底层即为红黑树（有序、O(log n) 增删查）。
**五条性质**：根黑、叶黑、红不连续、任意路径黑高相等、节点非红即黑。
**优势**：旋转次数比 AVL 少，插入删除综合性能更优。
**面试要求**：理解性质、与 AVL 对比、知道 STL 容器原理即可，很少要求手写红黑树。

# 五、堆 (Heap) 与优先队列

**结构**：完全二叉树实现，常用数组存储（索引 0 或 1 开始）。
- **最大堆**：父节点 ≥ 子节点，根最大。
- **最小堆**：父节点 ≤ 子节点，根最小。

## 1. 操作与建堆

- `push`：插到最后，向上渗透（上浮） O(log n)
- `pop`：堆顶与末尾交换，删末尾，从顶向下渗透（下沉） O(log n)
- 建堆：从最后一个非叶节点开始向前 `heapify`，O(n)

## 2. C++ STL

`std::priority_queue<T>` 默认最大堆。
```cpp
priority_queue<int> maxHeap;                         // 大顶堆
priority_queue<int, vector<int>, greater<int>> minHeap; // 小顶堆
```
自定义比较：
```cpp
struct Node { int x, y; };
auto cmp = [](Node a, Node b) { return a.x > b.x; }; // 小顶堆，注意符号
priority_queue<Node, vector<Node>, decltype(cmp)> pq(cmp);
```
**堆排序**：将所有元素插入堆，依次弹出，时间复杂度 O(n log n)，不稳定。

# 六、Trie（前缀树 / 字典树）
用于字符串存储、前缀匹配。多叉树，节点含 `bool isEnd` 和指向子节点的数组/哈希表。
```cpp
class Trie {
    struct Node {
        bool isEnd;
        Node* next[26]{};
        Node() : isEnd(false) {}
    };
    Node* root;
public:
    Trie() { root = new Node(); }
    void insert(string word) {
        Node* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->next[idx]) cur->next[idx] = new Node();
            cur = cur->next[idx];
        }
        cur->isEnd = true;
    }
    bool search(string word) {
        Node* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->next[idx]) return false;
            cur = cur->next[idx];
        }
        return cur->isEnd;
    }
    bool startsWith(string prefix) {
        Node* cur = root;
        for (char c : prefix) {
            int idx = c - 'a';
            if (!cur->next[idx]) return false;
            cur = cur->next[idx];
        }
        return true;
    }
};
```
时间复杂度：每次操作 O(L)，L 为字符串长度。

# 七、哈夫曼树（Huffman Tree）
**应用**：数据压缩，最优前缀编码。
**构建**：贪心算法 + 最小堆

1. 统计字符频率，为每个字符建叶子节点加入最小堆（权值=频率）。
2. 每次取出最小的两个节点，合并成新节点（左、右孩子，权=和），放回堆。
3. 直到堆大小=1，即为根。

C++ 可用 `priority_queue` 实现。

# 八、B 树 / B+ 树（简述）
**用途**：数据库索引、文件系统。
**B 树**：m 阶 B 树每个节点有 ⌈m/2⌉-1 ～ m-1 个关键字；所有叶子同一深度。插入满则分裂，删除欠则合并/借用。一次磁盘 IO 读一个节点，高度很小。
**B+ 树**：所有数据存在叶子，叶节点通过链表相连，非叶节点只存索引，范围查询高效。
**面试常见**：B 树与二叉平衡树的区别、B+ 树优势、为什么数据库用 B+ 树。

# 九、并查集 (Disjoint Set Union / Union-Find)
虽然叫 “集”，本质是多棵树的森林，实现动态连通性问题。
```cpp
class UnionFind {
    vector<int> parent, rank;
public:
    UnionFind(int n) : parent(n), rank(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]); // 路径压缩
    }
    void unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        if (rank[rx] < rank[ry]) parent[rx] = ry;
        else if (rank[rx] > rank[ry]) parent[ry] = rx;
        else { parent[ry] = rx; rank[rx]++; }
    }
    bool same(int x, int y) { return find(x) == find(y); }
};
```
均摊近似 O(α(n))，近似常数。

# 十、C++ STL 树相关容器总结
| 容器                     | 底层结构         | 有序性   | 操作复杂度 | 说明               |
| ------------------------ | ---------------- | -------- | ---------- | ------------------ |
| `std::set`               | 红黑树           | 有序     | O(log n)   | 唯一键，自动排序   |
| `std::map`               | 红黑树           | 有序     | O(log n)   | 键值对，按键排序   |
| `std::multiset/map`      | 红黑树           | 有序     | O(log n)   | 允许重复键         |
| `std::unordered_set/map` | 哈希表           | 无序     | O(1) 平均  | 无序，不能按序遍历 |
| `std::priority_queue`    | 堆（vector实现） | 部分有序 | O(log n)   | 获取最大/最小元素  |

# 十一、高频面试题类型
1. **遍历问题**：非递归前中后序、Morris 遍历、层序遍历变种（锯齿形、从底向上）。
2. **二叉树属性**：最大深度、最小深度、对称性、直径、平衡性判断、最近公共祖先（LCA）。
3. **构造与转换**：前/中序、中/后序重建二叉树；有序链表/数组转平衡 BST；二叉树展开为链表。
4. **路径和问题**：根到叶子总和、任意节点最大路径和（后续遍历同时维护全局变量）。
5. **二叉搜索树**：第 K 小/大元素、验证 BST、BST 的插入/删除、修剪区间。
6. **堆/优先队列**：Top K 问题、合并 K 个有序链表/数组、数据流中位数（大小堆配合）。
7. **Trie**：实现自动补全、前缀搜索、最大异或值。
8. **并查集**：连通分量计数、冗余连接、朋友圈、网格岛屿数量（可转并查集）。

>
> 1. 代码构造的二叉树结构为：
>    \- 根节点值为1
>    \- 根节点的右子节点值为2
>    \- 值为2的节点的左子节点值为3

>    在这个例子中遍历过程：
>    \- 从根节点1开始，1没有左子节点，直接输出1
>    \- 访问右子节点2，2有左子节点3
>    \- 先访问2的左子节点3，输出3
>    \- 最后访问节点2，输出2
>    因此输出顺序是：**`1 3 2`**
>
> 代码中使用栈实现非递归的中序遍历，通过while循环不断将左子节点入栈，当左子树遍历完成后，依次弹出栈顶元素并访问其右子树，这样保证了中序遍历的正确顺序。
