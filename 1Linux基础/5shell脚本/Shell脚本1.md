# Shell脚本

编程语言：编译型语言和解释性语言

# 编译型语言

需要把源代码通过编译生成可以执行的文件，才能执行。

常见的编译型语言有：

- `c`、`c++`、`c#`、`java`

# 解释型语言

不需要把代码进行编译生成可执行文件，就可以直接运行的。

常见的解释性语言有：

- `JavaScript(Js)` 、`TypeScirpt(Ts)`、`Python`、`Shell`

# 解释型语言和编译型语言的区别：

- 如果有十行代码
  - **编译型语言**：只有当10行代码都没有语法错误时，才能进行编译和运行。
  - **解释型语言**：哪怕后面九条语句都是错误的，只要第一条没错，它就能运行第一条代码，因为它是逐条解析的。
- **编译型语言：**：谁来进行编译？ -——>编译器(c++语言：g++)
- **解释型语言**：谁来进行解析？  ------->解释器

不管是**解析器**还**是编译器**本质都是一个软件(程序)

# Shell的解析器/解析程序

- `/bin/bash`
- `/bin/dash`
- `/bin/sh`

可以在编写`shell`脚本的时候去指定解析器去解析脚本。

# Shell脚本文件

以扩展名为`.sh`结尾的文件

一个非常简单的 `shell `脚本程序

````bash
#!/bin/bash
#指定这shell脚本使用 /bin/bash 这个解析器进行解析
# 一般是注释
echo "Hello Shell" # 通过echo这条指令来在终端上面打印一句话
````

- \#!/bin/bash 表示指定 /bin/bash 路径下的解析器来解析本脚本文件。
- \# #开头的是注释 注释，不参与运行
-  #! 表示指定解析器作用，不是注释的意思 
- `echo "hello shell"` 表示**在终端输出一段文字** `hello shell`

# Shell自己的内容

## Shell的变量

`Shell` 的变量没有类型的概念的。

` Shell `的变量不需要进行提前定义的，直接用。

### **定义/创建变量** 

- 变量名=值

- 示例： `NUM=123 `创建/定义了一个变量 `NUM` 并赋值为 123

==注意：**等号的两边不能存在空格**，必须要贴贴（贴着等号）==

### **使用 Shell 变量** 

- `$变量名`
  - 示例：` $NUM `	 表示引用变量` NUM` 的值 

- `${变量名}`
  - 示例： `${NUM}` 表示引用变量 `NUM`	 的值

### 示例

```bash
NUM=123
echo $NUM
echo ${NUM}
```

## Shell变量分为以下几种

### 自定义变量

- 由程序员自己创建的变量

  - ```bash
    LS=`ls` # 创建LS变量并且将ls指令执行的输出结果保存的LS里面，LS就是自定义变量
    echo $Ls
    ```

  - `反撇号(``) `： 里面可以写任何终端可执行的命令

### 	位置变量

- 指传递 Shell 脚本的参数或者是传递给函数的参数
- 示例：` ./demo.sh 123 abc`
  - 示例脚本里面 
  - `123 `和` abc `是脚本程序的位置参数
  -  位置参数的表示： 
    - `$0` ：表示参数里面的第零位参数：` ./demo.sh `(相当于 `main` 的 `agrv[0]` ) 
    - `$1` ：表示参数里面的第一位参数： `123 `
    - `$2` ：表示参数里面的第二位参数： `abc`
    -  ... 
    - $9 ： Shell 脚本的位置参数最多只能有9个参数。
    -  上述的参数和` main `函数的参数类似
    - `$#` ：表示的是参数的个数（不包含` $0` ）（相当于 `main `的` agrc-1` )(相当于是实际参数的个数)
  - `$@` ：表示的包含所有命令行的参数` $@ `等价于 "`$1`" "`$2`" "`$3`" "`$4`" "`$5`" "`$6`" "`$7`" "`$8`" "`$9`"
  - ` $*` ：表示的包含所有的命令行参数 `$*` 等价于  "`$1`" "`$2`" "`$3`" "`$4`" "`$5`" "`$6`" "`$7`" "`$8`" "`$9`"
  - `$? `：表示前面(最近)一个命令的退出码（进程退出码，就是` main` 函数的返回值、exit(值)） 
    - `$? `：一个字节，数据保存范围(0~255)

```bash
#!/bin/bash
NUM1=$1
NUM2=$2


echo $#
echo $NUM1 $NUM2
echo $@
echo $?

yishang@yishang-virtual-machine:~/文档/shell脚本$ ./shell位置参数.sh 1 2
2#参数的个数
1 2#第一个参数 和 第二个参数
1 2#全部参数
0#命令正常返回0，错误返回-1
```

# Shell的数组

- 数组的创建格式： 数组名=(值1 值2 值3 ... 值n) 
  - 示例： `Array=(1 2 3 4 5 6 7) `创建一个数组并进行赋值

-  数组的引用格式： 
  - 读数据：` ${数组名[下标]} `引用元素值 
    - 示例：` ${Array[0]}` 引用数组` Array `下标为`0`的元素
  - 写数据： `数组名[下标]=值 `修改元素的值 
    - 示例：` Array[1]=1` 修改下标为`1`的元素的值为`1 `
  - 引用整个数组： `${数组名[*]}` 或者` ${数组名[@]} `
    - 示例：`${Array[*]} `引用数组所有元素 
    - 示例：` ${Array[@]}` 引用数组所有元素

 ==注意：shell的数组创建并不是用花括号{}括起来的。而是用圆括号(),并且里面是用空格分割元素，不是逗号。==

==注意：shell的数组当你操作的下标复制不连续的时候，中间空出来的位置全部是空，什么东西都没有==

```bash
#!/bin/bash

#创建数组并赋值
Array=(abc 1 2 3 4 5 6)
echo ${Array[0]}
echo ${Array[*]}

Array[100]=100
echo ${Array[*]}
echo ${Array[7]}
echo ${Array[100]}

yishang@yishang-virtual-machine:~/文档/shell脚本$ chmod +x shell数组.sh
yishang@yishang-virtual-machine:~/文档/shell脚本$ ./shell数组.sh
abc#${Array[0]}
abc 1 2 3 4 5 6#${Array[*]}
abc 1 2 3 4 5 6 100#${Array[*]}
 #${Array[7]}
100#${Array[100]}
```

shell文件中的语句可以是

## 输入语句read

`read` ：表示从终端输入、接收数据

-  `read 变量名1 变量名2 ... `
  - 示例： `read NUM1 NUM2` 表示从终端接收两个数据，并存储到 `NUM1`和`NUM2` 中

```bash
#!/bin/bash

read -a NUM1
echo ${NUM1[*]}

yishang@yishang-virtual-machine:~/文档/shell脚本$ ./shell语句.sh 
1 2 3 4
1 2 3 4
```

## 输入重定向语句<

**重定向**：重新定向**输入/输出**的**来源/目标**

输入重定向：`<`

- 命令行的输入请求是通过我们的标准输入设备：` 键盘... `提交申请 
- 通过输入重定向的话，可以**不从键盘获取数据，从而将个输入请求重定向到一个文件**。这种情况就 叫做：**输入重定向** 
- 示例：

```bash
#!/bin/bash

#重定向语句
read student < 1.txt
echo $student

#1.txt中有以下数据
#zhangsan 18 2005
#list 12 abc

yishang@yishang-virtual-machine:~/文档/shell脚本$ ./shell语句.sh 
zhangsan 18 2005
```

==注意：输入重定向的时候获取数据**以一行为一个数据**。==

## 输出语句echo

- `echo `：输出一个内容到终端上
-  `echo "需要输出的内容" `将` "需要输出的内容"` 输出到标准输出设备 
- 示例： `echo 123` 将 `123` 输出到标准输出设备

## 输出重定向语句>|>>

- 输出重定向：` > `或者 `>>`
  - ` > `：**清空**写入/输出
  -  `>> `：**追加**写入/输出 
- 命令的输出通过向标准输出设备（终端）
-  通过输出重定向的话，可以不将数据输出到终端，从而将个输出的数据重定向到一个文件。这种情 况就叫做：**输入重定向**

```bash
#输出重定向语句
echo "abc123" >> 1.txt
echo "def456" >> 1.txt
#默认是换行输入的，加上-n不换行输入
#echo -n "def456" >> 1.txt

#此时1.txt中有以下数据
zhangsan 18 2005
list 12 abc
abc123
def456
```

# main函数的两个参数

1. **`argc` (Argument Count)**
   - **含义**：命令行参数的数量（个数）。
   - **类型**：整型 (`int`)。
   - **注意**：它的值**至少为1个**。因为第一个参数 (`argv[0]`) 永远是程序自身的名称。
2. **`argv` (Argument Vector)**
   - **含义**：一个字符串数组，存储了所有的命令行参数。
   - **类型**：`char *[]` 或 `char **`（即指向字符串的指针数组）。
   - **内容**：
     - `argv[0]`：程序自身的路径和名称。不同的操作系统提供的这个字符串的完整程度可能不同。
     - `argv[1]`：命令行传入的**第一个实际参数**。
     - `argv[2]`：命令行传入的第二个参数。
     - ...
     - `argv[argc-1]`：最后一个参数。
     - `argv[argc]`：C标准保证它是一个**空指针 (`NULL`)**，标志着数组的结束。这是一个非常有用的哨兵值。
