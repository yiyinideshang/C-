# 正则表达式

场景描述：比如现在需要编写一个程序，其中一个功能为匹配一个字符串中的` IP` 地址

// `IP`地址：`xxx.xxx.xxx.xxx : 0.0.0.0 ~ 255.255.255.255` 点分式数据

**正则表达式**：是用来描述某种规则的字符串的表达式，主要用于模糊搜索（查询）。

正则表达式里面字符串中字符分为两类：

- 普通字符：只代表它自己

  ```c++
  1 2 a b ...
  ```

- 元字符：不代表自己，有特殊的含义（这个含义优先）

  ```c++
  * . ？ + \ ...
  ```

==注意：元字符想要表示自己原有的意思，需要使用 \ 进行转义==

# 元字符

## 匹配任意单个字符.

`. ` ：表示匹配任意单个字符，可以匹配到任何的字符

- 示例

```c++
表达式：.
可以匹配到的结果：a b c 1 2 + { ] < ...
```

## 字符组匹配[]

`[] `：表示字符组，多个字符集合，但是只会匹配该集合中的一个。

- 示例：

```c++
表达式：[123456789] // 表示匹配1~9数字中的任意一个数字
可以匹配到的结果： 1 2 3 4 5 6 7 8 9
表达式：[123abc<] // 表示匹配字符组中任意一个字符
可以匹配到的结果： 1 2 3 a b c <
```

可以用` - `来表示一个范围

```c++
表达式：[1-9] // 表示匹配1~9数字中的任意一个数字
可以匹配到的结果： 1 2 3 4 5 6 7 8 9
表达式：[a-z] // 表示匹配a~z字符中的任意一个字符
其实就是按照ASCII去列举的。
```

## 特定字符的匹配\w

`\w` ：表示匹配 数字、字母、下划线（` _ `）

- 示例:

```c++
表达式：\w // 表示在0~9 a~z A~Z _ 这个范围内去匹配一个字符出来
可以匹配到的结果：0~9数字 A~Z a~z字母 _
```

## 匹配一个或多个字符+

`+ `：表示匹配一个或多个先前字符或者是模式（**贪婪匹配**）

- 示例:

```c++
表达式：\w+ // 表示在0~9 a~z A~Z _ 这个范围内去匹配至少一个字符出来
可以匹配到的结果：1 11 111...
12 122 1222...
a1 a11 a111...
...
表达式：1+ // 表示匹配一个或多个1
可以匹配到的结果：1 11 111...
```

## 匹配零个或多个字符*

`*` ：表示匹配零个或多个先前的字符或者模式（**惰性匹配**）

- 示例

```c++
表达式：\w* // 表示在0~9 a~z A~Z _ 这个范围内去匹配字符出来（可以没有，可以为0）
可以匹配到的结果：Nul 1 11 111...
Nul 12 122 1222...
Nul a1 a11 a111...
...
表达式：1+ // 表示匹配零个或多个1
可以匹配到的结果：Nul 1 11 111...
```

## 匹配零个或一个字符?

`?` ：表示匹配零个或一个先前字符或者是模式

- 示例：

````c++
表达式：ab? // 表示匹配零个或1一个b
可以匹配到的结果： a ab
````


## 匹配指定数目的字符

`{数字} `：表示匹配固定数目的先前字符或模式

示例:

```c++
表达式：a{5} 表示完成匹配到5个a
可以匹配到：aaaaa
```

## 至少匹配多少个字符

`{min,} `：表示至少匹配 min 个先前字符或模式

示例：

```c++
表达式：a{5,} 表示至少匹配到5个a
可以匹配到：aaaaa aaaaaaaa aaaaaaaaa ....
```

## 指定匹配字符的数量

`{min,max} `：表示至少匹配 min 个至多匹配 max 个先前字符或模式

示例：

```c++
表达式：a{2,3} 表示至少匹配2个a，至多匹配3个a
可以匹配到：aa aaa
```

## 子模式

`()` ：表示子模式，其内部表达式看成一个整体（子的正则表达式）

示例：

```c
表达式：(12+)+ 表示至少一个或多个(12或12222... )
可以匹配到：12 122122 12221222....
```

# 正则表达式的`API`接口

```c++
#include <regex.h>

// 正则表达式的接口头文件
int regcomp(regex_t *preg, const char *regex, int cflags);
int regexec(const regex_t *preg, const char *string, size_t nmatch,regmatch_t
pmatch[], int eflags);
size_t regerror(int errcode, const regex_t *preg, char *errbuf,size_t
errbuf_size);
void regfree(regex_t *preg);
```

## 编译正则表达式regcomp

```c++
int regcomp(regex_t *preg, const char *regex, int cflags);
/*
	@描述：
        编译 “正则表达式”。
        “正则表达式” 原始字符串，编译完成之后才能使用
        regex_t 用来表示一个编译完成的正则表达式
	@preg：
		regex_t 类型，所指向的空间，用于存储编译后的正则表达式
	@regex：
        const char* 类型的指针，常量字符串
        表示 未经编译的 “正则表达式” 原始字符串
    @cflags：
        标志位：表示编译正则表达式的属性操作
        REG_EXTENDED 用来扩展正则表达式的语法
        REG_ICASE ignore case 忽略大小写
        REG_NOSUB 不包含子模式
        以上标志都是可以通过位运算符 | 相结合
    @return :
        成功返回0表示无错误
        失败返回非0，该返回值表示一个错误，需要使用regerror去解析错误原因
*/
```

## 进行正则表达式的匹配regexec

```c++
int regexec(const regex_t *preg, const char *string, size_t nmatch,regmatch_t
pmatch[], int eflags);
/*
    @描述：
    	用于执行正则表达式匹配模式的匹配需要匹配的内容
    @preg：
    	正则表达式指针，编译后的正则表达式
    @string：
    	需要通过正则表达式进行内容匹配的字符串，称为：母串（原始字符串）
    @nmatch:
    	本质是一个整型
    	表示：提前告知函数，正则表达式中有多个模式。
    	总模式 = 1 + 子模式数量
    @pmatch：
        表示：通过正则表达式在母串中匹配到的结果会存储在这个数组中
    	regmatch_t 类型 结构类型
    	
    	typedef struct {
            regoff_t rm_so; // rm_so : start offset 当前这个结果起始位置下标
            regoff_t rm_eo; // rm_eo : end offset 当前这个结果的结束位置下标
        } regmatch_t;
        
        模式匹配信息数组
        数组大小为nmatch大小
        一个模式就需要有一个regmatch_t
        指定了多少模式就有多少个regematch_t
	@eflags：
		表示是否匹配行首或行尾 ，一般给0
	@return:
		成功返回0表示匹配到了数据
		失败返回REG_NOMATCH
*/
```

## 错误解析regerror

```c++
size_t regerror(int errcode, const regex_t *preg, char *errbuf,size_t
errbuf_size);
/*
    功能：
    	用来把regcomp和regexec函数执行返回的错误进行解析的，转换为错误信息字符串的
    @errcode：
        int 类型
        错误码。也就是需要进行解析的错误码
    @preg：
        const regex_t *类型
        编译好的正则表达式
    @errbuf:
        char *类型
        指向的空间用于保存解析错误信息之后，存储错误信息字符串的
    @errbuf_size:
    	size_t 类型
    	表示errbuf大小
    @return：
    	返回值为填充到errbuf中的错误提示信息的字符串长度
*/
```

```c++
    @preg：
    	就是编译后的正则表达式
*/
```
