# Makefile工程管理文件

Makefile文件的主要作用包括自动化编译、管理项目、生成可执行文件、清理和重建项目，以及打包和 发布项目。

- **自动化编译**：Makefile可以指定**编译工具**和**编译选项**
  - 编写好依赖关系之后，就可以进行自动化编译。

- **管理项目**：Makefile文件里面源文件和目标文件之间会存在**依赖关系**，在编译过程中自动选择修改 过的文件进行编译。
- **生成可执行文件**：定义生成可执行文件的规则和依赖关系。
- **清理和重建**：清理编译中间的文件，包含删除目标文件、删除可执行文件等。
- **打包和发布**：定义打包和发布操作。

# 自动化编译方式 make

在命令终端执行：` make` ，当命令被执行的时候，自动去找当前目录下的 `Makefile `文件进行执行。

`make` ：没有指定可执行文件名的时候，**默认在当前路径**下去找，名字为` Makefile` 或者说 `makefile`

- 注意：` make` 会**优先执行大写**` Makefile` 文件
- `make target`

# Makefile文件的编写格式

- 依赖关系： `目标文件:依赖文件列表`
  - `目标文件` ：需要生成的文件(可执行文件/.o文件/库文件...) 
  - `依赖文件` ：生成目标文件，需要哪些文件才能生成(一般是` .cpp` 源代码文件)

==注意： `Makefile` 中可以自己定义变量的，但是变量是没有类型，一般作为字符串使用。==

# Makefile的变量的定义

语法： `变量名 赋值符号 值`

## Makefile的赋值方式

**就地赋值**：简单的赋值

- `变量名:=值` 
- 示例：

```makefile
VALUE:="ABCDEF"
```

**递归赋值**：当前变量的值 依赖 后面的变量 来赋值的，**展开的赋值**

- `变量名=值 #向后展开值 `
- 示例

````makefile
A=$(B) # 需要把B的赋值给A
B:="123"
# 上述赋值等价 A = B = "123"
````

**追加赋值**：在**原有值的基础上追加新值**进去

- `变量名+=值1 值2 值3 ... `
- 示例：` A+=1 2 3 4 5 6` 相当于此时A是这组数据的一个集合

**条件赋值**：当**符合条件**的时候才会进行赋值

- `变量名?=值 `当变量没有被定义（第一次被定义）或者没有被赋值的时候，才可以进行赋值 
- 示例： `A?=123`（A之间没有被定义过，或者刚定义，或者定义了没赋值）

## 变量的引用

语法：`$(变量名) `

示例：

```makefile
VALUE1:=10 #创建变量` VALUE `并 就地赋值 为` 10`#就地赋值VALUE1
VALUE2=$(VALUE3) #引用了变量 `VALUE3` 的值#递归赋值VALUE2
VALUE3:=20#就地赋值VALUE3
VALUE3+=30#追加赋值VALUE3
VALUE4?=40#条件赋值VALUE4
VALUE4?=50#二次条件赋值VALUE4
```

## 自动变量

- `$*` ：**不包含扩展名**的目标文件的名字 
- `$@` ：目标文件名字的**完整名称** 
- `$+` ：所有**依赖文件**的名字，以空格进行分开，同时可能会包含**重复**的**依赖文件** 
- `$^` ：所有**依赖文件**的名字，以空格进行分开，但是不包含重复的文件 
- `$<` ：**第一个依赖文件**的名字 
- `$?` ：所有**修改时间比目标文件晚的依赖文件**，以空格进行分开

# Makefile的函数

语法： `$(函数名 参数列表)`

## 文件名展开函数(wildcard）

文件名展开函数：` wildcard `可以搜索指定路径下的特定文件 

- 只能传递一个参数，就是提供文件名的**通配方式**
- 示例：

```makefile
SOURCES +=$(wildcard *.cpp) # 表示将当前文件夹下的所有.cpp结尾的文件名存储到SOURCES中
run:$(SOURCES)
	@echo $^
```

==注意：目录是相对于 `Makefile` 文件而言，而不是针对终端。==

==注意： `wildcard `函数是不会搜索子目录.==

## 字符串替换函数(patsubst)

字符串替换函数：` patsubst `对指定的字符串内容进行替换操作 

- 需要传递三个参数 

  - 原有格式 
  - 替换格式
  -  需要替换的字符串

- 示例：

  ```makefile
  SOURCES += $(wildcard *.cpp)
  OBJECTS += $(patsubst %.cpp,%.o,$(SOURCES))# 表示将所有以.cpp结尾的字符串统统改为以.o结尾
  
  run:$(OBJECTS)
  	@echo $^
  ```

  - ==注意： % 通配符，但是它只作用于本` Makefile` 文件==
  - ==注意：只会更改Makefile中的文件名字，而不会实际的改变文件名字==

## 遍历列表函数(foreach)

遍历列表函数：` foreach `：迭代一个以空格分割的列表内容

- 需要传递三个参数 
  - 列表的当前元素 
  - 列表 
  - 对当前列表元素所要做的操作

- 示例：

  ```makefile
  SOURCES += $(wildcard *.cpp)
  OBJECTS += $(foreach filename,$(SOURCES),$(filename:.cpp=.o))
  
  run:$(OBJECTS)
  	@echo $^
  ```

**注意** 

- `Makefile` 文件用 `tab `缩进来描述包含关系。

- 指令要顶格写
-  规范：变量名一般都会使用大写 
- `Makefile` 文件没有后缀（扩展名） 
- 可以开头大写，也可以小写，但是执行 `make `的时候优先选择大写的 `Makefil`e 文件
-  `gcc `在 `Makefile` 里面被定义成了cc变量 
- 所有的` Makefile` 文件需要放在你要编译的工程目录下才能起效果。

```makefile
SOURCES = $(wildcard *.cpp)
OBJECTS = $(SOURCES:.cpp=.o)  # 这是第三种更简洁的写法

run: $(OBJECTS)
	@echo $^
```
