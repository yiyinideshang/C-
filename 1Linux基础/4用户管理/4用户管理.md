# 用户管理

存储用户信息的文件夹：`/etc/passwd`

- `root:x:0:0:root:/root:/bin/bash`
  - 用户名:密码(口令):用户ID号:组用户ID号:用户家目录:用户的Shell目录
  - root       x                   0                  0          root:/root       /bin/bash
  - `yishang:x:1000:1000:yishang,,,:/home/yishang:/bin/bash`

存储用户组的信息：` /etc/group`

- `root:x:0:`
  - 用户组名:密码:组ID号:成员列表

## 增加用户

`adduser` ：新增一个用户

- 用法： `sudo adduser 用户名称 `
- 示例： `sudo adduser tmpuser` 新增了一个名为 tmpuser 的新用户

## 删除用户

`userdel `：删除一个已经存在的用户

- 用法：` sudo userdel 登录名 `
  - 示例：` sudo userdel tmpuser` 删除一个名为 tmpuser 的用户

==注意：删除用户并不会清除用户的文件夹的信息==

# APT软件包管理工具

`apt` ：软件管理工具，类似于微软商店。是` ubuntu `中最强大的命令行软件包管理工具

**主要功能**： 

- 获取软件 
- 安装软件 
- 卸载软件 
- 搜索软件

**工作原理**： 

- 在 `Ubuntu `中存在一个文件，记录指定查询/下载的网址（网络地址），指定了源服务器的地址。 
  - `/etc/apt/sources.list` ：用来指定源服务器的地址的。 
  - `sudo gedit /etc/apt/sources.list` 通过可视化编辑器来更改 apt 的**源**服务器地址
  -  更改完成软件源之后需要更新软件源：`sudo apt-get update`

**常用操作**：

- 更新软件源： `sudo apt-get update `
- 搜索软件包： `sudo apt-cache search 软件包关键字 `
- 安装软件包：` sudo apt-get install 软件包名 `
- 卸载软件包：` sudo apt-get remove 软件包名`

**常用命令**：

```bash
list - 根据名称列出软件包
search - 搜索软件包描述
show - 显示软件包细节
install - 安装软件包
reinstall - 重新安装软件包
remove - 移除软件包
autoremove - 卸载所有自动安装且不再使用的软件包
update - 更新可用软件包列表
upgrade - 通过 安装/升级 软件来更新系统
full-upgrade - 通过 卸载/安装/升级 来更新系统
edit-sources - 编辑软件源信息文件
satisfy - 使系统满足依赖关系字符串
```

# g++编译工具套件

- **编译文件**： 
  - 语法： `g++ 需要编译的 C++ 源代码文件 `( 以 `.cpp` 扩展名结尾的文件 ) [可以带参数]
    -  `g++ Untitled-1.cpp` // 回车之后会默认生成一个 `a.out `的程序 
  - 语法：` g++ 需要编译的C++源代码文件 ( 以 .cpp 扩展名结尾的文件 ) -o` 指定生成的程序的 名字 
    - `g++` ： 编译器 
    - 需要编译的 C++ 源代码文件 ：源代码的文件可以有多个（多个文件用空格分开）
    -  `-o `： `output` 生成指定 
    - 指定生成的程序的名字 ：不会生成 `a.out` ，而是生成你指定的名字
- 运行程序： 
  - 语法： 指定文件所在目录/文件名字.扩展名 
  - 示例： `./a.out` 表示执行当前目录下的 `a.out `程序

==注意：命令和参数之间需要用空格分隔开。==

# 进程管理

**进程**：是一个正在运行的程序。

## 显示进程信息ps

`ps` ： proccess status 进程信息状态（列出系统中的进程信息状态）

- `ps` ：列举当前终端下的进程信息 
- `ps -a` ：列举当前终端下的所有进程
- `ps -A`:列举当前系统下的所有进程
-  `ps -e` ：列举当前系统下的所有进程

==查询进程信息组合指令：` ps -e | grep 需要查询的进程名`==

## ifconfig

用于配置和显示 Linux 系统中的网络接口信息。它可以查看网络接口（如以太网接口 eth0、无线接口 wlan0 等）的 IP 地址、子网掩码、MAC地址等参数。

## ping

主要用于测试主机之间的网络连通性。它通过发送 ICMP（Internet Control Message Protocol）回声请求数据包到目标主机，并等待目标主机返回回声应答数据包来判断网络是否可达。

- **示例**：`ping 192.168.1.1`，会不断向 IP 地址为 192.168.1.1 的主机发送 ICMP 数据包，直到手动停止（通常使用 Ctrl + C）。

## nc

`nc` 全称 `netcat`，是一个在 `Linux` 中多功能的网络工具，通常用于通过 `TCP` 或 `UDP` 读取和写入网络连接，也能作为客户端或服务端用来 `debug`，测试，网络问题分析。

## `nslookup`

用于查询域名系统（DNS）相关的信息，如查询域名对应的 IP 地址，或者查询 DNS 服务器的信息。
