# 列举目录/文件 ls

- `ls` ： list 列举当前/指定目录下的文件夹和文件

  ==**ls --help ：调取出 ls 指令的帮助手册**==

- 第一种： `ls 目标路径` 可以指定目录进行列举

  - `ls ~ `**列举家目录**下的文件夹和文件

- 第二种： ls [参数] 通过指定 ls 的一些特定参数来实现特殊的列举

  - `ls -a,` --all  不要隐藏以 . 开头的项目，列举当前/指定文件夹下所有的文件夹和文件(**包含隐藏文件**)

  - `ls -l` : **列举当前/指定目录下的文件夹和文件以及它们的属性信息**（**不包括隐藏文件**）

    - ### `drwxrwxrwx 1 root root 0 8月 25 22:37 Code` 表示文件夹/文件的**属性信息**

    如：drwxrwxr-x 2 yishang yishang 4096  8月 25 22:37 linux常用指令

    - drwxrwxrwx ：包含了文件类型以及文件各用户的权限在里面

      - d ：表示了文件类型

        - `d` ： directory **目录文件**

        - p ： pipe 管道文件

        -  l : link 链接文件

        - w ： write 可写入权限 

        - x ： excute 可执行权限

#  复制cp

- `cp` ： copy 拷贝/复制

- 第一种：` cp 源文件(可以有多个) 目标路径{/新名字}` {}中的内容表示可以省略 

  - 示例： `cp ~/1.txt /mnt/hgfs/2.txt `**将当前用户家目录下的 `1.txt` 这个文件，复制到 `/mnt/hgfs/` 目录下，并且将复制后的新文件重命名为 `2.txt`。**

  - 示例： `cp ~/1.txt /mnt/hgfs/` 在复制过程中不会进行更名

-  第二种： `cp 源路径(可以有多个) 目标路径{/新名字} -r `{} 中的内容表示可以省略 

  - 示例： `cp ~/ClassCode/1dir ~ -r` **将当前用户家目录下的ClassCode/文件夹中的 `1dir` 递归地复制到当前用户的家目录中。家目录 → ClassCode目录 → 1dir目录**。
    -  -r ： recursive **（递归）**递归地复制目录；告诉 `cp` 命令递归地进入目录，复制其内部所有的**子目录和文件**。如果不加 `-r` 选项去复制一个目录，系统会报错
  - 示例：`cp ~/ClassCode/1dir /opt/my_project -r`   **将 `1dir` 目录复制到系统级的 `/opt` 目录（通常用于安装附加软件），并重命名为 `my_project`。**

==注意：不能将文件夹往文件中拷贝==

# 修改文件的权限chmod

## 认识权限

- rwxrwxrwx ：表示 **所属用户 组用户 其他用户** 的访问权限
  - rwx ：表示一组权限，也就是一种用户的权限
    -  r ： read 可读取权限
    - w ： write 可写入权限 
    - x ： excute 可执行权限
- 权限表示方式： 
  - 以字符形式： 
  - rwx 以八进制形式： 0777(即二进制：111’111’111)

- 权限所有值：
  - --- ：无任何权限
  -  r-- ：只读权限
  -  -w- ：只写权限
  -  --x ：无读写权限，但是可以执行 
  - rw- ：可读写，不能运行
  -  r-x ：可读可运行不可写 
  - -wx ：可写可执行不可读
  -  rwx ：可读可写可执行

- 如果以八进制形式表示：一类用户的权限就是一个八进制数

  - `--- `： 0 000 : 八进制：00 
  - `rwx` ： 0 111 : 八进制：07
  - `r-x `： 0 101 : 八进制：05

   比特位下： 0 表示无对应权限， 1 表示有对应权限

- linux 里面的权限是有三组 分别为： 

  - 所属用户权限: `user `

  - 所属组用户权限: `group `

  - 其他用户权限: `other` 

    `ugo` :所属用户|所属组用户|其他用户 

- 第一种： `chmod +/- 权限值(字符) 文件/目录名`

  -  示例：` chmod -r 2dir` 将 2dir 文件夹**移除可读权限** 

- 第二种： `chmod 权限值(八进制) 文件/目录名 `

  - 示例：` chmod 0255 2dir` 将 2dir 文件夹的权限更改为 0255 权限 (二进制：011‘111’111)

- 第三种： `chmod 用户类型+/-权限值 文件/目录名` 

  - 示例： `chmod u-rw 2dir` 将 2dir 文件夹的所属**用户权限**中的 **移除可读写权限**。

==注意：以上的命令在家目录操作，不要再共享目录( `/mnt/hgfs` )下去操作,因为共享目录是 windows 文件系统，有的指令是无法生效的==

# 判断外部命令，内部命令

Linux命令有内部（内建）（内置）命令和外部命令之分，内部命令和外部命令功能基本相同，但有些细微差别。

所谓的内部和外部其实是相对Shell自身来讲。Linux系统为了提高系统运行效率，将经常使用的轻量的命令在系统启动时一并加载这些命令到内存中供Shell随时调用，这部分命令即为内部命令。

反之，系统层调用的较重的命令只有当被调用时才会硬盘加载的这部分命令即为外部命令。

## 内部命令

内部命令实际上是[**Shell程序**]的一部分，由 Shell 软件内部进行实现的命令，其中包含的是一些比较简单的`linux`系统命令，这些命令由shell程序识别并在shell程序内部完成运行，通常在linux系统加载运行时shell就被加载并驻留在系统内存中。内部命令是Shell本身的重要组成部分。内部命令嵌入在Shell程序中，并不单独以磁盘文件的形式存在于磁盘上。内部命令是写在bashy源码里面的，其执行速度比外部命令快，因为解析内部命令shell不需要创建子进程，它们都运行在 Shell 进程当中。比如：`exit，history，help，echo，fg，cd、source、export、time`等。

## 外部命令

外部命令是`linux`系统中的实用程序部分，是一个独立的外部可执行程序，因为实用程序的功能通常都比较强大，所以其包含的程序量也会很大，在系统加载时并不随系统一起被加载到内存中，而是在需要时才将其调用内存。通常外部命令的实体并不包含在Shell中，但是其命令执行过程是由Shell程序控制的。当外部命令被调用时，本质就是调用了另外一个程序，首先 Shell 会创建子进程，然后在子进程当中运行该程序。Shell程序管理外部命令执行的路径查找、加载存放，并控制命令的执行。外部命令是在bash之外额外安装的，通常放在/bin，/usr/bin，/sbin，/usr/sbin……等等。可通过“echo $PATH”命令查看外部命令的存储路径。常见外部命令比如：`/bin/ls、vi、tee、tar`等。

## 判断某个命令为外部命令或内部命令

- `type`命令用于显示指定命令的类型，判断给出的指令是内部指令还是外部指令。例如：

- `which` 命令的作用是在 `$PATH` 环境变量指定的目录中搜索**外部命令**（即可执行文件），并返回第一个匹配到的路径。

````bash
yishang@yishang-virtual-machine:~$ type -a ls
ls 是 "ls --color=auto" 的别名
ls 是 /usr/bin/ls
ls 是 /bin/ls
yishang@yishang-virtual-machine:~$ which ls
/usr/bin/ls
````

这说明：ls是一个**外部命令**，命令的路径为/usr/bin/ls。

```bash
yishang@yishang-virtual-machine:~$ type -a cd
cd 是 shell 内建
```

这说明：cd是shell内嵌命令。

| **在线资源**     | 无特定命令        | 所有命令                                     | 当本地文档不足时，可通过搜索引擎查找命令的用法、示例和常见问题。 |

## 🔍 如何判断一个命令支持哪些帮助选项？

1. **优先尝试** `命令 -h` 或 `命令 --help`。如果没有任何输出或提示非法选项，再尝试其他方法。
2. **查看 man 手册**：`man 命令` 几乎总是有效的（如果命令已安装）。man 手册的第一行通常会显示命令的语法和常用选项。
3. **检查版本信息**：`命令 -V` 或 `命令 --version` 可以快速确认命令是否存在以及它的版本。
4. **对于 Shell 内置命令**：直接使用 `help 命令`，或者查阅 `man bash`。
5. **如果以上都无效**：可能是命令没有安装，或者是一个别名/函数。可以用 `type 命令` 查看其类型。

# ==帮助手册 man==

## 1. 什么是 man 手册？

`man`（manual）是 Linux/Unix 系统中最常用的帮助工具，几乎每一个命令、系统调用、库函数、配置文件格式等都有对应的手册页。它采用分章节的方式组织内容，通过 `man` 命令可以查阅这些文档，快速了解某个命令的用法、选项、参数等。

------

## 2. man 手册的章节结构

手册页被划分成多个章节（sections），用数字（或字母）表示。默认情况下，`man` 按章节顺序搜索。常见章节如下：

| 章节 | 内容说明                                                     |
| :--- | :----------------------------------------------------------- |
| 1    | **用户命令**（普通用户在 shell 中可执行的命令，如 `ls`, `cp`） |
| 2    | **系统调用**（内核提供的函数，如 `open`, `read`）            |
| 3    | **库函数**（C 库函数，如 `printf`, `malloc`）                |
| 4    | **特殊文件**（通常指 `/dev` 下的设备文件）                   |
| 5    | **文件格式和约定**（如 `/etc/passwd` 的格式说明）            |
| 6    | **游戏和屏保**（很少用到）                                   |
| 7    | **杂项**（宏包、约定等，如 `man(7)` 本身）                   |
| 8    | **系统管理命令**（通常只有 root 可以执行的命令）             |

> **注意**：同一个名字可能出现在多个章节中，例如 `printf` 在第 1 节（命令）和第 3 节（库函数）都有。如果不指定章节，`man` 默认显示第一个找到的章节。

------

## 3. 基本用法

### 3.1 查看命令手册

```bash
man 命令名
```

示例：`man ls` 查看 `ls` 命令的手册。

### 3.2 指定章节查看

```bash
man 章节号 名称
```

示例：

- `man 1 printf` 查看 `printf` 命令的手册
- `man 3 printf` 查看 C 库函数 `printf` 的手册

### 3.3 查看所有章节的手册（依次显示）

```bash
man -a 名称
```

按 `q` 退出当前章节，自动进入下一章节。

### 3.4 显示手册页的路径

```bash
man -w 名称
```

或

```bash
man --path 名称
```

显示手册文件所在的具体位置。

### 3.5 搜索手册页关键字

```bash
man -k 关键字
```

或

```bash
apropos 关键字
```

搜索所有手册页的名称和简短描述中包含关键字的条目。

## 5. 手册页的常见组成部分

一个典型的手册页通常包含以下段落：

- **NAME**：命令/函数名称及简短描述。
- **SYNOPSIS**：用法概要，显示命令格式或函数原型。
- **DESCRIPTION**：详细描述功能。
- **OPTIONS**：列出所有可用选项及其含义。
- **EXAMPLES**：使用示例（部分手册页提供）。
- **SEE ALSO**：相关命令或文档的参考。
- **BUGS**：已知问题。
- **AUTHOR**：作者信息。

> 示例：`man ls` 查看 `ls` 的手册，可以很清楚地看到这些部分。

## 6. 高级用法与技巧

### 6.1 使用 `man` 查看自身

```bash
man man
```

查看 `man` 命令自己的手册，里面包含所有选项和配置说明。

### 6.2 搜索所有章节的某个函数

如果不知道 `read` 属于哪个章节，可以先搜索：

```bash
man -k read
```

然后根据描述确定要查看的章节。

### 6.3 以特定语言显示手册页

通过设置环境变量 `LANG` 可以查看不同语言的手册（如果系统已安装对应语言包）：

```bash
LANG=zh_CN.UTF-8 man ls
```

尝试显示中文手册（需要中文手册页支持）。

### 6.4 将手册页保存为文本文件

```bash
man ls | col -b > ls_manual.txt
```

`col -b` 用于过滤掉格式化字符，生成纯文本文件。

### 6.5 使用 `whatis` 快速查看简要说明

```bash
whatis ls
```

只显示一行简要描述，相当于 `man -f`。

## 7. 特殊情况的处理

### 7.1 Shell 内置命令

有些命令是 Shell 内置的（如 `cd`、`ulimit`），它们没有独立的手册页，而是包含在 Shell 的手册中（如 `bash(1)`）。可以使用以下方式查看帮助：

- `help 内置命令`（仅对 bash 有效）
- `man bash` 然后在手册中搜索该命令（输入 `/ulimit` 搜索）

### 7.2 没有 man 页的命令

有些第三方软件或简单的脚本可能没有安装手册页。可以尝试：

- 使用 `命令 --help` 或 `命令 -h` 获取简短的帮助信息
- 使用 `info 命令`（info 是另一种帮助系统，有时包含更详细的文档）
- 查看 `/usr/share/doc/` 下对应软件包的文档目录

------

## 8. 环境变量与配置

- **MANPATH**：指定 man 手册的搜索路径。
- **PAGER**：指定分页程序（默认 `less`，可改为 `more` 或 `most`）。
- **MANWIDTH**：指定手册显示的宽度（用于终端宽度不够时调整）。

示例：设置分页器为 `more`：

```bash
export PAGER=more
man ls
```

------

## 9. 总结

`man` 手册是 Linux 学习之路上的必备工具，掌握它能让你快速了解命令的用法，避免频繁上网搜索。记住以下几点：

- 不确定章节时先用 `man -k` 搜索；
- 多使用 `man` 本身的帮助（`man man`）；
- 内置命令用 `help` 查看；
- 阅读时善用 `/` 搜索关键词。

# 切换用户 su

` su `切换用户 

- 第一种用法：` su 用户名 `
  - 示例： `su thirteen13` 切换到` thirteen13` 用户

- 第二种用法： 切换超级管理员

  - **`sudo su`**： 会切换到一个模拟的 root 登录环境。

  - **`sudo -i`**： 会切换到一个更接近真实 root 登录的环境（会读取 root 的 `.profile` 等配置文件）。

  -  示例： 

```c++
yishang@yishang-virtual-machine:~/文档/linux常用指令$ sudo su
[sudo] yishang 的密码： 
root@yishang-virtual-machine:/home/yishang/文档/linux常用指令# 
```

**root 用户**的提示符通常以 `#` 号结尾，并且常常包含 `root` 用户名或主机名

**普通用户**的提示符通常以 `$` 号结尾，并显示你的用户名
