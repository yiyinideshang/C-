# 一、文件 IO 基础（最简版）

 [文件IO.md](..\刷题\牛客C++\文件IO.md) 

- **文件 IO** 就是程序与磁盘上的文件进行数据交换：从文件**读**数据到内存，或者将内存中的数据**写**入文件。
- C++ 标准库提供了 `<fstream>` 头文件，里面有三个常用类：
  - `std::ofstream`：输出文件流，用于**写入**文件。
  - `std::ifstream`：输入文件流，用于**读取**文件。
  - `std::fstream`：通用文件流，既可以读也可以写（需要指定模式）。
- **基本操作**：
  - `open(filename, mode)`：打开文件。
  - `is_open()`：检查文件是否成功打开。
  - `<<` 运算符：向文件写入数据（类似 `cout`）。
  - `close()`：关闭文件（析构时会自动调用，但显式调用也可）。

# open函数

在 C++ 的 `<fstream>` 库中，`open()` 函数的第二个参数是**打开模式**，用于指定如何操作文件（读、写、追加、截断等）。这些模式是 `std::ios_base` 中定义的**位掩码常量**，可以通过按位或 `|` 组合使用。

------

## 一、常用的文件打开模式

| 模式常量           | 含义                           | 说明                                                         |
| :----------------- | :----------------------------- | :----------------------------------------------------------- |
| `std::ios::in`     | 打开文件用于**读取**           | 如果文件不存在，`open` 失败。`ifstream` 默认包含此模式。     |
| `std::ios::out`    | 打开文件用于**写入**           | 默认会清空文件内容（除非与 `in` 或 `app` 等组合）。`ofstream` 默认包含此模式。 |
| `std::ios::app`    | **追加**模式                   | 所有写入都添加到文件末尾，文件指针始终在结尾。即使显式 `seekp` 也无效。 |
| `std::ios::ate`    | 打开后**定位到文件末尾**       | 与 `app` 不同：`ate` 允许在写入前重新定位文件指针（例如用 `seekp` 覆盖旧内容）。 |
| `std::ios::trunc`  | 如果文件已存在，**清空**其内容 | 常与 `out` 组合使用。如果未指定 `trunc` 且文件存在，`out` 默认行为是清空（标准规定），但最好显式写出。 |
| `std::ios::binary` | **二进制**模式                 | 默认是文本模式。二进制模式下不会进行换行符转换（如 `\n` 转 `\r\n`），按原样读写。 |
