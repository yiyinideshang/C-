# 什么是接口

接口是一个共享框架，供两个系统(如在计算机和打印机之间或者用户或计算机程序之间)交互时使用

对于**类**，我们说是**公共接口**， 交互系统由类对象组成，而接口由编写类的人提供的方法组成

通常，C++程序员将接口(类定义)放在头文件中，并将实现(类方法的代码)放在源代码文件中

# 访问控制属性

通过 公有成员函数 -》访问 私有成员

**公有成员函数是程序和对象的私有成员之间的桥梁，提供了对象和程序之间的接口**

将数据封装到私有部分(private)可以保护数据的完整性，防止程序直接访问数据，这被称为**数据隐藏**

- private
- public
- protected

# 类和结构

C++对类进行了扩展，使之具有与类相同的特性

在C++中，类和结构体的唯一区别是：

结构体的的默认访问控制属性是`public`，而类的默认访问控制属性是`private`

C++程序员 通常使用类来实现类描述，而把结构体限制为只表示纯粹的数据对象(普通式数据POD)（`Plian Old Data`）

## 内联函数

**其定义位于类声明的函数都将自动成为 内联函数**，类声明通常将短小的成员函数作为内联函数

Stock::set_tot()是一个内联函数。类声明常将短小的成员函数作为内联函数，set_tot()符合这样的要求。

内联含的特殊规则要求，在每个使用它们的文件中都要对其进行定义

### `stock00.h`

定义一个类的内联函数

- **在类声明中 显示定义该函数**

```c++
// stock00.h -- Stock class interface
// version 00
#ifndef STOCK00_H_
#define STOCK00_H_

#include <string>

class Stock // class declaration
{
private:
    std::string company;
    long shares;
    double share_val;
    double total_val;
    void set_tot() { total_val = shares * share_val; } //内联函数，定义位于类声明
public:
    void acquire(const std::string & co, long n, double pr);
    void buy(long num, double price);
    void sell(long num, double price);
    void update(double price);
    void show();
};     // note semicolon at the end

#endif
```

- **在类声明中 声明方法(使用函数原型) + 在类声明之外(类声明之后),使用`inline`前缀定义该函数，即函数声明 + 内联定义 **

  如，使`set_tot()`成为内联函数的另一种方法：

```c++
class Stock
{
private:
    ...
    void set_tot(); // definition kept separate 定义是分开的 这是函数声明
public:
    ...
};

inline void Stock::set_tot() // use inline in definition 使用内联定义
{
    total_val = shares * share_val;
}
```

# 类的构造函数和析构函数

一般来说，最好是在创建对象时对它进行初始化

C++提供了一个特殊的成员函数——类**构造函数**，**专门用于构造新对象、将值赋给它们的数据成员。**更准确地说，C++为这些成员函数提供了名称和使用语法，而程序员需要提供方法定义。

类的构造函数名称与类名相同。例如，Stock类一个可能的构造函数是名为Stock()的成员函数。构造函数的原型和函数头有一个有趣的特征——虽然没有返回值，但没有被声明为void类型。实际上，**构造函数没有声明类型(返回类型)。**

**构造函数的成员名和参数名**

```c++
Stock::Stock(const string & company, long shares, double share_val)
{
	...
}
```

这是错误的。**构造函数的参数表示的不是类成员，而是赋给类成员的值**。因此，参数名不能与类成员相同，否则最终的代码将是这样的

```c++
shares = shares;
```

为了避免这种混乱，常见的做法是**在数据成员名中使用`m_`前缀** 或者 **在成员名中使用后缀`_**`：

如：

````c++
class Stock
{
private:
    string m_company; 
    // string company_;
    long m_shares;
    //long shares_;
    ...
````

## 使用构造函数

- ### **显式地调用构造函数**：

  ```c++
  Stock garment = Stock("Furry Mason", 50, 2.5));
  ```

- ### **隐式地调用构造函数**:

  ```c++
  Stock garment("Furry Mason", 50, 2.5);
  ```

每次创建类对象（甚至使用new动态分配内存）时，C++都使用类构造函数。下面是将构造函数与new一起使用的方法：

```c++
Stock *pstock = new Stock("Electroshock Games", 18, 19.0);
```

这条语句创建一个Stock对象，将其初始化为参数提供的值，并将该对象的地址赋给`pstock`指针。在这种情况下，**对象没有名称，但可以使用指针来管理该对象。**

无法使用对象来调用构造函数，因为在构造函数构造出对象之前，对象是不存在的。因此**构造函数被用来创建对象，而不能通过对象来调用。**

- ### **拷贝初始化，可以通过explicit禁止隐式转换**

```c++
class Foo {
public:
    Foo(int a) {}	// 无 explicit：允许隐式转换
    // explicit Foo(int a) {} // 有 explicit：禁止隐式转换
};
 
int main() {
    Foo f1(5); // 直接构造 → 始终合法
    Foo f2 = 5; // 拷贝初始化 → 无explicit时合法，有explicit时非法
    //无explicit时，Foo f2 = 5;合法 隐式转换为 Foo(5)，
    //有explicit时，Foo f = 5; 非法（禁止隐式转换）
}
```


## ==使用构造函数的坑：==

下面是非默认构造函数:

```c++
Stock first("Concrete Conglomerate"); // calls constructor
Stock second();                       // declares a function
Stock third;                          // calls default constructor
```

- `Stock first("Concrete Conglomerate");` 这调用了非默认构造函数，即接受参数的构造函数

- `Stock second();`  这个声明指出：`second() `是一个返回`Stock`对象的函数

  **要想使用隐式的默认构造函数，不要带圆括号！**

  ```c++
  Stock second() !=	Stock second
  Stock second() != 	Stock second = Stock() 
  ```



下列代码编译时会产生错误的是（）

````c++
#include <iostream>
using namespace std;
struct Foo {
    Foo() {}
    Foo(int) {}
    void fun() {}
};
 
int main(void) {
    Foo a(10);//语句1
    a.fun();//语句2
    Foo b();//语句3 b是一个函数名
    b.fun();//语句4 不存在b对象，不能通过b调用函数fun
    return 0;
}
````

语句4会发生错误：

语句3没有声明一个b的`Foo`类型，而是声明了一个无参数的返回类型为`Foo`的函数`b`。如果要声明一个`Foo`，并调用默认构造函数，那么应该是这样的：`Foo b；`

```c++
Foo b() != Foo b;
Foo b() != Foo b = Foo();
```

## 析构函数

用构造函数创建对象后，程序负责跟踪该对象，直到其过期为止。对象过期时，程序将自动调用一个特殊的成员函数，该函数的名称令人生畏——**析构函数**。析构函数完成清理工作，因此实际上很有用。例如，

- 如果构造函数使用new来分配内存，则析构函数将使用delete来释放这些内存。
- Stock的构造函数没有使用new，因此析构函数实际上没有需要完成的任务。在这种情况下，只需让编译器自动生成一个什么都不做的隐式析构函数即可，Stock类第一版正是这样做的。然而，了解如何声明和定义析构函数是绝对必要的，下面为Stock类提供一个析构函数。

析构函数的原型：

```c++
~Stock();

Stock::~Stock()
{
     cout << "Bye, " << company << "!\n";
}
```

**什么时候调用析构函数**

这由编译器决定，通常不应在代码中显式地调用析构函数。

- 如果创建的是静态存储类对象，则其析构函数将在程序结束时自动被调用。
- 如果创建的是自动存储类对象，则其析构函数将在程序执行完代码块时（该对象是在其中定义的）自动被调用。
- 如果对象是通过new创建的，则它将驻留在栈内存或自由存储区中，当使用delete来释放内存时，其析构函数将自动被调用。最后，程序可以创建临时对象来完成特定的操作，在这种情况下，程序将在结束对该对象的使用时自动调用其析构函数。**如果构造函数中使用了`new`,则必须提供使用`delete`的析构函数。**

由于在类对象过期时析构函数将自动被调用，因此必须有一个析构函数。**如果程序员没有提供析构函数，编译器将隐式地声明一个默认析构函数**

## **编译器处理	显式调用构造函数的两种方式**：

- 一种是：使其行为和第一种语法完全相同

- 另一种是：允许调用构造函数来创建一个临时对象，然后将该临时对象复制到`stock2`中，并丢弃它。

如果编译器使用第二种方式时，则**会为临时对象调用析构函数**，

## 构造函数的两种工作

- 初始化新对象

  ````c++
  Stock stock1("NanoSmart", 12, 20.0);
  Stock stock2 = Stock ("Boffo Objects", 2, 2.0);//编译器可能会创建临时对象
  ````

- 将新值赋值给已经存在的对象

  ```c++
  stock1 = Stock("Nifty Foods", 10, 50.0);//编译器总是会创建临时对象
  ```

  `stock1`对象已经存在，因此这条语句不是对`stock1`进行初始化，而是将新值赋给它。这是通过让构造程序创建一个新的、临时的对象，然后将其内容复制给`stock1`来实现的。随后程序调用析构函数，以删除该临时对象.

如果既可以通过初始化，也可以通过赋值来设置对象的值，要尽可能使用初始化，这样的效率更高。

## 析构函数的执行顺序

函数main()结束时，其局部变量（`stock1`和`stock2`）将消失。由于**这种自动变量被放在栈**中，因此**最后创建的对象将最先被删除，最先创建的对象将最后被删除**

## 类的`const`对象和`const`成员函数

假设有一下代码：

```c++
const Stock land = Stock("Kludgehorn Properties");
land.show();
```

编译器会拒绝第二行，因为`land`的 `show()`方法无法保证调用对象不被修改 --- 

需要修改成员函数`show()`的声明和定义：

```c++
void show() const; 
void stock::show() const
```

**函数名后面加`const`表示约束函数行为：保证不修改对象状态。**

**类的常对象和常引用一样，只能调用常函数**
