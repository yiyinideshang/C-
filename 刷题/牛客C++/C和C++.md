以下哪一些是C++的属性(非C的属性)[**多选**]

A	union

B	class

C	template

D	virtual function

E	pragma

- **B. class**：C++ 支持类（class）作为面向对象编程的基础，C 语言没有类。
- **C. template**：模板是 C++ 泛型编程的核心特性，C 语言没有模板。
- **D. virtual function**：虚函数是 C++ 实现多态的机制，C 语言没有虚函数。

而：

- **A. union**：联合体在 C 语言中也存在，不是 C++ 独有。
- **E. pragma**：预处理指令 `#pragma` 在 C 和 C++ 中都有，不是 C++ 独有。

因此，属于 C++ 属性（非 C 属性）的是 **B、C、D**。
