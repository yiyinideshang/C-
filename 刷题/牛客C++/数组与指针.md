## 	字符串数组

下面合法的数组声明是（）[多选]

A	char szData[3] = “ab”

B	char szData[2] = “ab”

C	char szData[] = “abc”

D	char szData[] = {“abc”}

- **A：`char szData[3] = "ab";`**
  字符串 `"ab"` 包含字符 `'a'`、`'b'` 和终止空字符 `'\0'`，总长度为 3。数组大小恰好为 3，可以完全容纳，因此合法。
- **B：`char szData[2] = "ab";`**
  字符串 `"ab"` 实际需要 3 个字符空间（包括空字符），但数组大小仅为 2，无法容纳完整字符串。在 C++ 中属于编译错误，在 C 中虽可能允许但会丢弃空字符，通常视为不合法。
- **C：`char szData[] = "abc";`**
  数组大小由初始化器自动推导，字符串 `"abc"` 长度为 4（包含空字符），因此 `szData` 大小为 4，合法且常见。
- **D：`char szData[] = {"abc"};`**
  使用花括号初始化字符数组，其中包含一个字符串字面量。这种写法与 `char szData[] = "abc";` 等价，同样合法。

因此，正确选项为 **A、C、D**。

`strcpy` 函数的执行过程：

```c++
strcpy(p, "hello");
```

1. 它从 `p` 所指向的内存地址（即 `a` 的起始位置）开始写入字符。
2. 将字符串 "hello" 的每个字符（包括结尾的 `'\0'`）依次写入内存。
3. 写入完成后，`a` 数组的前 6 个字节变为：`'h'`, `'e'`, `'l'`, `'l'`, `'o'`, `'\0'`。
4. **关键：** `strcpy` 不会修改指针 `p` 本身的值，它只是使用 `p` 作为目标地址。

```c++
strcpy(a, "abcdefg");// 正确，但要确保字符串长度不超过数组大小-1
strcpy(p, "hello");// 正确，使用strcpy不会修改p本身的值，只是使用p作为目标地址
```

# 避免空指针

在 C++ 中，对应的字符串检查方式取决于使用的是 **C 风格字符串（`char*`）** 还是 **C++ 标准库的 `std::string`**。

---

## 1. **如果使用的是 `std::string`：**

`std::string` 是值类型，不会为 `nullptr`，因此**不需要检查是否为 `null`**。  
只需要检查是否为空字符串即可：

```cpp
std::string str;
if (!str.empty()) {  // 或者 if (str != "")
    // 字符串非空
}
```

### 对应 Java 的 `if (str != null && !str.equals(""))` 的 C++ `std::string` 版本：

```cpp
// 因为 std::string 不会为 nullptr，所以直接：
if (!str.empty()) {
    // 等价于 Java 的 str != null && !str.equals("")
}
```

---

## 2. **如果使用的是 C 风格字符串 `char*`：**

这时需要同时检查 **指针是否为 `nullptr`** 和 **内容是否为空**：

```cpp
const char* str = ...;
if (str != nullptr && str[0] != '\0') {
    // 等价于 Java 的 str != null && !str.equals("")
}
```

或者用 `strlen`（效率稍低，因为会遍历字符串）：

```cpp
if (str != nullptr && strlen(str) > 0) {
    // 等价条件
}
```

---

## 3. **注意：C++ 中的 `nullptr` 和 `NULL`**

- C++11 之后使用 `nullptr` 表示空指针。
- 传统 C++ 中使用 `NULL`（实际上是 0）。

---

## 4. **对比总结**

| 语言 | 类型          | 检查非空且非空字符串的写法                                   |
| ---- | ------------- | ------------------------------------------------------------ |
| Java | `String`      | `str != null && !str.equals("")`                             |
| C++  | `std::string` | `!str.empty()`（empty检查容器为空返回`true`,否则返回`false`） 或 `str != ""` |
| C++  | `char*`       | `str != nullptr && str[0] != '\0'`                           |

---

## 5. **重要区别**

- **Java 的 `String`** 是引用类型，可能为 `null`。
- **C++ 的 `std::string`** 是值类型，不会为 `nullptr`（除非故意用 `std::string*` 指针，但一般不这样用）。
- **C++ 的 `char*`** 是指针，需要检查空指针。

因此，如果你在 C++ 中看到类似 Java 的写法 `if (str != null && !str.equals(""))`，那很可能是处理 `char*` 字符串，或者是来自 Java 程序员的习惯。在 C++ 中，更推荐使用 `std::string` 来避免空指针问题。

# 常量指针与指针常量

**`int * const a`** ： ( * 读成 pointer to ) `a is a const pointer to int` // a 是一个指针，这个指针的地址不能改变，即指针的指向不能改变，但是可以利用这个指针改变值。

**`const int * a` :** `a is a pointer to const int`; //a是一个指针，这个指针指向的地址存放的是一个不允许更改的int。即指针可以指向别的位置（指针的指向可以改变），但是就是不能通过该指针改变地址中的值。

- 关键字`const`在`*`号右边，说明修饰的是**指针本身**，指针指向是固定的，不能再乱指了。

- 关键字`const`在`*`左边，说明修饰的是**指针指向的内容**，指针指向的是一个常量，它的值是固定的，不能在乱改大小了。

## **指针指向的内容是常量（常量指针 / Pointer to Constant）**

```c++
const int* ptr;      // ptr是一个指针，指向一个const int
int const* ptr;      // 同上，等价写法
```

- **特点**：**不能通过这个指针修改指向的内容**
- **指针本身可以改变指向**（指向其他地址）

```c++
#include <iostream>
using namespace std;

int main() {
    int x = 10;
    int y = 20;
    
    const int* ptr;  // ptr指向一个常量整数
    ptr = &x;        // OK：指针可以指向x
    
    // *ptr = 30;    // 错误：不能通过ptr修改x的值
    cout << *ptr << endl;  // OK：可以读取值
    
    ptr = &y;        // OK：指针可以改变指向
    cout << *ptr << endl;  // 输出：20
    
    x = 30;          // OK：x本身不是const，可以直接修改
    cout << *ptr << endl;  // 注意：ptr仍指向x，现在输出30
    
    return 0;
}
```

## **指针本身是常量（指针常量 / Constant Pointer）**

```c++
int* const ptr;      // ptr是一个const指针，指向一个int
```

- **特点**：**指针本身的值（地址）不能改变**
- **指向的内容可以通过指针修改**

```c++
#include <iostream>
using namespace std;

int main() {
    int x = 10;
    int y = 20;
    
    int* const ptr = &x;  // ptr是一个常量指针，初始化时必须赋值
    
    *ptr = 30;            // OK：可以修改指向的内容
    cout << x << endl;    // 输出：30
    
    // ptr = &y;         // 错误：ptr本身是const，不能改变指向
    
    return 0;
}
```

这句话声明了一个指向常量字符串的指针node,指针的值可以修改(可以改变指向)，但是不能通过指针修改它所指向的字符串的内容

- A：**错误**，node[2]即*(node+2), `node[2] = 'k';` 等价与 `*(node+2) = 'k'`

  `node[2]` 的类型是 `const char`（只读字符），而非地址。 

  `node[2] = 'k';`是让指针`node`偏移2位后所指向的内容改为k,由于`node` 是指向 `const char` 的指针，所以不能修改指向的内容

- B:**错误**，混淆了"**指针数组**的元素"和"**字符串指针**的元素"的类型差异

  - **如果** `node` 是 `char*` 数组（指针数组）：
    `char* node[3];` 那么 `node[2]` 是一个 `char*` **指针**，`*node[2]` 是合法的，表示取**该指针指向的字符**。

  - **但实际** `node` 是 `const char*`（字符串指针）：
    `node[2]`等价与`*(node+2)` 直接就是一个 `char` 字符，不能再对它使用 `*` 运算符。

- C:**错误**，**类型不匹配**。`*node` 是 `node` 指向的**字符**,即A（`char` 类型），而 `"xyz"` 是**字符串字面量**（`const char*` 类型），**不能将字符串字面量赋值给字符**

  **关键点**：`node` 指向的是一个字符串，但字符串本质上是一个**字符数组**，而 `node` 指向的是这个数组的**首元素地址**。

  - `node` 类型是 `const char*`，指向字符数组（字符串）的第一个字符。
  - `*node` 解引用得到的是这个字符数组的第一个字符（'A'），类型是 `const char`。

  **为什么不会混淆？**

  - 在C语言中，**字符串**没有单独的“字符串类型”，它就是**以空字符 '\0' 结尾的字符数组**。
  - 当说“`node` 指向字符串”时，是一种简化说法，准确说是“`node` 指向字符串的第一个字符”。
  - 通过这个指针，我们可以访问整个字符串（因为知道起始位置和结束标志 '\0'）

  ````c++
  const char *node = "ABC";
  
  // node 指向：'A' 'B' 'C' '\0' 这个字符数组
  // *node 得到：'A'（第一个字符）node存放字符串的首地址，解引用node得到字符串的首字符
  // node[0] 得到：'A'
  // node[1] 得到：'B'
  // node+1 指向：'B' 的地址
  //*(node+1) 得到：'B'
  ````

- D:**正确**，与A相对应，node虽然不能改变指向的字符串的内容，但是可以改变指向，这句话node="xyz";时node重新指向了一个新的字符串字面量`"xyz"`（即 不是 ` char * const node`）。
