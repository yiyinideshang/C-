# 引用、指针和右值引用

下列说明语句中正确的是：

A `int a,&ra=a,&&ref=ra;`

B `int &refa[10];`

C `int a,&ra=a,&*refp=&ra;`

D `int *pi, *&pref=pi;`

A:将一个右值引用绑定到左值ra中，错误；右值引用只能绑定到右值

B：试图声明“引用的数组”，C++不允许数组元素为引用类型，引用不是对象，，不能构成数组

C： &*refp是不合法的声明符   //引用本身不是对象，因此不能定义指向引用的指针

D：`int *&pref = pi;`表示 声明`pref`为指针的引用 ,**正确**。//指针是对象，存在对指针的引用

- `&pref` 表示 `pref` 是一个引用
- `*` 表示引用的类型是指针

# 变量的声明与定义的关系

为了允许程序拆分成多个逻辑部分来进行编写，C++支持**分离式编译**(`separate compilation`)机制，该机制允许将程序分成若干个文件，每个文件可以被独立编译

为了支持分离式编译，C++将声明和定义分开来

- 声明(declaration)：告诉程序我已经在其他地方定义了，声明必须显式`extern`且不可以赋值
- 定义(definition)：物理实体申请存储空间

```c++
extern int i;//声明i而非定义i
int j;//声明并定义j
```

任何包含了显式初始化的声明即成为定义，也就是抵消了extern的作用

```c++
extern double pi = 3.1415//定义
```

**变量能且只能被定义一次，但可以被多次声明**

**要在多个文件中使用同一变量，就必须将声明和定义分离，此时，变量的定义必须出现且只能出现在一个文件中，而其他用到该变量的文件必须对其进行声明，却绝不能进行重复定义**

# 引用

C++11 新增： **右值引用**(`rvale reference`)

**一般引用，也叫左值引用(reference)**

## 引用是什么

引用就是给 对象另起一个名字

## 引用的定义

如：

```c++
int ival = 1024;
int &refVal = ival;//refVal 指向ival(是ival的别名)
int &refVal2;//错误，引用必须进行初始化,即必须指定引用的对象是谁
```

定义引用时，程序把引用和它的初始值**绑定(bind)**到一起，而不是将初始值拷贝给引用。一旦初始化完成，引用和它的初始值对象 将 一直**绑定**在一起。因此无法令引用重新绑定到另一个对象，因此，**引用必须初始化**

## 引用的特征

**引用不是对象**，它只是对一个已经存在的对象起一个别名

```c++
refVal = 2;//通过引用可以修改它绑定对象的值;这是把2赋给了refVal绑定的对象，即赋值给了ival，ival的值由1024变为了2
int ii = refVal;//通过引用可以将绑定的对象的值赋给其他对象;这个结果与int ii = ival一样
//int ii = ival
int &refVal3 = refVal;//这里将refVal绑定的对象赋给了refVal3，让refVal3同refVal一样，都是 ival的引用
```

- 为引用赋值，实际上是把值赋给了与引用绑定的对象。

- 获取引用的值，实际上是获取了与引用绑定对象的值

- 以引用作为初始化，实际上是以 引用绑定的对象作为初始值

**引用不是对象，所以不能定义引用的引用**

# 指针

指针(pointer)是指向(point to) 另一种类型的复合类型

通过指针可以实现对其他对象的间接访问

```c++
int ival = 42;
int *p = &ival;//定义了一个int类型的指针p,p中存放的是ival的地址，或者说p是指向变量ival的指针
cout<<*p;//解引用指针p，得到p所指向的对象，的内容 输出42
```

## 解引用符(操作符`*`)

对指针进行解引用，得到所指向的对象

对指针解引用的结果进行复制，实际上就是给指针指向的对象赋值

```c++
*p = 0;//由*解引用得到指针p所指向的独享，通过指针p为变量ival赋值
cout<<*p;//输出0
```

## 空指针

空指针(null pointer)

```c++
int *p1 = nullptr;
int *p2 = 0;
int *p3 = NULL;
```

## `void*` 指针

`void *`是一种特殊的指针类型，可用于存放任意对象的地址

不能直接操作`void*`指针所指向的对象，因为不知道该对象的类型，也就无法确定能在这个对象上面进行什么操作

## 复合类型的声明

```c++
int *p1,p2;//p1是指向int的指针，p2是int类型的变量
int *p1,*p2;//p1,p2都是指向int类型的指针
```

## 指向指针的指针

```c++
int ival = 1024;
int *pi = &ival;//pi指向一个int类型变量ival的指针
int **pii = &pi;//pii指向int类型指针pi的 指针

ppi		 pi		ival
[	-]-> [	-]->[	1024 	]
```

## 对指针的引用

引用本身不是对象，因此不能定义指向引用的指针

但是指针是对象，所以存在对指针的引用

```c++
int i = 42;
int *p;//p是一个指向int类型的指针
int *&r = p;//r 是一个对 int类型的指针p 的引用

r = &i;//通过引用来修改指针p的指向，r引用了一个指针，因此对r赋值&r，即令p指向i;
*r = 0;//通过引用来修改指针p的指向的内容(值)
//解引用r得到i,也就是p指向的对象，将i的值改为0
```

# ==对一条复杂的指针或引用的声明语句时，从右向左阅读有助于弄清楚它的真正含义==

```c++
const int* const p;
// 从右向左读：
// p is a const pointer to const int
// 所以：左边const是底层，右边const是顶层
```



# `const`限定符

默认情况下，`const`对象被设定仅在该文件内有效。当多个文件出现了同名的`const`变量时，等同于在不同文件中分别定义独立的变量

- #### **如果想在多个文件中共享`const`对象，必须在变量的定义之前添加`extern`关键字**

在一个文件中定义`const`，而在其他多个文件中声明并使用它：

解决方法： 对于`const`变量，不管是声明还是定义都添加`extern`关键字，这样只需要定义一次即可

- 在该文件中定义并初始化

````c++
//file_1.cpp
extern const int bufsize = fcn();
//在该文件中定义并初始化常量bufsize，该变量能在其他文件中访问
````

- 在其他文件中声明并可以使用

```c++
//file_1.h
extern const int bufsize;
//在该文件中声明，这与file_1.cpp中定义的bufsize是同一个
```

## `const`的引用

将引用绑定到`const`对象上，称之为 对常量的引用(`reference to const`)

```c++
const int ci = 1024;
const int &r1 = ci;
r1 = 42;//错误，不能通过常量引用来修改绑定的值

int &r2 = ci;//错误，常对象只能被绑定到常引用
```

- 常引用也叫万能引用，即能引用左值，也能引用右值；常引用所绑定的对象即可以是普通对象也可以是常对象，如以下的 `r1`(常引用绑定普通对象)、`r3`(常引用绑定常对象)

- 普通引用，只能引用左值

  ```c++
  int x = 5;
  const int& r1 = x;//正确，常引用，引用左值
  const int& r2 = 42;//正确，常引用，引用右值
  const int& r3 = x*2;//正确，常引用，引用右值
  int& r4 = r1*2//错误，普通引用，不能引用右值,只能引用左值
  ```

- 普通对象（非常对象），可被以绑定到常引用或非常引用

- 常对象只能被绑定到常引用

```c++
int x = 5;
const int cx = 10;

const int& r1 = x;//正确，普通对象，被绑定到常引用
int& r2 = x;//正确，普通对象，被绑定到普通引用

const int &r3 = cx;//正确，常对象，被绑定到常引用
int& r4 = cx;//错误，常对象只能被绑定到常引用
```

- 类对象的普通引用和普通对象一样，即能调用常函数，也能调用普通函数
- 类对象的常引用和常对象一样，只能调用常函数
  - 常对象和常引用 说明这个对象不可再被改变了，
  - 常对象和常引用要调用的函数，在类中的必须明确表示  这个函数内部不改变对象，也就是常成员函数，这样 常对象和常引用才能调用，即     类对象的常引用和常对象一样，只能调用常函数

## 指针和`const`

### 指向常量的指针(`pointer to const`)

- // `const`在`*`左边，表示指针指向的数据是常量，**约束的是指针所指向的对象，指针不要乱改指向的值了**
- // 可以改变指针的指向，但不能通过指针修改数据

```c++
int x = 10;
const int* ptr = &x;// 或 int const* ptr;
// *ptr = 20;  // 错误！不能通过ptr修改x
ptr = nullptr; // 正确，可以改变指针的指向
```

### 常量指针(`const pointer`)

- // `const`在`*`右边，表示指针本身是常量，**约束的是指针本身，指针不要乱指了**
  // 指针的指向不能改变，但可以通过指针修改数据

```c++
int x = 10, y = 20;
int* const ptr = &x;
*ptr = 30;  // 正确，可以修改x的值
// ptr = &y;  // 错误！不能改变指针的指向
```

## 顶层`const`与底层`const`

- ### **顶层`const`（`Top-level const`）**

  - ==表示**对象本身**是常量==

  - 主要应用于变量、指针本身等

  - 可以出现在任何数据类型上

- ### **底层`const`（`Low-level const`）**

  - ==表示**指针或引用所指向的对象**是常量==

  - 主要应用于指针和引用

  - 与复合类型的基本类型部分相关

- ==**约束自己是顶层`const`，约束别人是底层`const`**==

### ==示例==

```c++
int x = 10;
const int y = 20;           // 顶层const：y本身是常量

// 指针相关示例
int* const p1 = &x;        // 顶层const：指针本身是常量
const int* p2 = &y;        // 底层const：指向的数据是常量
const int* const p3 = &y;  // 左const是底层，右const是顶层

// 引用只有底层const
const int& r = y;          // 底层const：引用的对象是常量
```

### **用途1：理解拷贝和赋值规则**

```c++
int x = 10;
const int cx = 20;
const int* p1 = &cx;  // 底层const

// 规则：非常量可以转换为常量（添加底层const）
const int* p2 = &x;   // OK：int* → const int*
// int* p3 = p1;      // 错误！不能去掉底层const

// 顶层const在拷贝时被忽略
int y = cx;           // OK：顶层const被忽略
const int cy = x;     // OK：添加顶层const
```

### **用途2：函数重载**

```c++
void print(int* ptr);           // #1
void print(const int* ptr);     // #2：底层const不同，可以重载
// void print(int* const ptr);  // 错误！顶层const不能重载

int main() {
    int x = 10;
    const int y = 20;
    
    print(&x);  // 调用 #1
    print(&y);  // 调用 #2
    
    const int* p1 = &x;
    int* const p2 = &x;
    
    print(p1);  // 调用 #2（底层const）
    print(p2);  // 调用 #1（顶层const被忽略）
}
```

### **用途3：类型推导（模板和auto）**

```c++
const int cx = 10;
const int* p = &cx;

// auto会忽略顶层const，但保留底层const
auto a = cx;     // a是int（顶层const被忽略）
auto b = p;      // b是const int*（底层const保留）

// decltype保留所有const
decltype(cx) c = cx;  // c是const int（顶层const保留）
decltype(p) d = p;    // d是const int*（底层const保留）
```

### **用途4：成员函数重载**

```c++
class MyClass {
    std::vector<int> data;
public:
    // 底层const可以区分重载
    int& operator[](size_t index) {  // 用于非常量对象
        return data[index];
    }
    
    const int& operator[](size_t index) const {  // 用于常量对象
        return data[index];
    }
};

MyClass obj;
const MyClass constObj;

obj[0] = 10;        // 调用非常量版本
int val = constObj[0];  // 调用常量版本
// constObj[0] = 10;    // 错误！不能修改
```

### **规则1：非常量 → 常量（安全）**

```c++
int* → const int*     // 添加底层const ✓
int& → const int&     // 添加底层const ✓
int → const int       // 添加顶层const ✓
```

### **规则2：常量 → 非常量（危险，需要强制转换）**

```c++
const int* → int*     // 需要const_cast
const int& → int&     // 需要const_cast
const int → int       // 顶层const，可以直接拷贝（值复制）
```

### **规则3：拷贝操作**

- **顶层const在拷贝时被忽略**
- 底层const必须匹配或可转换

```c++
const int cx = 10;
int x = cx;          // OK：顶层const被忽略

const int* p1 = &cx;
// int* p2 = p1;     // 错误！不能去掉底层const
const int* p3 = p1;   // OK：相同底层const
int* p4 = const_cast<int*>(p1);  // 危险！但语法允许
```

区别顶层`const`和底层`const`有助于：

- **理解类型推导规则**

- **类型安全**：帮助编译器发现潜在错误
  - 正确使用指针和引用
- **`API`清晰**：明确函数是否能修改参数
  - 设计安全的`API`接口
- **多线程安全**：`const`成员函数天然是线程安全的
- **优化机会**：编译器可以利用`const`信息优化
- **代码可读性**：明确表达设计意图
  - 编写`const`正确的代码
