# 函数

函数`fun`的声明为`int fun(int *p[4])`,以下哪个变量可以作为`fun`的合法参数（）

A	`int a[4][4];`

B	`int **a;`

C	`int **a[4]`

D	`int (*a)[4];`



函数 `fun` 的参数 `int *p[4]` 是一个数组声明，但在函数参数中它会退化为指向 `int*` 的指针，即 `int**`。因此，`fun` 实际接收一个 `int**` 类型的参数。

- **A**：`int a[4][4]` 的类型为 `int (*)[4]`（指向长度为4的整型数组的指针），与 `int**` 不兼容。
- **B**，**正确**：`int **a` 的类型为 `int**`，与参数退化后的类型完全匹配，是合法参数。
- **C**：`int **a[4]` 是一个数组，每个元素为 `int**`，退化为 `int***`，与 `int**` 不兼容。
- **D**：`int (*a)[4]` 的类型为 `int (*)[4]`，与 `int**` 不兼容。

关于类模板的说法正确的是（）

A	类模板的主要作用是生成抽象类

B	类模板实例化时，编译器根据给出的模板实参生成一个类

C. **错误**
模板里的数据成员类型可以随模板参数变化，例如 `T val;` 在 `Vector<int>` 中是 `int`，在 `Vector<string>` 中就是 `string`，并非“同样类型”。

D. **错误**
成员函数可以有任意返回值类型，包括 `T`、`T&`、`void` 等，完全由模板参数或程序员自己指定。

# `std::bind`

*std::bind* 是 C++11 引入的一个函数模板，用于创建一个新的可调用对象，将函数或其他可调用实体与部分参数绑定在一起。它的主要作用是通过参数绑定和重组，生成一个新的函数对象，从而实现更灵活的函数调用。

基本用法

`std::bind` 定义在头文件 `<functional>` 中，支持两种形式：

```c++
#include <functional>
#include <iostream>
// 示例函数
void exampleFunction(int a, int b, int c) {
   std::cout << "a: " << a << ", b: " << b << ", c: " << c << std::endl;
}
int main() {
   using namespace std::placeholders; // 使用占位符 _1, _2, _3
   // 绑定函数，将第一个参数固定为 10
   auto boundFunction = std::bind(exampleFunction, 10, _1, _2);
   // 调用绑定后的函数
   boundFunction(20, 30); // 输出: a: 10, b: 20, c: 30
   return 0;
}
```

在上述代码中，`std::bind` 将 *`exampleFunction`* 的第一个参数绑定为固定值 *10*，而 *_1* 和 *_2* 是占位符，表示调用时需要提供的参数。

主要功能

1. **参数绑定**：可以将函数的部分参数固定为特定值，生成一个新的可调用对象。
2. **占位符支持**：通过 *std::placeholders::_1* 等占位符，可以灵活调整参数顺序或延迟提供参数。
3. **成员函数绑定**：支持将类的成员函数绑定到具体对象或对象指针上。
4. **与 \*std::function\* 配合**：生成的可调用对象可以存储在 *std::function* 中，便于统一管理和调用。

成员函数绑定示例

```c++
#include <functional>
#include <iostream>
class MyClass {
public:
   void printSum(int x, int y) {
       std::cout << "Sum: " << x + y << std::endl;
   }
};
int main() {
   MyClass obj;
   // 绑定成员函数
   auto boundMemberFunction = std::bind(&MyClass::printSum, &obj, _1, _2);
   // 调用绑定后的函数
   boundMemberFunction(5, 10); // 输出: Sum: 15
   return 0;
}
```

*std::bind* 可以绑定类的成员函数或数据成员

在这个例子中，*std::bind* 将 *MyClass::printSum* 绑定到对象 *obj* 上，生成了一个新的可调用对象。

优缺点

**优点**：

- 提供了灵活的参数绑定和函数重组能力。
- 支持多种可调用对象（普通函数、成员函数、函数对象等）。
- 与 *std::function* 结合使用，便于统一管理。

**缺点**：

- 语法复杂，尤其是涉及多个参数和占位符时，代码可读性较差。
- 性能可能不如直接使用 Lambda 表达式。
- 不支持完美转发和移动语义，限制了某些场景的使用。

与 Lambda 表达式的对比

在现代 C++ 中，Lambda 表达式通常是 *std::bind* 的更优选择，因为它更直观、灵活且性能更高。例如，上述绑定函数的例子可以用 Lambda 表达式替代：

```c++
#include <iostream>
void exampleFunction(int a, int b, int c) {
   std::cout << "a: " << a << ", b: " << b << ", c: " << c << std::endl;
}
int main() {
   auto lambdaFunction = [](int b, int c) { exampleFunction(10, b, c); };
   lambdaFunction(20, 30); // 输出: a: 10, b: 20, c: 30
   return 0;
}
```

相比 *std::bind*，Lambda 表达式的语法更加简洁，且支持完美转发。

**总结**

*std::bind* 是 C++11 提供的一种强大的工具，用于函数绑定和参数重组。然而，随着 Lambda 表达式的引入，*std::bind* 的使用场景逐渐减少。在现代 C++ 编程中，建议优先使用 Lambda 表达式来替代 *std::bind*，以获得更好的代码可读性和性能。





````c++
#include <functional>
 
void func(int x, int y) {};
auto l = [](int x, int y) {};
 
class C {
public:
    void operator () (int x, int y) const {};
    void memfunc(int x, int y) const {};
};
````

基于以上C++代码，以下定义无法通过编译的是（）[**多选**]

A	std::bind(func, 10, 20)();

B	std::bind(l, 10, 20)();

C	std::bind(C(), 10, 20)();

D	std::bind(&C::memfunc, 10, 20)();

- **A**：`func` 是普通函数，`std::bind` 可以正确绑定函数指针和参数，生成的可调用对象可以直接调用。
- **B**：`l` 是 lambda 表达式，可以隐式转换为函数对象，绑定方式与普通函数类似，可以编译。
- **C**：`C()` 生成一个临时函数对象（仿函数），其 `operator()` 可调用，绑定方式正确。
- **D**：`&C::memfunc` 是成员函数指针。使用 `std::bind` 绑定非静态成员函数时，**第二个参数必须是一个类对象（或指针/引用）**，用于调用该成员函数。此处第二个参数是 `10`（`int` 类型），无法作为 `C` 类对象使用，因此编译失败。

# 回调函数

下面有关回调函数的说法，错误的是？

A	回调函数一般是一个通过函数指针调用的函数

B	回调函数可能被系统API调用一次，也可能被循环调用多次

C	回调函数本身可以直接是全局函数 、静态函数或某个特定类的成员函数

D	回调函数可用于通知机制

- **A 正确**：回调函数通常通过函数指针（或类似机制，如函数对象、std::function）来调用，这是回调的基本特征。
- **B 正确**：回调函数的调用次数取决于设计需求，可能被调用一次（如异步操作完成）或多次（如遍历、定时事件）。
- **C 错误**：回调函数如果使用普通函数指针传递，则必须是**全局函数**或**静态成员函数**，因为它们的签名与普通函数指针兼容。**非静态成员函数**由于隐含的 `this` 指针，不能直接作为普通函数指针使用，需要借助对象实例和包装机制（如 `std::bind`、lambda 或静态成员函数中转）。
- **D 正确**：回调函数广泛用于事件驱动和通知机制，例如在异步操作完成后通知调用者。
