# 函数重载

以下不是double compare(int,int)的重载函数的是()

B double compare(double,double)

C double compare(double,int)

D int compare(int,int)

函数重载的定义：

**重载函数必须具有相同的函数名但不同的参数列表（参数类型、顺序或数量不同）。返回类型不影响重载。**

## 1

下列关于运算符重载的叙述中，正确的是（    ）

A	通过运算符重载，可以定义新的运算符

B	有的运算符只能作为成员函数重载

C	若重载运算符+，则相应的运算符函数名是+

A. ❌ 错误。只能对**已有**的运算符（如 +、-、*、/、[] 等）进行重载，**不能发明新符号**。

B. ✔️ 正确。例如 `=`、`[]`、`()`、`->`、`T*` 类型转换函数等，**必须**以成员函数形式重载，不允许是友元/普通函数。

C. ❌ 错误。函数名是 `operator+`，而不是单独的 `+`。

D.❌ 错误。如果采用**成员函数**重载，左操作数就是隐式的 `this`，形参表只需写**一个**参数（右操作数）。

## 3	`++`运算符的重载

如果定义了一个类`myclass`, 则为`myclass`类对象以成员函数形式重载后++运算符的声明应该是：

A:	`myclass operator++()`                     

B:	`myclass operator++(int)`

C:	`myclass &operator++()`

D:	`myclass &operator（int)`



**前++的重载方式：**

```c++
 //前++:成员函数形式
    Integer& operator++(void)
    {
        ++m_i;
        return *this;
    }
    //前--:全局函数形式
    friend Integer& operator--(Integer& i)
    {
        --i.m_i;
        return i;
    }
```

**后++的重载方式:** 	与前++区别，不带&，参数带上哑元int

```c++
//后++:成员函数形式
	const Integer operator++(int /*哑元*/)
	{
		Integer old = *this;
		++this->m_i;//++m_i;
		return old;
	}
	//后--:全局函数形式
	friend const Integer operator--(Integer& i, int/*哑元*/)
	{
		Integer old = i;
		--i.m_i;
		return old;
	}
```

\- 返回类型是 float* 而不是要求的 float&
\- 不能直接用于元素访问







# 成员函数的隐藏,重写,重载

- **重载（Overload）**：是指同一可访问区内被声明的几个具有不同参数列（参数的类型，个数，顺序不同的同名函数，根据参数列表确定调用哪个函数。重载不关心函数返回类型。 
  - **相同作用域内，同名函数，不同参数列表。编译器根据实际传入的参数列表来确定调用哪个函数。**
- **隐藏（Hide）**：是指子类的函数屏蔽了与其同名的基类函数，注意**只要同名函数，不管参数列表是否相同，基类函数都会被隐藏。** 
- **重写(覆盖)（Override）**：是指子类中存在重新定义的函数。**其函数名，参数列表，返回值类型，所有都必须同基类中被重写的函数一致。只有函数体不同**（花括号内），**子类调用时会调用子类的重写函数**，不会调用被重写函数。重写的**基类**中被重写的函数必须有`virtual`修饰。

| 特性             | 重载（Overload） | 重写（Override）         | 隐藏（Hide）                                 |
| :--------------- | :--------------- | :----------------------- | :------------------------------------------- |
| **作用域**       | 同一个类         | 基类和派生类             | 基类和派生类                                 |
| **函数名**       | 相同             | 相同                     | 相同                                         |
| **参数列表**     | 必须不同         | 必须相同                 | 可以不同                                     |
| **返回类型**     | 可以不同         | 必须相同（协变除外）     | 可以不同                                     |
| **虚函数要求**   | 不要求           | 必须是虚函数             | 不要求（如果是虚函数且参数相同，则变为重写） |
| **关键字**       | 无               | `virtual` + `override`   | 无                                           |
| **绑定方式**     | 静态绑定         | 动态绑定（多态）         | 静态绑定                                     |
| **访问基类函数** | 直接调用         | 通过基类指针调用基类版本 | 使用 `Base::function()`                      |

有如下类模板定义：（）

```c++
template<class　T> class　BigNumber{ 
    long　n; 
public: 
    BigNumber(T i):n(i){}
    BigNumber　operator+(BigNumber　b)
    { 
        return　BigNumber(n+b.n); 
    } 
};
```

已知b1,b2是BigNumber的两个对象,则下列表达式中错误的是?

A	3+3

B	b1+3

C	b1+b2

D	3+b1

- **A选项：`3+3`**
  这是普通的整数加法表达式，与`BigNumber`类无关，语法合法。
- **B选项：`b1+3`**
  成员运算符`operator+`的左操作数为`BigNumber`对象`b1`，右操作数`3`可通过构造函数`BigNumber(T i)`隐式转换为`BigNumber`对象，因此表达式合法。
- **C选项：`b1+b2`**
  两个`BigNumber`对象直接使用成员运算符`operator+`，合法。
- **D选项：`3+b1`**
  成员运算符`operator+`要求左操作数为`BigNumber`对象，而此处左操作数为整数`3`，不会调用该成员运算符。同时，没有定义全局的`operator+(int, BigNumber)`，因此表达式无法编译，是错误的。

1. 模版定义：

   `template<class T>` 表示这是一个类模板，`T` 是一个类型参数，在实例化时指定具体类型（如 `int`、`double` 等）。

2. 数据成员：

   `long n` 是`BigNumber`类的私有成员，用于存储一个长整型数值。

3. 构造函数：

   `BigNumber(T i): n(i)` 是构造函数，接受一个类型为 `T` 的参数 `i`，并将其赋值给 `n`。注意：由于 `n` 是 `long` 类型，若 `T` 不是 `long`，可能会发生隐式类型转换。

4. 重载加法运算符：

   `BigNumber operator+(BigNumber b)` 是成员函数，重载了 `+` 运算符。它接受另一个 `BigNumber` 对象 `b`，将当前对象的 `n` 与 `b.n` 相加，并用相加的结果构造一个新的 `BigNumber` 对象返回。

使用示例：

```c++
BigNumber<int> b1(10);  // 实例化为 int 类型，b1.n = 10
BigNumber<int> b2(20);  // b2.n = 20
BigNumber<int> b3 = b1 + b2;  // 调用 operator+，b3.n = 30
```

注意事项:

- 由于 `operator+` 是**成员函数**，它隐含的左操作数是当前对象，因此只能用于 `BigNumber + BigNumber` 或 `BigNumber + 其他类型`（若构造函数支持隐式转换），但不能用于 `其他类型 + BigNumber`（如 `3 + b1`），除非定义了全局的友元运算符函数。
- 代码中的 `BigNumber` 在类内使用时，默认指代当前实例化类型（即 `BigNumber<T>`），但返回类型和参数类型可以简写为 `BigNumber`（在类模板内部，类名可以直接使用）。
- 这个模板允许用不同类型（如 `int`、`float` 等）初始化 `BigNumber` 对象，但最终数据都存储为 `long` 类型，因此可能会发生精度损失或截断。
