# `fork`

```c++
for (int i = 0; i < 2; i++)
{
    fork();
    printf("-\n");
}
```

会打印出多少个"-"?
A	4
B	5
**C	6**
D	8

该代码段中的循环会执行两次，每次循环中调用 `fork()` 创建新进程，然后打印 "-"。初始进程在第一次循环后创建一个子进程，此时有两个进程。这两个进程在第二次循环中各自再创建一个子进程，最终共有四个进程。每个进程打印的次数取决于它被创建的时机：

- 初始进程：在两次循环中各打印一次，共2次。
- 第一次循环创建的子进程：在第一次循环中打印一次，在第二次循环中打印一次，共2次。
- 第二次循环创建的两个子进程：各打印一次，共2次。

总打印次数为 2 + 2 + 1 + 1 = 6。

因此，程序会打印出 6 个 "-"。
