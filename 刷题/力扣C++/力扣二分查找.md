# 35. 搜索插入位置

> 提示:`nums` 为 **无重复元素** 的 **升序** 排列数组

- 数组、二分查找

## for循环查找法

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        for(int i = 0;i<nums.size();i++){
            if(nums[i]>=target){
                return i;
            }
        }
        return nums.size();
    }
};
```

### 复杂度分析

- **时间复杂度**：**O(n)**
  最坏情况下需要遍历整个数组（当 `target` 比所有元素都大，或数组中没有满足 `>= target` 的元素），循环执行 `n` 次。
- **空间复杂度**：**O(1)**
  只使用了固定的几个变量，没有额外空间。

## 标准模版库STL函数查找法

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        //标准库中的二分查找函数,返回第一个大于等于指定值的元素的迭代器,否则返回end()
        return std::lower_bound(nums.begin(),nums.end(),target)-nums.begin();
    }
};
```

### 复杂度分析

- **时间复杂度**：**O(log n)**
  C++ 标准要求 `lower_bound` 在随机访问迭代器（如 `vector` 的迭代器）上使用二分查找，比较次数约为 `log₂(n) + 1`。
- **空间复杂度**：**O(1)**
  内部实现是迭代，不分配额外空间。

## 二分查找法

### 左闭右闭[left,right]-找到值为target的位置,不保证是第一个或最后一个

- `right = nums.size() - 1`
- `left <= right`
- ` right = mid - 1; `

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;      // 闭区间
        while (left <= right) {           // 区间不为空，等号有意义
            int mid = left + (right - left) / 2;
            if(nums[mid]==target){        // 法1:找到直接返回,因为nums为无重复元素的升序排列数组
                return mid;
            }
            if (nums[mid] < target) {
                left = mid + 1;           // 去右半边 [mid+1, right]
            } else if (nums[mid] > target) {
                right = mid - 1;          // 去左半边 [left, mid-1]
            } //else {
                //return mid;               // 法2:找到直接返回,因为nums为无重复元素的升序排列数组
            //}
        }
        return left;                      // 没找到，返回插入位置
    }
};
```

## 方法三：二分查找

**240.搜索二维矩阵II**：这题的矩阵不保证完全顺序排序

> - 每行的元素从左到右升序排列。
> - 每列的元素从上到下升序排列。

**这题的矩阵保证了完全顺序排序,是完全单调递增的**

> - 每行中的整数从左到右按非严格递增顺序排列。
> - 每行的第一个整数大于前一行的最后一个整数。

所以可以将**二维有序数组**看做一个**一维有序数组**，然后用二分法判断 `target` 是否在 `matrix` 中。

`a=[1,3,5,7,10,11,16,20,23,30,34,60]`

> 代码实现时，并不需要真的拼成一个长为 m*n 的数组 a，而是将 a[i] 转换成矩阵中的行号和列号。例如示例 1，i=5 对应的 a[i]=11，由于矩阵有 n=4 列，所以 a[i] 在 $\left\lfloor \frac{i}{2} \right\rfloor$=1行，在 i mod n =1列。

**一般地**：

a[i] = matrix[$\left\lfloor \frac{i}{2} \right\rfloor$] [i % n]

### 代码: 左闭右闭

```c++
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size();
        int n = matrix[0].size();
        int left = 0;
        int right = m*n-1;
        while(left <= right){
            int mid = left+(right-left)/2;
            int x = matrix[mid/n][mid%n];
            if(x == target){
                return true;//找到直接返回,因为该二维矩阵严格单调递增
            }
            if(x < target){
                left = mid+1;
            }
            else if(x>target){
                right = mid-1;
            }
        }
        return false;
    }
};

int main(){
    vector<vector<int>> matrix  = {{1,3,5,7},{10,11,16,20},{23,30,34,60}};
    Solution s;
    int target = 3;
    std::cout<<s.searchMatrix(matrix,target)<<std::endl;

    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(log(*mn*))，其中 *m* 和 *n* 分别为 *matrix* 的行数和列数。
- 空间复杂度：O(1)。

# 34. 在排序数组中查找元素的第一个和最后一个位置

- 数组、二分查找

## 法一:暴力法

将所有值为target的元素下标都存放到结果数组中

如果数组中存在目标值target，先保存数组中的第一个元素和最后一个元素，然后清除整个数组，再取结果数组的第一个元素和最后一个元素并返回。

如果数组中不存在目标值target，则直接构建数组为:{-1,-1}

### 代码1

```c++
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        vector<int> result;
        bool flag = false;
        for(int i = 0;i<nums.size();i++){
            if(nums[i] == target){
                result.emplace_back(i);
                flag = true;
            }
        }
        if(flag){
            int i = result.front();
            //int j = result[result.size()-1];
            int j = result.back();
            result.clear();
            result.emplace_back(i);
            result.emplace_back(j);
        }
        else{
            result.insert(result.begin(),2,-1);//从头插入两个元素,值为-1
        }
        return result;
    }
};
```

### 代码3

**优化版:**

```c++
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int first = -1,last = -1;
        for(int i = 0;i<nums.size();++i){
            if(nums[i] == target){
                if(first == -1) first = i;  //记录第一个位置
                last = i;					// 不断更新最后一个位置
            }
            else if(nums[i] > target){
                break;// 数组是升序的，一旦超过 target 就可以停止了
            }
        }
        return {first,last};
    }
};
```

- 只用了两个整型变量，**O(1) 额外空间**。
- 第一个位置记录后就不再改动，最后一个位置持续覆盖。
- 遇到大于 `target` 的值直接跳出循环，**提前终止**。
- 返回的 `vector` 用初始化列表构建，简洁清晰。
- 未找到时 `first` 和 `last` 仍是 `-1`，符合题目要求。

时间复杂度 O(n)，但常数因子更小，空间也更省。

## 法2:库函数二分法

```c++
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        if (nums.empty()) return {-1, -1};
        int left = lower_bound(nums.begin(), nums.end(), target) - nums.begin();
        if (left == nums.size() || nums[left] != target) {
            return {-1, -1};   // 不存在
        }
        int right = upper_bound(nums.begin(), nums.end(), target) - nums.begin() - 1;
        return {left, right};
    }
};
```

## 法3:手写二分法

在排序数组中查找元素的第一个和最后一个位置 **相当与 二分查找 第一个大于且等于target的位置 和 最后一个小于且等于target的位置**

```c++
nums = [5,7,7,8,8,10], target = 8
left = 二分查找,找到第一个大于等于8的位置,即下标3
right = 二分查找,找到最后一个小于等于8的位置,即下标4
```

### 代码:

```c++
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        if (nums.empty()) return {-1, -1};   //为空,直接返回
        int first = findFirst(nums, target);
        if (first == -1) return {-1, -1};    // first不存在,直接返回
        int last = findLast(nums,target);
        return {first, last};
    }
private:
    int findFirst(vector<int>& nums,int target){
        int left = 0,right = nums.size()-1;
        while(left<=right){
            int mid = left + (right-left)/2;
            if(nums[mid]>=target){
                right = mid -1;
            }
            else/*if(nums[mid]<target)*/{
                left = mid + 1;
            }
        }

        // 循环结束时 left 指向第一个 >= target 的元素
        // 确保下标真实存在,并且当前元素==target,而不是>=
        if(left<nums.size()&&nums[left]==target){
            return left;
        }
        return -1;
    }
    int findLast(vector<int>& nums,int target){
        int left = 0,right = nums.size()-1;
        while(left<=right){
            int mid = left + (right-left)/2;
            if(nums[mid]<=target){
                left = mid + 1;
            }
            else/*if(nums[mid]>target)*/{
                right = mid - 1;
            }
        }

        // 循环结束时 right 指向最后一个 <= target 的元素
        // 确保下标真实存在,并且当前元素==target,而不是<=
        if (right >= 0 && nums[right] == target) return right;
        return -1;
    }
};

int main(){
    vector<int> nums = {1,1,3,3,5,6};
    // int target = 0;   // -1 -1
    // int target = 7;   // -1 -1
    // int target = 2;   // -1 -1
    // int target = 3;      // 2 3

    for(int i :result){
        std::cout<<i<<" ";
    }

    return 0;
}
```

### 分析:

**必须写以下判断**:

`if(left<nums.size()&&nums[left]==target)`

`if (right >= 0 && nums[right] == target) return right;`

因为:

> 举个例子：`nums = [1,1,3,5,6]`，`target = 2`
>
> **找第一个 `>= 2`：**
>
> - 二分结束，`left = 2`（指向 `3`）。
> - 检查：`left < nums.size()` ✅，但 `nums[left] == 3 ≠ 2` → 返回 `-1`。
>
> **找最后一个 `<= 2`：**
>
> - 二分结束，`right = 1`（指向 `1`）。
> - 检查：`right >= 1` ✅，但 `nums[right] == 1 ≠ 2` → 返回 `-1`。
>
> 如果没有这两层判断，代码会错误地返回 `2` 和 `1`，以为找到了 `target`。

```c++
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        if (nums.empty()) return {-1, -1};   //为空,直接返回

            }
```

# 33. 搜索旋转排序数组

- 数组、二分查找
- 时间复杂度为 `O(log n)`：法2、法3

## 法1:排序后计算偏移量

1. 将旋转排序数组 `nums` 复制并排序得到完全升序的数组 `sortnums`。
   利用旋转数组的第一个元素 `nums[0]` 在 `sortnums` 中的索引，计算出旋转的偏移量 `move`。
   对目标值 `target` 在 `sortnums` 中进行二分查找，得到它在完全升序数组中的索引 `result`（若不存在则返回 -1）。
   最后通过公式 `(result + move) % n` 将该索引映射回原旋转数组中的实际位置并返回。
2. **关键步骤**
   - 排序：`vector<int> sortnums = nums; sort(sortnums.begin(), sortnums.end());`
   - 计算偏移量：`int move = n - Binary_division(sortnums, nums[0]);`
     这里 `Binary_division` 是标准的二分查找，返回 `nums[0]` 在 `sortnums` 中的索引 `p0`，则 `move = n - p0`。
   - 查找目标：`int result = Binary_division(sortnums, target);`
   - 映射回原数组：若 `result != -1`，则 `result = (result + move) % n`。
3. **复杂度分析**
   - **时间复杂度**：`O(n log n)`。主要开销来自对 `nums` 的排序（`O(n log n)`），两次二分查找仅 `O(log n)`。
   - **空间复杂度**：`O(n)`。额外创建了排序数组 `sortnums`。

### 代码

```c++
#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>
using namespace std;

class Solution {
public:
    int search(vector<int>& nums, int target) {
        vector<int> sortnums = nums;
        std::sort(sortnums.begin(),sortnums.end());
        int n = nums.size();
        int move = n - Binary_division(sortnums,nums[0]);
        int result = Binary_division(sortnums,target);
        if(result!=-1){
            result = (result + move)%n;
        }
        return result;
    }
    int Binary_division(vector<int>& nums,int target){
        int left = 0;
        int right = nums.size()-1;
        while(left<=right){
            int mid = left + (right-left)/2;
            if(nums[mid] == target){
                return mid;
            }
            else if(nums[mid]>target){
                right = mid -1;
            }
            else{
                left = mid + 1;
            }
        }
        if (left < nums.size() && nums[left] == target) return left;
        return -1;
    }
};

int main(){
    vector<int> nums = {4,5,6,7,0,1,2};
    int target = 3;
    Solution s;
    std::cout<<s.search(nums,target)<<std::endl;
    return 0;
}
```

- **空间复杂度**：`O(n)`。额外创建了排序数组 `sortnums`。

## 法3:找到旋转点

```c++
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int n = nums.size();
        if (n == 0) return -1;
        
        // Step 1: 找旋转点（最小值索引）
        int left = 0, right = n - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > nums[right]) {
                left = mid + 1;      // 最小值在右侧
            } else {
                right = mid;         // 最小值在左侧或就是mid
            }
        }
        int pivot = left;   // 最小值索引
        
        // Step 2: 确定 target 在哪一段有序区间
        if (target >= nums[0]) {
            // target 在左段 [0, pivot-1]
            left = 0;
            right = (pivot == 0) ? n - 1 : pivot - 1;
        } else {
            // target 在右段 [pivot, n-1]
            left = pivot;
            right = n - 1;
        }
        
        // Step 3: 标准二分查找
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;
            else if (nums[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
};
```

# 153. 寻找旋转排序数组中的最小值

## 法1:“有序侧舍弃法”（或“双端最小值跟踪法”）

### 思路

**核心思想**：
利用旋转数组的局部有序特性，每次二分后，判断哪一半区间是严格升序的（即 `[left, mid]` 有序 或 `[mid, right]` 有序）。
由于最小值一定出现在无序的那一侧（或者当整个数组有序时在左端），我们可以：

1. 记录当前有序侧的最小值（即该侧的左端点或中点，因为升序区间的最小值就是左端点，但为了安全也记录中点）。
2. 舍弃有序侧，继续在无序侧进行二分查找。
3. 最后 `mina` 变量中保存的就是全局最小值。

**详细步骤**：

- 初始化 `mina = nums[0]`，`left = 0`，`right = n-1`。
- 当 `left <= right` 时循环：
  - 计算中点 `mid`。
  - 如果 `nums[left] <= nums[mid]`，说明左半区间 `[left, mid]` 是升序的：
    - 更新 `mina = min(mina, nums[left], nums[mid])`。
    - 舍弃左半部分，令 `left = mid + 1`（因为最小值一定在右半部分）。
  - 否则（即 `nums[left] > nums[mid]`），说明右半区间 `[mid, right]` 是升序的：
    - 更新 `mina = min(mina, nums[mid])`（此时 `nums[mid]` 是右半区间的最小值）。
    - 舍弃右半部分，令 `right = mid - 1`。
- 返回 `mina`。

**注意事项**：

- 当数组无旋转时，每次都会进入 `nums[left] <= nums[mid]` 分支，不断更新 `mina` 并右移 `left`，最终 `left` 会越界，但 `mina` 已记录所有值的最小值（即 `nums[0]`）。
- 该方法通过额外变量记录最小值，避免了最终区间收缩到一点时还需返回该点的麻烦。

### 代码1

```c++
class Solution {
public:
    int findMin(vector<int>& nums) {
        int left = 0;
        int right = nums.size()-1;
        int mina = nums[0];
        while(left<=right){
            int mid = left+(right-left)/2;
            if(nums[left]<=nums[mid]){
                //左侧有序 //4 5 6 7 0 1 2
                mina = min(mina,nums[mid]);
                mina = min(nums[left],mina);
                left = mid + 1;
            }
            else if(nums[mid]<nums[right]){
                //右侧有序//4 5 6 0 1 2 3
                mina = min(mina,nums[mid]);
                right = mid - 1;
            }
        }
        return mina;
    }
};
```

## 法2: “右边界二分法”（或“标准旋转数组最小值二分法”）

### 思路

**旋转排序数组的特点是**：**从某个点断开，左边段升序，右边段升序**，且**左边段的所有元素都大于右边段的所有元素**（除非没有旋转）。最小值就是右边段的第一个元素（或者无旋转时是第一个元素）。

比较 `nums[mid]` 与 `nums[right]`：

- 如果 `nums[mid] > nums[right]`，说明 `mid` 处于左边段（因为左边段的元素都大于右边段的元素），而右边段的最小值在 `mid` 的右侧，所以可以舍弃左半部分 `[left, mid]`，令 `left = mid + 1`。
- 否则 `nums[mid] <= nums[right]`，说明 `mid` 和 `right` 处于同一递增段（可能是右边段，也可能是整个数组无旋转），那么最小值一定在 `[left, mid]` 内（因为 `mid` 右侧都大于等于 `nums[mid]`，不会更小），所以令 `right = mid`（注意不是 `mid-1`，因为 `mid` 本身也可能是最小值，如`[4,5,6,0,1,2,3]`）。

这样每次循环都能保证最小值仍在新区间内，并且区间长度严格减少，最终 `left == right` 指向最小值。

### 代码

```c++
class Solution {
public:
    int findMin(vector<int>& nums) {
        int left = 0;
        int right = nums.size()-1;
        while(left < right){//当区间长度为 1 时（left == right）结束循环
            int mid = left+(right-left)/2;
            if(nums[mid]>nums[right]){//只要中间值大于最右侧值,则表明最小值在右侧
                //[1,2,3,4,5,6,0]//mid属于左边段
                //[2,3,4,5,6,0,1]
                //[3,4,5,6,0,1,2]
                
                //[2,3,4,5,1]
                //[2,1]
                left = mid + 1;
            }
            else{//中间值小于等于最右侧值,则最小值在左侧
                //[0,1,2,3,4,5,6]//数组无旋转
                //[4,5,6,0,1,2,3]//mid属于右边段
                //[5,6,0,1,2,3,4]
                //[6,0,1,2,3,4,5]
                right = mid;
            }
        }
        return nums[left];//当left==right时,只剩一个元素,该元素即为最小值或写成return[right]
    }
};
```

## 复杂度分析

| 方法    | 时间复杂度 | 空间复杂度 | 说明                                                |
| :------ | :--------- | :--------- | :-------------------------------------------------- |
| **法1** | O(log n)   | O(1)       | 每次循环将搜索区间减半，`mina` 变量仅占用常数空间。 |
| **法2** | O(log n)   | O(1)       | 经典二分查找，每次比较后区间长度减半，无额外数组。  |

- **法1** 的思路更直观：每次找到有序侧，记录该侧最小值，然后继续在无序侧查找。适合初学者理解“局部有序”概念。
- **法2** 更加简洁优雅：仅需比较 `nums[mid]` 与 `nums[right]`，无需额外变量，是 LeetCode 官方推荐解法。
