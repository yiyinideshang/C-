# 35. 搜索插入位置

- 数组、二分查找

## for循环查找法

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        for(int i = 0;i<nums.size();i++){
            if(nums[i]>=target){
                return i;
            }
        }
        return nums.size();
    }
};
```

### 复杂度分析

- **时间复杂度**：**O(n)**
  最坏情况下需要遍历整个数组（当 `target` 比所有元素都大，或数组中没有满足 `>= target` 的元素），循环执行 `n` 次。
- **空间复杂度**：**O(1)**
  只使用了固定的几个变量，没有额外空间。

## 标准模版库STL函数查找法

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        //标准库中的二分查找函数,返回第一个大于等于指定值的元素的迭代器,否则返回end()
        return std::lower_bound(nums.begin(),nums.end(),target)-nums.begin();
    }
};
```

### 复杂度分析

- **时间复杂度**：**O(log n)**
  C++ 标准要求 `lower_bound` 在随机访问迭代器（如 `vector` 的迭代器）上使用二分查找，比较次数约为 `log₂(n) + 1`。
- **空间复杂度**：**O(1)**
  内部实现是迭代，不分配额外空间。

## 二分查找法

### 左闭右闭[left,right]

- `right = nums.size() - 1`
- `left <= right`
- ` right = mid - 1; `

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;      // 闭区间
        while (left <= right) {           // 区间不为空，等号有意义
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;           // 去右半边 [mid+1, right]
            } else if (nums[mid] > target) {
                right = mid - 1;          // 去左半边 [left, mid-1]
            } else {
                return mid;               // 找到直接返回
            }
        }
        return left;                      // 没找到，返回插入位置
    }
};
```

### 左闭右开[left,right)

- `int right = nums.size();` 
- `left<right;`
- `right = mid;`

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();          // 开区间
        while (left < right) {            // 区间至少有一个元素
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;           // 前往右半边 [mid+1, right)
            } else if (nums[mid] > target) {
                right = mid;              // 前往左半边 [left, mid)
            } else {
                return mid;               // 找到直接返回
            }
        }
        return left;                      // 没找到，返回插入位置
    }
};
```

### 复杂度分析

- **时间复杂度**：**O(log n)**
  每次循环都将搜索区间缩小约一半，最多执行约 `log₂(n) + 1` 次循环。
- **空间复杂度**：**O(1)**
  只使用了几个整数变量。
