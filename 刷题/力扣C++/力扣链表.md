# 160. 相交链表

哈希表、链表、双指针

## 方法一：哈希表

- 首先遍历链表 *headA*，并将链表 *headA* 中的每个节点加入哈希集合中。
- 然后遍历链表*headB*，对于遍历到的每个节点，判断该节点是否在哈希集合中：
  - 如果当前节点不在哈希集合中，则继续遍历下一个节点；
  - 如果当前节点在哈希集合中，则后面的节点都在哈希集合中，即从当前节点开始的所有节点都在两个链表的相交部分，因此在链表 headB 中遍历到的第一个在哈希集合中的节点就是两个链表相交的节点，返回该节点。
- 如果链表 *headB* 中的所有节点都不在哈希集合中，则两个链表不相交，返回 null。

```c++
#include <iostream>
#include <unordered_map>
#include <unordered_set>
using namespace std;

//Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};
 
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        unordered_set<ListNode*> myset;

        ListNode* cur = headA;
        while(cur){
            myset.insert(cur);
            cur = cur->next;
        }

        cur = headB;
        while(cur){
            if(myset.find(cur) != myset.end()){
                //cur 是一个 ListNode* 类型的指针，指向相交节点
                return cur;//返回当前链表位置,之后程序通过cur->val得到当前链表对应的值
            }
            cur = cur->next;
        }
        return nullptr;
    }
};

//辅助函数:打印链表
void printList(ListNode *&head){
    ListNode* cur = head;
    while(cur){
        cout<<cur->val;
        cur = cur->next;
        if(cur)   cout<<"->";
    }
    cout<<endl;
}

// 构造相交链表测试用例
// 链表 A: 4 -> 1 ->               
// 链表 B: 5 -> 6 -> 1 ->   (公共部分 8 -> 4 -> 5)
// 返回 headA, headB, 以及预期的相交节点（值为8的节点）
void buildIntersectedLists(ListNode* &headA,ListNode* &headB,ListNode* &intersectNode){
    ListNode *common = new ListNode(8);
    common->next = new ListNode(4);
    common->next->next = new ListNode(5);

    // 链表 A：4 -> 1 -> common
    headA = new ListNode(4);
    headA->next = new ListNode(1);
    headA->next->next = common;

    // 链表 B：5 -> 6 -> 1 -> common
    headB = new ListNode(5);
    headB->next = new ListNode(6);
    headB->next->next = new ListNode(1);
    headB->next->next->next = common;

    // 记录相交节点（值为8的节点）
    intersectNode = common;
}

// 构造不相交链表测试用例
// 链表 A: 2 -> 6 -> 4
// 链表 B: 1 -> 5
void buildNonIntersectedLists(ListNode* &headA, ListNode* &headB) {
    headA = new ListNode(2);
    headA->next = new ListNode(6);
    headA->next->next = new ListNode(4);

    headB = new ListNode(1);
    headB->next = new ListNode(5);
}

// deleteLists 函数
void deleteLists(ListNode *headA, ListNode *headB) {
    unordered_set<ListNode*> deleted;
    
    ListNode *cur = headA;
    while (cur) {
        if (deleted.find(cur) == deleted.end()) {
            deleted.insert(cur);
            ListNode *temp = cur;
            cur = cur->next;
            delete temp;
        } else {
            break;
        }
    }
    
    cur = headB;
    while (cur) {
        if (deleted.find(cur) == deleted.end()) {
            deleted.insert(cur);
            ListNode *temp = cur;
            cur = cur->next;
            delete temp;
        } else {
            break;
        }
    }
}


int main(){
    Solution sol;
    // 测试用例 1：相交链表
    cout << "测试用例1：相交链表" << endl;
    ListNode *headA1, *headB1, *intersect1;
    buildIntersectedLists(headA1, headB1, intersect1);
    cout << "链表A: ";
    printList(headA1);
    cout << "链表B: ";
    printList(headB1);
    ListNode *result1 = sol.getIntersectionNode(headA1, headB1);
    if (result1) {
        cout << "相交节点值为: " << result1->val << endl;
        cout << "预期相交节点值为: " << intersect1->val << endl;
        if (result1 == intersect1) {
            cout << "测试通过~" << endl;
        } else {
            cout << "测试失败!" << endl;
        }
    } else {
        cout << "未找到相交节点（预期应相交）" << endl;
    }

    cout << "\n测试用例2：不相交链表" << endl;
    ListNode *headA2, *headB2;
    buildNonIntersectedLists(headA2, headB2);
    cout << "链表A: ";
    printList(headA2);
    cout << "链表B: ";
    printList(headB2);
    ListNode *result2 = sol.getIntersectionNode(headA2, headB2);
    if (result2) {
        cout << "相交节点值为: " << result2->val << "（预期应为nullptr）" << endl;
    } else {
        cout << "未找到相交节点（符合预期）" << endl;
    }
    
    cout << "\n测试用例3：其中一个链表为空" << endl;
    ListNode *headA3 = new ListNode(1);
    ListNode *headB3 = nullptr;
    ListNode *result3 = sol.getIntersectionNode(headA3, headB3);
    cout << "结果: " << (result3 ? "相交节点" : "nullptr（符合预期）") << endl;


    // 释放内存（测试用例1相交链表）
    deleteLists(headA1, headB1);
    // 释放测试用例2（不相交，独立释放）
    deleteLists(headA2, headB2);
    // 释放测试用例3
    delete headA3;
    return 0;
}
```

**复杂度分析**：

- 时间复杂度：O(m+n)，其中 m 和 n 是分别是链表 headA 和 headB 的长度。需要遍历两个链表各一次。

- 空间复杂度：O(m)，其中 m 是链表 headA 的长度。需要使用哈希集合存储链表 headA 中的全部节点。

## ==方法二：双指针==

使用双指针的方法，可以将空间复杂度降至 *O*(1)。

- 只有当链表 headA 和 headB 都不为空时，两个链表才可能相交。因此**首先**判断链表 headA 和 headB 是否为空，如果其中至少有一个链表为空，则两个链表一定不相交，返回 null。
- 当链表 headA 和 headB 都不为空时，创建两个指针 pA 和 pB，初始时分别指向两个链表的头节点 headA 和 headB，然后将两个指针依次遍历两个链表的每个节点。具体操作如下：
  - 每步操作需要同时更新指针 *pA* 和 *pB*。
  - 如果指针 *pA* 不为空，则将指针 *pA* 移到下一个节点；如果指针 *pB* 不为空，则将指针 *pB* 移到下一个节点。
  - 如果指针 *pA* 为空，则将指针 *pA* 移到链表 *headB* 的头节点；如果指针 *pB* 为空，则将指针 *pB* 移到链表 *headA* 的头节点。
  - **当指针 *pA* 和 *pB* 指向同一个节点或者都为空时，返回它们指向的节点或者 null。**

- 证明：

1. **当两个链表相交时**：

- 假设链表 *headA* 的不相交部分有 *a* 个节点，链表 *headB* 的不相交部分有 *b* 个节点，两个链表相交的部分有 *c* 个节点。
- 如果 *a* = *b*，则两个指针会同时到达两个链表相交的节点，此时，**返回相交的节点**。
- 如果 *a* != *b*，则遍历到两个链表相交的首节点时，此时有：
  - 指针  *pA*：*a*+*c*+*b*+1 = 相交首节点。
  - 指针  *pB*：*b+c+a*+1 = 相交首节点
  - 此时，**指针 *pA* 和 *pB* 指向同一个节点，返回它们指向的节点，即为相交的节点**

2. **当两个链表不相交时**：

- 如果 *a* = *b*，则两个指针会同时到达自己的尾节点，然后同时变为空值 null，此时指针 *pA* 和 *pB* 指向都为空时，**返回 null**。
- 如果 a != b，则当两个指针遍历完两个链表后，有：
  - 指针pA：a + b +1 = null
  - 指针pB：b + a + 1 = null
  - 两个指针会同时变成空值 null，此时，**返回 null**。

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        if(headA==nullptr || headB==nullptr){
            return nullptr;
        }
        ListNode* pA = headA,*pB = headB;
        while(pA != pB){
            pA = pA == nullptr ? headB : pA->next;
            pB = pB == nullptr ? headA : pB->next;
        }
        return pA;
    }
};
```

# 206. 反转链表

- 递归，链表

## 迭代法

- 假设链表为 1→2→3→∅，我们想要把它改成 ∅←1←2←3。
- 在遍历链表时确定一个前节点`prev`和一个当前节点的后节点`next = curt -> next;`
- 首先，让`prev`节点指向`nullptr`，表示反转前第一个节点将作为最后一个节点,它的后序节点为空。`ListNode *prev = nullptr;`
- 同时，让当前节点`curt`指向头结点。`ListNode *curt = head;`
- 然后，依次遍历当前节点`while(curt)`，①保存当前节点的后续节点`curt -> next`为 `next`，因为后序将改变当前节点的后续节点，所以先存起来，以便后序使用。`ListNode *next = curt->next;`
- ②将当前节点的后续节点`curt -> next`改为`prev`节点；`curt->next = prev;`
- ③将prev节点更新至当前节点，当前节点curt更新至next节点。`prev = curt;` `curt = next;`
- 然后，继续执行①②③，直到遍历到原链表的最后一个节点，即当前节点的后续节点为`nullptr`时，`next = nullptr;(curt = next) == nullptr`，终止，此时prev节点指向反转后的第一个节点。

class Solution

## 法一：使用数组和双指针

由于链表的随机访问效率为o(N)，不如数组的o(1)，所以考虑将链表的值复制到数组后使用双指针。

```c++
#include <iostream>
#include <vector>
using namespace std;

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
struct ListNode{
    int val;
    ListNode *next;
    ListNode() : val(0),next(nullptr) {}
    ListNode(int x) : val(x),next(nullptr){}
    ListNode(int x,ListNode *next) : val(x),next(next){}
};

class Solution {
public:
    bool isPalindrome(ListNode* head) {
        vector<int> myvector = {};
        while(head){
            myvector.push_back(head->val);
            head = head->next;
        }
        for(int i = 0,j = myvector.size()-1;i<j;++i,--j){
            if(myvector[i] != myvector[j]){
                return false;
            }
        }
        return true;
    }
};

ListNode* bulidList(const std::vector<int> &val){
    ListNode dummy(0);
    ListNode *tail = &dummy;
    for(int i : val){
        tail->next = new ListNode(i);
        tail = tail->next;
    }
    return dummy.next;
}

void printList(ListNode *&head){
    ListNode* curt = head;
    while(curt){
        std::cout<<curt->val;
        curt = curt->next;
        if(curt) std::cout<<" -> ";
    }
    std::cout<<std::endl;
}

void deletList(ListNode *&head){
    while(head){
        ListNode *temp = head;
        head = head->next;
        delete temp;
    }
    std::cout<<"链表已释放!"<<std::endl;
}

int main(){
    Solution s;
    vector<int> myvetor = {1,2,2,1,3};
    ListNode *head;
    head = bulidList(myvetor);
    std::cout<<s.isPalindrome(head)<<std::endl;
    printList(head);
    
    return 0;
}
```

## 法2：使用栈

- 栈是一种后进先出的数据结构，如果该链表是回文链表，则从前往后读一遍 和 从后往前 从栈中取出一遍的结果应该相同。如果相同则返回`true`，否则返回`false	`

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    bool isPalindrome(ListNode* head) {
        stack<int> stack;
        ListNode* p = head;
        while(p!=nullptr){
            stack.push(p->val);
            p = p->next;
        }
        p = head;
        while(p!=nullptr){
            if(p->val != stack.top()){
                return false;
            }
            stack.pop();
            p = p->next;
        }
        return true;
    }
};
```

## 法3：==快慢指针==

**思路**

避免使用 O(n) 额外空间的方法就是改变输入。

我们可以将链表的后半部分反转（修改链表结构），然后将前半部分和后半部分进行比较。比较完成后我们应该将链表恢复原样。虽然不需要恢复也能通过测试用例，但是使用该函数的人通常不希望链表结构被更改。

该方法虽然可以将空间复杂度降到 O(1)，但是在并发环境下，该方法也有缺点。在并发环境下，函数运行时需要锁定其他线程或进程对链表的访问，因为在函数执行过程中链表会被修改。

# 数组和链表

在 C++ 中，数组（连续内存，如 `std::vector`、原生数组）和链表（非连续节点，如 `std::list`、自定义 `ListNode*`）的选择取决于**访问模式**和**插入/删除频率**。以下是核心对比。

## 数组和链表优缺点一览

| 维度               | 数组 (`vector` / `array`)  | 链表 (`list` / `forward_list`)    |
| :----------------- | :------------------------- | :-------------------------------- |
| **内存连续性**     | ✅ 连续存储，缓存友好       | ❌ 节点分散，缓存不友好            |
| **随机访问**       | ✅ O(1) 直接通过下标        | ❌ O(n) 必须从头遍历               |
| **头部插入/删除**  | ❌ O(n) 需移动全部元素      | ✅ O(1) 只改指针                   |
| **中间插入/删除**  | ❌ O(n) 需移动后续元素      | ✅ O(1) 但查找位置需 O(n)          |
| **尾部插入/删除**  | ✅ 均摊 O(1) (`push_back`)  | ✅ O(1)                            |
| **内存额外开销**   | ✅ 几乎无（仅容量预留）     | ❌ 每个节点需存储指针（前驱/后继） |
| **遍历速度**       | ✅ 极快（预取命中率高）     | ❌ 较慢（指针跳转导致 cache miss） |
| **元素地址稳定性** | ❌ 扩容时整体搬移，地址失效 | ✅ 节点地址永不改变                |

## 什么时候用数组（`std::vector` / `std::array`）

- **需要频繁随机访问**（如 `v[100]`、二分查找）。
- **大部分操作为尾部追加或遍历**。
- **元素数量基本固定或可预分配**（避免扩容代价）。
- **对内存占用和缓存性能敏感**（如游戏开发、高频交易）。
- 典型场景：
  - 存储配置列表、日志缓冲区、像素数据
  - 实现栈、队列（基于 `vector` 效率更高）
  - 任何需要排序、二分搜索的数据集

## 什么时候用链表（`std::list` / 自定义链表）

- **频繁在中间或头部插入/删除**，且已有指向插入位置的迭代器（否则查找仍是 O(n)）。
- **元素非常大**，移动代价高于指针操作。
- **需要保证元素地址永远不变**（其他指针/引用不能失效）。
- **内存极度碎片化**，难以分配大块连续内存。
- 典型场景：
  - LRU 缓存（`std::list` + 哈希表）
  - 多线程任务队列（头部取、尾部加）
  - 实现图的邻接表（虽然 `vector` 也常用）
  - 音乐播放器的播放列表（频繁切歌、插歌）

## 关键陷阱提醒

1. **链表查找是 O(n)**：很多人以为链表插入 O(1) 就快，但如果你需要先找到插入位置（比如“在第 k 个元素后插入”），查找过程本身是 O(n)。
2. **现代 CPU 缓存效应**：遍历一个百万级元素的 `vector` 比遍历 `list` 快**数十倍**，因为数组的连续内存让 CPU 能预测并预取数据。
3. **C++ 标准库选择**：无特殊需求，**默认用 `std::vector`**。Bjarne Stroustrup 曾建议：除非有明确理由，否则就用 `vector`。

```
是否频繁随机访问或需要排序？
    ├── 是 → 用数组（vector）
    └── 否
         ↓
    是否频繁在头部/中间插入删除，且元素很大？
         ├── 是 → 考虑链表（list）
         └── 否 → 仍用数组（vector 大概率更快）
```

## 法1：哈希表

使用哈希表来存储所有已经访问过的节点。

遍历所有节点，每次遍历到一个节点时，判断该节点此前是否被访问过，如果该节点已经存在于哈希表中，则说明该链表是环形链表，直接返回`true`，否则就将该节点加入到哈希表中，继续遍历下一个节点，重复这一过程，直到遍历完整个链表。遍历完这个链表后则说明该链表不是环形链表，则返回`false`；

```c++
#include <iostream>
#include <vector>
#include <unordered_set>
using namespace std;

struct ListNode
{
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};

class Solution
{
public:
    bool hasCycle(ListNode *head)
    {
        unordered_set<ListNode*> myset;
        while(head){
            if(myset.find(head)!= myset.end())
            {
                return true;
            }
            myset.insert(head);
            head = head->next;
        }
        return false;
    }
};

ListNode* bulidList(const std::vector<int> &val){
    ListNode dummy(0);
    ListNode *tail = &dummy;
    for(int i : val){
        tail->next = new ListNode(i);
        tail = tail->next;
    }
    return dummy.next;
}

void printList(ListNode *head){//只改变形参指针的指向,对外部的真正head指针无影响
    while(head){
        std::cout<<head->val;
        head = head->next;
        if(head)
            std::cout<<"->";
    }
    std::cout<<std::endl;  
}

void deleteList(ListNode *&head){
    while (head){
        ListNode *temp = head;
        head = head->next;
        delete temp;
    }
    std::cout<<"已释放链表!"<<std::endl;

}

int main()
{
    vector<int> myvetor = {3,2,0,-4};
    ListNode *head = bulidList(myvetor);
    Solution s;
    std::cout<<s.hasCycle(head)<<std::endl;
    printList(head);
    deleteList(head);
    return 0;
}
```

**时间复杂度**：O(N)，其中 N 是链表中的节点数。最坏情况下我们需要遍历每个节点一次。

**空间复杂度**：O(N)，其中 N 是链表中的节点数。主要为哈希表的开销，最坏情况下我们需要将每个节点插入到哈希表中一次。

## 法2：快慢指针

「Floyd 判圈算法」（又称龟兔赛跑算法）

假想「乌龟」和「兔子」在链表上移动，「兔子」跑得快，「乌龟」跑得慢。当「乌龟」和「兔子」从链表上的同一个节点开始移动时，如果该链表中没有环，那么「兔子」将一直处于「乌龟」的前方；如果该链表中有环，那么「兔子」会先于「乌龟」进入环，并且一直在环内移动。等到「乌龟」进入环时，由于「兔子」的速度快，它一定会在某个时刻与乌龟相遇，即套了「乌龟」若干圈。

具体地，我们定义两个指针，一快一慢。慢指针每次只移动一步，而快指针每次移动两步。初始时，慢指针在位置 head，而快指针在位置 head.next。这样一来，如果在移动的过程中，快指针反过来追上慢指针，就说明该链表为环形链表。否则快指针将到达链表尾部，该链表不为环形链表。

````c++
class Solution
{
public:
    bool hasCycle(ListNode *head)
    {
        if(head == nullptr || head->next == nullptr){
            return false;
        }
        ListNode *slow = head;
        ListNode *fast = head->next;
        while(slow != fast){
            if(fast == nullptr || fast->next==nullptr){
                return false;
            }
            slow = slow->next;
            fast = fast->next->next;
        }
        return true;
    }
};
````

# 21. 合并两个有序链表

## 法1：递归

> **每次选出较小节点作头，递归处理剩余部分，遇空返回另一条。**

1. **终止条件：任一为空，返回另一**
   如果 `l1` 或 `l2` 为空，说明其中一个链表已经遍历完毕，此时无需继续比较，直接返回另一个非空链表即可（若两者都为空，返回的也是空）。
2. **确定当前头节点，递归构建后继**
   - **比较 `l1.val` 与 `l2.val`**：
     - 若 `l1.val` 较小，则 `l1` 应作为当前合并结果的头节点。随后，`l1.next` 应指向 **`l1` 剩余部分与 `l2` 合并函数递归后的结果**，这一子问题通过递归调用自身解决。
     - 否则，`l2` 作为当前头节点，并递归地让 `l2.next` 指向 **`l1` 与 `l2` 剩余部分的合并函数递归结果。**
       - 即递归的过程是节点值较小的链表指针的后移与另一个链表的节点值比较，递归的返回值是节点值较小的链表，并使用 当前链表的下一个结点来接受返回结果；
       - list1->next = fun(list1->next,list2);return list1;
3. **逐层返回，连接完整链表**
   每一层递归都会返回当前子问题的头节点，并挂接在上一层的 `next` 指针上。递归栈自底向上弹出时，链表节点被依次串联，最终在顶层得到完整有序的合并链表。

示例：

```
L1：红1,红2,红4
L2：灰1,灰3,灰4
输出:灰1-》红1-》红2-》灰3-》灰4-》红4
```

首先，

红1 不小于 灰1，首节点为灰1，它的下一个结点为 红1 和 灰3 的递归结果

红1 小于 灰3，则当前链表顺序为 灰1-》红1-》，红1的下一个结点为 红2 和 灰3 的递归结果

红2 小于 灰3，则当前链表顺序为 灰1-》红1-》红2，红2的下一个结点为 红4 和 灰3 的递归结果

红4 不小于 灰3，则当前链表顺序为 灰1-》红1-》红2-》灰3，灰3的下一个结点为 红4 和 灰4 的递归结果

红4 不小于 灰4，则当前链表的顺序为 灰1-》红1-》红2-》灰3-》灰4，灰4的下一个结点为 灰空 和红4的递归的结果

因为L2的链表为空了，所以此时返回当前的L1链表，即红4，则当前链表的顺序为 **灰1-》红1-》红2-》灰3-》灰4-》红4**

```c++
#include <iostream>
#include <vector>
using namespace std;

struct ListNode
{
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution
{
public:
    ListNode *mergeTwoLists(ListNode *list1, ListNode *list2)
    {
        if(list1 == nullptr){//1. 终止条件：若任一链表为空，返回另一链表。
            return list2;
        }
        else if(list2 == nullptr){
            return list1;
        }
        else if(list1->val < list2->val){ //2. 选取较小值节点作为当前头节点：
            list1->next = mergeTwoLists(list1->next,list2);//2.1 l1 为头，递归连接 l1->next 与 l2。
            return list1;//3. 返回当前选定的头节点，递归栈回溯时自动完成链表串联。
        }
        else{ //2. 选取较小值节点作为当前头节点：
            list2->next = mergeTwoLists(list1,list2->next);//2.2 l2 为头，递归连接 l1 与 l2->next。
            return list2;//3. 返回当前选定的头节点，递归栈回溯时自动完成链表串联。
        }
    }
};

ListNode *bulidList(std::vector<int>& vec)
{
    ListNode dummp(0);
    ListNode *tail = &dummp;
    for(int i :vec){
        tail->next = new ListNode(i);
        tail = tail->next;
    }
    return dummp.next;
}

        std::cout<<tail->val;
        tail = tail->next;
        if(tail)
            std::cout<<"->";
    }
    std::cout<<std::endl;
}

void deletList(ListNode *&head){
    while(head){
        ListNode *tail = head;
        head = head->next;
        delete tail;
    }
    std::cout<<"链表已释放!"<<std::endl;
}

int main()
{
    Solution s;
    std::vector<int> vec1 = {1, 2, 4};
    std::vector<int> vec2 = {1,3,4};
    ListNode *list1 = bulidList(vec1);
    ListNode *list2 = bulidList(vec2);
    ListNode *list3 = s.mergeTwoLists(list1, list2);
    
    printList(list3);
    deletList(list3);
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(n+m)，其中 n 和 m 分别为两个链表的长度。因为每次调用递归都会去掉 l1 或者 l2 的头节点（直到至少有一个链表为空），函数 mergeTwoList 至多只会递归调用每个节点一次。因此，时间复杂度取决于合并后的链表长度，即 O(n+m)。

- 空间复杂度：O(n+m)，其中 n 和 m 分别为两个链表的长度。递归调用 mergeTwoLists 函数时需要消耗栈空间，栈空间的大小取决于递归调用的深度。结束递归调用时 mergeTwoLists 函数最多调用 n+m 次，因此空间复杂度为 O(n+m)。

## 法2：迭代

1. **创建哨兵节点**
   我们预先构造一个值为 `-1` 的哑结点（`dummy`），它不存储有效数据，仅作为合并链表的临时头部。同时维护一个尾指针 `prev`，初始指向该哑结点，用于在遍历过程中动态连接下一个节点。
2. **逐对比较，择优接入**
   当两个链表均非空时，比较它们当前头节点的值：
   - **若 `list1` 的值较小**，则将 `prev` 的下一个节点指向 `list1`，随后 `list1` 指针后移一位。
   - **否则**，将 `prev` 的下一个节点指向 `list2`，随后 `list2` 指针后移一位。
3. **拼接剩余节点**
   退出循环时，至多有一个链表还有剩余节点。由于剩余节点本身已有序且值均大于已合并部分，直接将 `prev` 的下一个节点指向该非空链表的剩余部分即可。
4. **循环迭代，直至一表耗尽**
   重复上述比较与连接过程，直到其中一个链表遍历完毕（指针变为 `nullptr`）。
5. **返回结果链表头部**
   哨兵节点 `dummy` 的 `next` 指针始终指向合并后链表的第一个真实节点，因此最终返回 `dummy.next` 即为所求的有序链表头。

```c++
#include <iostream>
#include <vector>
using namespace std;

struct ListNode
{
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution
{
public:
    ListNode *mergeTwoLists(ListNode *list1, ListNode *list2)
    {
        // 哨兵头 + 尾插法：每次取两链表当前节点值较小者接入尾部，最后拼接剩余链表。
        ListNode prevhead = ListNode(-1);//哨兵节点prevhead
        ListNode *prev = &prevhead;//尾指针prev动态构建结果链表
        while(list1 != nullptr && list2 != nullptr){
            if(list1->val < list2->val){//选择较小节点接入prev->next,对应节点的链表指针后移
                prev->next = list1;
                list1 = list1->next;
            }
            else{
                prev->next = list2;
                list2 = list2->next;
            }
            prev = prev->next;//尾指针prev同步后移
        }
        prev->next = list1==nullptr?list2:list1;//拼接剩余部分
        return prevhead.next;
    }
};

ListNode *bulidList(std::vector<int>& vec)
{
    ListNode dummp(0);
    ListNode *tail = &dummp;
    for(int i :vec){
        tail->next = new ListNode(i);
        tail = tail->next;
    }
    return dummp.next;
}

void printList(ListNode *& head){
    ListNode *tail = head;
    while(tail){
        std::cout<<tail->val;
        tail = tail->next;
        if(tail)
            std::cout<<"->";
    }
    std::cout<<std::endl;
}

void deletList(ListNode *&head){
    while(head){
        ListNode *tail = head;
        head = head->next;
        delete tail;
    }
    std::cout<<"链表已释放!"<<std::endl;
}

int main()
{
    Solution s;
    std::vector<int> vec1 = {1, 2, 4};
    std::vector<int> vec2 = {1,3,4};
    ListNode *list1 = bulidList(vec1);
    ListNode *list2 = bulidList(vec2);
    ListNode *list3 = s.mergeTwoLists(list1, list2);
    
    printList(list3);
    deletList(list3);
    return 0;
}
```

### 复杂度分析

- 时间复杂度：O(n+m)，其中 n 和 m 分别为两个链表的长度。因为每次循环迭代中，l1 和 l2 只有一个元素会被放进合并链表中， 因此 while 循环的次数不会超过两个链表的长度之和。所有其他操作的时间复杂度都是常数级别的，因此总的时间复杂度为 O(n+m)。

- 空间复杂度：O(1)。我们只需要常数的空间存放若干变量。

# 2. 两数相加

- 使用虚拟头结点和一个动态尾节点指针，方便构造

- 用carry表示上次相加结果后的进制
- 每次遍历至少有一个条件满足：
  - **l1不为空** 或 
  - **l2不为空** 或
  -  **carry不为空**(表示有进制残留)
- 每次遍历将sum置为0，并进行以下判断：
  - 如果l1不为空，将sum加上当前l1链表的val值，并让l1链表后移
  - 如果l2不为空，将sum加上当前l2链表的val值，并让l2链表后移
  - 如果进制不为0，将sum++（当前链表元素值之和 + 上次得到的进制）
- 然后判断这次相加后的结果sum是否超过10，即是否有进制：
  - 如果`sum / 10`,则说明本次应该存储进制,让`carry=1`;
  - 否则`carry=0`
- 每次存储的结果为：`sum % 10`，并，并让tail链表后移
- 最终返回虚拟头结点的next节点即可。

            else

# 19. 删除链表的倒数第N个节点

## 法1：两趟扫描法

#### 核心思路

1. **第一趟扫描：计算链表长度**
   遍历整个链表，统计节点总数 `len`。
2. **计算目标位置**
   倒数第 `n` 个节点，对应正数第 `target = len - n` 个节点（从 `0` 开始计数，即头节点为第 `0` 个）。
3. **特殊处理头节点**
   若 `target == 0`，说明待删除的是头节点。此时直接返回 `head->next` 作为新头节点，并释放原头节点内存。
4. **第二趟扫描：定位前驱节点并删除**
   - 从头节点开始，向后移动 `target - 1` 步，找到待删除节点的**直接前驱** `prev`。**注意：这里i<target-1是重点**
     - 当链表为1->2->3->4->5,并删除倒数第二个节点时,n=2,len=5,target=3,i<3-1为条件,i最终停在2,执行完循环体`prev = prev->next`后最终停留在目标节点的前驱节点上,也就是3这个位置
   - 待删除节点为 `prev->next`，使用del指针来接受这个待删除节点。
   - 修改 `prev->next = prev->next->next`，将目标节点从链表中断开。
   - 释放目标节点的内存，即`delete del`。
5. **返回头节点**
   返回原头节点（若未删除头节点）或新头节点（若删除了头节点）。

------

#### 复杂度分析

- **时间复杂度**：`O(L)`，其中 `L` 为链表长度。两次独立遍历，总体仍为线性时间。
- **空间复杂度**：`O(1)`，仅使用了常数个额外指针变量。

#### 一句话总结

> **先数总数，再定位前驱；若删头结点，直接返下一位。**

## 法2：快慢指针法

#### 核心思路

利用两个指针 `fast` 和 `slow`，让它们之间始终保持 **固定的间隔**，当 `fast` 到达链表末尾时，`slow` 恰好指向待删除节点的**前驱**。

**关键设计：**

- 引入**哨兵节点（dummy）**，其 `next` 指向原链表头。这样做的好处是**统一处理删除头节点的情况**，无需特殊分支判断。
- 初始时 `fast` 和 `slow` 均指向哨兵节点。
- `fast` 先向前移动 **`n + 1`** 步，使得 `fast` 与 `slow` 之间相隔 `n` 个节点。
- 随后 `fast` 和 `slow` 同步后移，直到 `fast` 指向 `nullptr`。
- 此时 `slow` 正好指向待删除节点的**直接前驱**，执行常规删除即可。

------

#### 图解示意（以 `head = [1,2,3,4,5]`，`n = 2` 为例）

**初始化：**

```
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
  ^
fast, slow
```

**第一步：`fast` 先走 `n+1 = 3` 步**

```
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
  ^                ^
 slow             fast
```

**第二步：`fast` 和 `slow` 同步移动，直到 `fast` 为 `null`**

```
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
                   ^              ^
                   slow          fast（null）
```

**第三步：`slow` 指向节点 `3`，正是待删除节点 `4` 的前驱。**
执行 `slow->next = slow->next->next`，链表变为 `1->2->3->5`。

让指针fast节点 与 指针slow节点 相距n+1个节点，这样当slow到达链表末尾时，fast正好到达要删除节点的前驱节点的位置。

```c++
class Solution
{
public:
    ListNode *removeNthFromEnd(ListNode *head, int n)
    {
        ListNode dummp(-1);
        dummp.next = head;
        ListNode *prev = &dummp;
        ListNode *tail = &dummp;

        //tail指针比prev先走n+1个节点
        for(int i = 0;i<=n;++i){
            tail = tail->next;
        }

        //同时移动这两个指针,直到tail指针到达链表末尾的nullptr节点,此时prev指针指向正好是待删除节点的前驱节点
        while(tail != nullptr){
            prev = prev->next;
            tail = tail->next;
        }

        //删除待删除节点
        ListNode *temp = prev->next;
        prev->next = prev->next->next;
        delete temp;

        //返回真正的头结点
        return dummp.next;
    }
};
```

# 24. 两两交换链表中的节点

## 法1：迭代法-哨兵节点

```c++
#include <iostream>
#include <vector>
using namespace std;

struct ListNode
{
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        // 空链表或只有一个节点，直接返回
        if(!head || !head->next)
            return head;

        ListNode dummy(-1);
        dummy.next = head;
        ListNode* prev = &dummy; // 指向待交换节点对的前驱

        while(prev->next && prev->next->next){
            ListNode *first = prev->next;   // 每对的第一个节点
            ListNode *second = first->next; // 每对的第二个节点  

            // 执行交换和更新
            first->next = second->next;
            second->next = first;
            prev->next = second;

            // 移动 prev 到下一对的前驱（即当前的 first）
            prev = first;
        }
        return dummy.next;
    }
};

ListNode* bulidList(std::vector<int>& val){
    ListNode dummp(0);
    ListNode *tail = &dummp;
    for(int i : val){
        tail->next = new ListNode(i);
        tail = tail->next;
    }
    return dummp.next;
}

void printList(ListNode* head){
    while(head){
        std::cout<<head->val;
        head = head->next;
        if(head)
            std::cout<<"->";
    }
    std::cout<<std::endl;
}

void deleList(ListNode *&head){
    while(head){
        ListNode *temp = head;
        head = head->next;
        delete temp;
    }
    std::cout<<"链表已释放!";
}

int main(){
    std::vector<int> vec = {1,2,3,4};
    Solution s;
    ListNode* head = bulidList(vec);
    head = s.swapPairs(head);
    printList(head);
    deleList(head);
    return 0;
}
```

引入一个**哨兵节点（dummy）**，将其 `next` 指向原链表头`dummy(-1);dummy.next=head`。维护一个指针 `prev`，始终指向**待交换节点对的前驱节点**`ListNode* prev=&dummy;prev=second`。在每一轮循环中，交换 `prev` 之后的两个节点，然后移动 `prev` 到下一对的前驱位置，直至剩余节点不足两个。

1. **边界处理**
   若链表为空或只有一个节点，直接返回原链表头 `head`边界处理：若链表为空或只有一个节点，直接返回原链表头 `head`。

2. **初始化哨兵节点**
   创建哨兵节点 `dummy(-1)`，令 `dummy.next = head`。
   维护指针 `prev = &dummy`，初始时指向哨兵节点。

3. **循环交换相邻节点对**
   循环条件：`prev->next` 和 `prev->next->next` 均非空（即至少还有两个节点可交换）。
   每一轮执行以下操作：

   - **标记当前对的两个节点**

   ```c++
   ListNode* first = prev->next;      // 每对的第一个节点
   ListNode* second = first->next;    // 每对的第二个节点
   ```

   - **执行三步指针重连**

   ```c++
   first->next = second->next;   // 步骤①：first 指向 second的后继结点
   second->next = first;         // 步骤②：second 指向 first
   prev->next = second;          // 步骤③：前驱节点prev 指向 新的队首 second
   ```

   - **移动 `prev` 至下一对的前驱**

   ```c++
   prev = first;   // 此时 first 正好变成下一对的前驱节点
   ```

4. **返回新头节点**
   循环结束后，返回 `dummy.next`，它始终指向交换后的链表头节点。

### 复杂度分析

- **时间复杂度**：`O(n)`，其中 `n` 为链表节点数。每个节点仅被访问常数次。
- **空间复杂度**：`O(1)`，仅使用有限的额外指针变量。

### 确保dummy的next节点是更改后的链表的头结点?

**原因**:

- 首先`dummy`节点的`next`指针指向原链表的头结点`dummy.next=head;`
- 让`prev`指向的是`dummy`节点`ListNode* prev=&dummy;`
- 后续第一次通过`prev->next=second`，让`dummy`节点的`next`指针 直接指向 交换后的链表的头结点。
  - 因为： `prev->next == (*prev).next == dummy.next;`
- 在整个函数生命周期中，**`dummy` 节点自身的 `next` 指针只被修改了一次**，就是在第一轮循环的 `prev->next = second` 时。**因为**:
  - 后续将`prev`指向了新的前驱节点`prev = first;`，不再改变`dummy`节点的`next`指针，故**在整个函数生命周期中，`dummy` 节点自身的 `next` 指针只被修改了一次。**

# 25. K 个一组翻转链表

## 解题思路:

1. **计算链表长度，确定组数**

```c++
int count = 0;
ListNode *tail = head;
while(tail){
    count++;
    tail = tail->next;
}
int group_count = count / k;
```

- 先遍历一次链表，获取总节点数 `count`。
- 计算完整分组的数量 `group_count = count / k`，用于控制翻转的组数。

**2. 分组翻转并连接**

```cpp

ListNode *new_head = nullptr;
ListNode* prev_group_tail = nullptr; // 上一组翻转后的尾节点
```

- `curt` 作为遍历指针，始终指向当前处理的节点。
- `new_head` 用于记录第一组翻转后的新链表头。
- `prev_group_tail` 保存**上一组翻转后的尾节点**，用于将前一组与当前组正确连接。

3. 对每一组进行 k 个节点的翻转

```c++
while(curt && i<group_count){
    ListNode *prev = nullptr;
    ListNode* cur_group_tail = curt; // 翻转前记住当前组第一个节点（翻转后变尾节点）
    j = 0;
    while(curt && j<k){
        ListNode *next = curt->next;
        curt->next = prev;
        prev = curt;
        curt = next;
        ++j;
    }
    // 翻转完成后，prev 是当前组的头节点，cur_group_tail 是尾节点
}
```

- 标准的三指针链表翻转逻辑，将当前组的 `k` 个节点顺序反转。
- `cur_group_tail` 在翻转前记录了组首节点，翻转后它变成组尾节点，用于后续连接。

4. 处理组间连接

```cpp
if(prev_group_tail){
    prev_group_tail->next = prev;    // 上一组尾节点 → 当前组新头节点
}
else{
    new_head = prev;                 // 第一组翻转后，记录整个链表的新头
}
cur_group_tail->next = curt;         // 当前组尾节点 → 下一组剩余节点（或 nullptr）
prev_group_tail = cur_group_tail;    // 更新 prev_group_tail 为当前组的尾节点
```

- **关键操作**：
  - 如果 `prev_group_tail` 不为空，说明不是第一组，需要把上一组的尾部连接到当前组的头部 `prev`。
  - 如果是第一组，则记录 `new_head`，作为最终返回的头指针。
  - 将当前组的尾部 `cur_group_tail` 指向下一组还未处理的第一个节点 `curt`（此时 `curt` 已走到下一组的起始位置）。
  - 更新 `prev_group_tail` 为当前组的尾节点，供下一轮使用。

5. 返回结果

```cpp
return new_head;
```

- 由于题目保证至少有一组翻转（`k <= n`），`new_head` 一定非空，直接返回即可。

# 138. 随机链表的复制

- 哈希表、链表

## 法1:回溯+哈希表

构造一个哈希表,在这个哈希表 `unordered_map<Node*, Node*> cachedNode` 中：

- **键 (Key)**：是 **原链表中的节点指针** (`head`)。
- **值 (Value)**：是 **新链表中对应的拷贝节点指针** (`Newhead`)。

**核心思想**：**回溯（深度优先搜索）+ 哈希表缓存**。利用递归沿着 `next` 指针遍历原链表，在“递”的过程中创建所有新节点并建立原节点到新节点的映射，在“归”的过程中同时完成 `next` 和 `random` 指针的赋值。

```c++
class Solution {
public:
    std::unordered_map<Node*,Node*> hasNode; // ① 全局哈希表：原节点 → 拷贝新节点
    Node* copyRandomList(Node* head) {
        if(!head)
            return nullptr; // ② 递归基：空节点直接返回空
        if(!hasNode.count(head)){// ③ 检查缓存：若当前原节点尚未被拷贝
            Node* Newhead = new Node(head->val);// ④ 创建新节点，仅复制 val
            hasNode[head] = Newhead; // ⑤ 立即存入哈希表，防止后续 random 递归重复创建
            Newhead->next = copyRandomList(head->next); // ⑥ 递归处理 next 链，返回下层已装配好的子链表头
            Newhead->random = copyRandomList(head->random);// ⑦ 递归处理 random 指针（此时哈希表已完备，直接命中）
        }
        return hasNode[head];// ⑧ 返回当前原节点对应的拷贝节点
    }
};
```

### 执行流程详解（以链表 `7 → 13 → 11 → 10 → 1 → null` 为例）

#### 阶段一：递归“递”过程 —— 沿 `next` 链深入并建立所有新节点

1. 从 `head = 7` 开始，`hasNode` 为空，创建 `Newhead(7)`，存入 `hasNode[7]`。
2. 调用 `Newhead->next = copyRandomList(13)`，进入下一层。
3. 同样逻辑依次处理 `13`、`11`、`10`、`1`，每层都创建对应新节点并立即放入哈希表。
4. 当 `head = 1` 调用 `copyRandomList(head->next)` 时，`head->next` 为 `null`，触发递归基返回 `nullptr`。

**注意！**此时：哈希表 `hasNode` 中已存在所有 5 个原节点到新节点的映射，但新节点之间的 `next` 和 `random` 尚未完全连接。

#### 阶段二：递归“归”过程 —— 从最底层逐层返回并装配关系

1. **最底层（`head = 1`）**：
   - `Newhead->next` 被赋值为 `nullptr`。
   - 紧接着执行 `Newhead->random = copyRandomList(head->random)`。
     - 假设原节点 `1` 的 `random` 指向 `7`（链表首节点）。
     - 由于 `7` 早已存在于 `hasNode` 中，`copyRandomList(7)` 会立即命中缓存，直接返回 `hasNode[7]`（即新链表头节点）。
   - 返回当前新节点 `hasNode[1]` 给上一层。
2. **上一层（`head = 10`）**：
   - `Newhead->next` 被赋值为上一层返回的 `hasNode[1]`。至此，`10` 和 `1` 的拷贝节点通过 `next` 串联。
   - 再执行 `Newhead->random = copyRandomList(head->random)`，同样直接从哈希表中取对应拷贝节点完成指向。
   - 返回当前新节点 `hasNode[10]`。
3. **逐层向上**：`11`、`13`、`7` 依次完成 `next` 串联和 `random` 补全。
   - 当最外层 `head = 7` 的 `Newhead->next` 语句执行完毕时，其 `next` 已正确指向 `13` 的拷贝，且 `random` 也已就位。
   - 整个深拷贝链表已完全构建完毕。

#### 阶段三：返回结果

- 最外层函数最终 `return hasNode[head]`，即返回新链表的头节点指针。

### 算法复杂度分析

- **时间复杂度**：`O(n)`，其中 `n` 为原链表节点数。
  每个节点仅被递归访问一次（通过 `next` 或 `random` 触发），且哈希表操作 `count` 和 `[]` 均为平均 `O(1)`。
- **空间复杂度**：`O(n)`。
  - 哈希表 `hasNode` 存储 `n` 个键值对。
  - 递归调用栈最深为链表长度 `n`（最坏情况，如单链表无分支）。

### 思路核心要点（一句话总结）

> **利用哈希表在递归深入前建立节点映射，确保在递归返回过程中同时装配 `next` 和 `random` 时，所有需要的拷贝节点均已存在且可直接获取，从而一次递归完成整个深拷贝。**

## 选择排序:

```c++
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;

        ListNode dummyNew(0);          // 新链表的哨兵头
        ListNode* tailNew = &dummyNew; // 新链表尾指针

        ListNode dummyOld(0);          // 原链表的哨兵头（方便删除操作）
        dummyOld.next = head;

        while (dummyOld.next) {
            // 寻找最小值节点的前驱
            ListNode* prev = &dummyOld;
            ListNode* minPrev = &dummyOld;
            int minVal = INT_MAX;

            while (prev->next) {
                if (prev->next->val < minVal) {
                    minVal = prev->next->val;
                    minPrev = prev;
                }
                prev = prev->next;
            }

            // 摘下最小值节点
            ListNode* minNode = minPrev->next;
            minPrev->next = minNode->next;// 将 minNode 从原链表中断开
            minNode->next = nullptr;   // 清理 minNode 的后继指针

            // 接到新链表尾部
            tailNew->next = minNode;
            tailNew = minNode;
        }

        return dummyNew.next;
    }
};
```

| **时间复杂度** | **O(n²)** — 每次找最小值都要遍历剩余链表                     |
| -------------- | ------------------------------------------------------------ |
| **空间复杂度** | **O(1)** — 只使用了固定数量的指针，没有额外数据结构          |
| **优点**       | 思路简单，不移动大量数据，只是修改指针；空间消耗极小         |
| **缺点**       | 效率较低，对于长链表（如力扣 148 中最大 5×10⁴ 个节点）会超时 |
| **适用场景**   | 学习链表指针操作的绝佳练习；数据量很小时的简单排序           |

### 📖 实例演示：链表 `4 -> 2 -> 1 -> 3`

我们跟踪每一次外层循环后的链表状态。

**初始状态：**

- 原链表 (`dummyOld.next`): `4 -> 2 -> 1 -> 3`
- 新链表 (`dummyNew.next`): 空

------

**第 1 轮外层循环：**

1. 扫描原链表，找到最小值节点为 `1`，其前驱是节点 `2`（`minPrev` 指向节点 `2`）。
2. 摘下节点 `1`：
   - `minPrev->next = minNode->next` → 节点 `2` 的 `next` 从 `1` 变成 `3`。
   - 原链表变为：`4 -> 2 -> 3`。
3. 将节点 `1` 接到新链表尾部：
   - 新链表变为：`1`。

**第 1 轮结束后：**

- 原链表：`4 -> 2 -> 3`
- 新链表：`1`

------

**第 2 轮外层循环：**

1. 扫描原链表 `4 -> 2 -> 3`，最小值节点为 `2`，其前驱是节点 `4`。
2. 摘下节点 `2`：
   - 节点 `4` 的 `next` 改为指向 `3`。
   - 原链表变为：`4 -> 3`。
3. 将节点 `2` 接到新链表尾部：
   - 新链表变为：`1 -> 2`。

**第 2 轮结束后：**

- 原链表：`4 -> 3`
- 新链表：`1 -> 2`

------

**第 3 轮外层循环：**

1. 扫描原链表 `4 -> 3`，最小值节点为 `3`，其前驱是节点 `4`。
2. 摘下节点 `3`：
   - 节点 `4` 的 `next` 改为 `nullptr`。
   - 原链表变为：`4`。
3. 将节点 `3` 接到新链表尾部：
   - 新链表变为：`1 -> 2 -> 3`。

**第 3 轮结束后：**

- 原链表：`4`
- 新链表：`1 -> 2 -> 3`

------

**第 4 轮外层循环：**

1. 扫描原链表 `4`，最小值节点为 `4`，其前驱是哑节点 `dummyOld`。
2. 摘下节点 `4`：
   - `dummyOld.next` 改为 `nullptr`。
   - 原链表变为空。
3. 将节点 `4` 接到新链表尾部：
   - 新链表变为：`1 -> 2 -> 3 -> 4`。

**第 4 轮结束后：**

- 原链表：空
- 新链表：`1 -> 2 -> 3 -> 4`

循环结束，返回新链表的头节点 `1`。

### 💡 小结

> 这段代码是**选择排序思想在单向链表上的标准实现**。它通过引入两个哑节点，巧妙地将“在原链表上查找最小值”和“在新链表尾部追加节点”这两个步骤统一了起来，逻辑清晰且完全符合 O(1) 空间复杂度的要求。对于理解链表的删除、插入操作非常有帮助。不过由于其 O(n²) 的时间复杂度，无法通过力扣 148 题的时间限制，更适合作为学习材料或小数据场景使用。

## 暴力解法：使用`vector` + `sort`

```c++
class Solution
{
public:
    ListNode *sortList(ListNode *head)
    {
        if(!head)
            return nullptr;
        std::vector<int> vals; // 额外开辟了大小为 n 的数组
        ListNode* cur = head;   
        while(cur){
            vals.push_back(cur->val);
            cur = cur->next;
        }
        std::sort(vals.begin(),vals.end());
        cur = head;
        for(int val:vals){
            cur->val = val;
            cur = cur->next;
        }
        return head;
    }
};
```

- **空间复杂度为什么是 O(n)？**
  因为创建了一个 `vector`，它存储了 **n 个 `int`**。无论原始链表是否被修改，这个容器占据的堆内存与链表长度 n 成正比，因此空间复杂度为 O(n)。
- **链表的 `next` 指针有没有变？**
  **完全没有变。**
  整个过程只通过 `cur->val = val` 修改了节点内部存储的 `int` 值，所有节点的 `next` 指针保持了原有的连接关系。
  结果链表**在物理连接上仍然是原链表**，只是节点的值被重新排了序。

> 这可以理解为一种 **“欺骗性排序”** —— 从外部看链表是有序的，但内部连接顺序与排序结果无关。只要题目不检查节点地址的排列，仅验证遍历顺序，这种方法就能通过。

## 自顶向下归并排序

![](D:\Typora\typora_work\刷题\力扣C++\自顶向下归并排序.png)

归并排序基于分治算法。最容易想到的实现方式是自顶向下的递归实现，考虑到递归调用的栈空间，自顶向下归并排序的空间复杂度是 O(logn)。如果要达到 O(1) 的空间复杂度，则需要使用自底向上的实现方式。

1. 找到链表的中点，以中点为分界，将链表拆分成两个子链表。寻找链表的中点可以使用快慢指针的做法，**快指针每次移动 2 步，慢指针每次移动 1 步，当快指针到达链表末尾时，慢指针指向的链表节点即为链表的中点。**

2. 对两个子链表分别排序。

3. 将两个排序后的子链表合并，得到完整的排序后的链表。可以使用==「**21. 合并两个有序链表**」==的做法，将两个有序的子链表进行合并。

上述过程可以通过递归实现。递归的终止条件是链表的节点个数小于或等于 1，即当链表为空或者链表只包含 1 个节点时，不需要对链表进行拆分和排序。

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}    
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution
{
public:
    ListNode *sortList(ListNode *head)
    {
        //递归终止条件:空链表或单节点链表已是有序的
        if(!head || !head->next)
            return head;

        //1.分割:使用快慢指针找到中点,并将链表从中断开
        ListNode* mid = findMiddle(head);
        ListNode* rightHead = mid->next;//右半部分的头结点是从中间节点的下一个位置开始的
        mid->next = nullptr;//断开链表,形成两个独立的链表
        ListNode* leftHead = head;//左半部分的头结点

        //2. 递归:分别对左右两个子链表进行该函数,让左右子链表继续分割直到只剩单链表时返回该单链表的信息,
        //由left 和 right接受
        ListNode *left = sortList(leftHead);
        ListNode *right = sortList(rightHead);

        //3.合并:最后一次递归结果返回单链表信息后,由倒数第二次递归接受,然后对这两个链表进行合并排序
        // 3->2->4
        //leftHead = 3->2;rightHead = 4;left = sort(3->2);right = sort(4)=4;
        //sort(3->2) : leftHead = 3;rightHead = 2;left = 3,right = 2;return merge(3,2);
        // 2->3 left = sort(3->2)的返回值为  2->3
        // left = 2->3;right = 4;merge(2->3,4);return 2->3->4;
        return merge(left,right);
    }
private:
    ListNode* findMiddle(ListNode* head){
        //辅助函数:查找链表的中间节点(或正中间的前一个节点)
        ListNode* slow = head, *fast = head->next;
        //当快指针到达末尾时,慢指针正好位于中间位置
        // (链表长度是偶数时,快指针到达的是最后一个节点位置,此时慢指针到达的是正中间的前一个节点)
        // (链表长度是奇数时,快指针到达的是最后一个节点的next即nullptr位置,此时慢指针到达是中间节点)
        while(fast && fast->next){
            slow = slow->next;
            fast = fast->next->next;
        }
        return slow;//返回慢指针的位置,得到链表的中间节点
    }
    ListNode *merge(ListNode* l1,ListNode* l2){
        ListNode dummp(-1);
        ListNode *tail = &dummp;
        while(l1 && l2){
            if(l1->val < l2->val){
                tail->next = l1;
                l1 = l1->next;
            }
            else{
                tail->next = l2;
                l2 = l2->next;
            }
            tail = tail->next;
        }
        //将剩余部分直接接上
        tail->next = l1?l1:l2;
        return dummp.next;
    }
};
```

- 时间复杂度：假设每个链表的最长长度是 n。在第一次合并后，ans 的长度为 n；第二次合并后，ans 的长度为 2×n，第 i 次合并后，ans 的长度为 i×n。第 i 次合并的时间代价是 O(n+(i−1)×n)=O(i×n)，那么总的时间代价为*O*(∑*i*=1*k*(*i*×*n*))=*O*(2(1+*k*)⋅*k*×*n*)=*O*(*k*2*n*)，故渐进时间复杂度为 *O*(*k*2*n*)。

- 空间复杂度：没有用到与 *k* 和 *n* 规模相关的辅助空间，故渐进空间复杂度为 *O*(1)。

#include <iostream>
#include <list>
#include <unordered_map>

// 您的LRUCache对象将如下所示实例化和调用：
// LRUCache* obj = new LRUCache(capacity);
// int param_1 = obj->get(key);
// obj->put(key,value);
class LRUCache {
public:
    LRUCache(int capacity):capacity(capacity) {
        
    }
    
    int get(int key) {
        auto umap_iter = key_to_iter.find(key);
        if(umap_iter == key_to_iter.end()){//没有这本书
            return -1;
        }
        auto list_iter = umap_iter->second;// 有这本书
        //把这本书(list_iter) 从书堆里(cache_list)中抽出来,放到最上面(cache_list.begin())
        //将链表 x 中迭代器 i 指向的元素移动到当前链表的 position 位置。
        cache_list.splice(cache_list.begin(),cache_list,list_iter);
        return list_iter->second;// 返回这本书的 value
    }
    
    void put(int key, int value) {
        auto umap_iter = key_to_iter.find(key);
        if(umap_iter != key_to_iter.end()){//有这本书
            auto list_iter = umap_iter->second;
            list_iter->second = value;//更新value值
            //把这本书(list_iter) 从书堆里(cache_list)中抽出来,放到最上面(cache_list.begin())
            cache_list.splice(cache_list.begin(),cache_list,list_iter);
            return ;
        }
        //新书,放到最上面(emplace_front),存入哈希表中
        cache_list.emplace_front(key,value);
        key_to_iter[key] = cache_list.begin();
        //书太多了,超过capacity容量
        if(key_to_iter.size() > capacity){
            //去掉最后一本书,删除对应的哈希表
            //.back返回最后一个元素的引用;首先通过cache_list.back()方法得到最后一个节点,
            //再使用.first方法,得到该节点的key值
            //最后从哈希表中删除该key,随之即删除了该key->双链表的链表节点迭代器
            key_to_iter.erase(cache_list.back().first);
            //从链表中删除最后一本书
            cache_list.pop_back();
        }
    }
private:
    int capacity;
    //pair里面存的是key和value;
    // cache_list   key->value
    std::list<std::pair<int,int>> cache_list;
    //key -> 双链表的链表节点迭代器
    //key_to_iter key ->list<int,int>::iterator
    std::unordered_map<int,std::list<std::pair<int,int>>::iterator> key_to_iter;
};

int main(){
 // 操作序列（仅用于展示）
    std::vector<std::string> output;  // 存放结果（字符串形式）

    LRUCache* obj = new LRUCache(2);

    // 1. put(1, 1) → null
    obj->put(1, 1);
    output.push_back("null");

    // 2. put(2, 2) → null
    obj->put(2, 2);
    output.push_back("null");

    // 3. get(1) → 1
    output.push_back(std::to_string(obj->get(1)));

    // 4. put(3, 3) → null
    obj->put(3, 3);
    output.push_back("null");

    // 5. get(2) → -1
    output.push_back(std::to_string(obj->get(2)));

    // 6. put(4, 4) → null
    obj->put(4, 4);
    output.push_back("null");

    // 7. get(1) → -1
    output.push_back(std::to_string(obj->get(1)));

    // 8. get(3) → 3
    output.push_back(std::to_string(obj->get(3)));

    // 9. get(4) → 4
    output.push_back(std::to_string(obj->get(4)));

    // 打印结果，格式为 [null, null, null, 1, ...]
    std::cout << "[";
    for (size_t i = 0; i < output.size(); ++i) {
        if (i > 0) std::cout << ", ";
        std::cout << output[i];
    }
    std::cout << "]" << std::endl;

    delete obj;  // 不要忘记释放内存
    return 0;
}
