# 20. 有效的括号

- 栈、字符串

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

**有效字符串需满足**：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

> **示例 1：**
>
> ​	**输入：**s = "()"
>
> ​	**输出：**true
>
> **示例 2：**
>
> ​	**输入：**s = "()[]{}"
>
> ​	**输出：**true
>
> **示例 3：**
>
> ​	**输入：**s = "(]"
>
> ​	**输出：**false
>
> **示例 4：**
>
> ​	**输入：**s = "([])"
>
> ​	**输出：**true
>
> **示例 5：**
>
> ​	**输入：**s = "([)]"
>
> ​	**输出：**false

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成

## 史山写法

```c++
#include <iostream>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        for(char i:s){
            stk.push(i);
            if(i == ')' || i == ']' || i == '}'){
                stk.pop();
                if(i==')'&&!stk.empty()){
                    if(stk.top()=='('){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i==']'&&!stk.empty()){
                    if(stk.top()=='['){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i=='}'&&!stk.empty()){
                    if(stk.top()=='{'){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else{
                    return false;
                }
            }
        }
        if(stk.empty()){
            return true;
        }
        else{
            return false;
        }
    }
};

int main(){
    std::string s = "{([])}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 正确代码

**思路**：

括号匹配只需记住一条规则：**遇到左括号就入栈，遇到右括号就检查栈顶是否是对应的左括号**。

- 如果匹配，就弹出栈顶左括号，继续处理下一个字符。
- 如果不匹配（或栈为空），直接返回 `false`。
- 遍历完整个字符串后，栈为空说明全部匹配，否则返回 `false`。

另外，可以用一个哈希表（`unordered_map`）来存右括号到左括号的映射，避免多层 `if-else`。

```c++
#include <iostream>
#include <string>
#include <stack>
#include <unordered_map>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        unordered_map<char,char> pairs = 
        {
            {')','('},
            {']','['},
            {'}','{'}
        };
        for(char ch:s){
            if(ch=='('||ch=='['||ch=='{'){
                stk.push(ch);
            }
            else{
                if(stk.empty()||stk.top()!=pairs[ch]){
                    return false;
                }
                stk.pop();
            }
        }
        return stk.empty();
    }
};

int main(){
    std::string s = "{([])}}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 复杂度分析

- **时间复杂度：O(n)**：
  - 算法只遍历字符串一次，每个字符的处理都是 O(1)：
    - 左括号：入栈 O(1)
    - 右括号：检查栈顶、弹出栈顶 O(1)
  - 哈希表 `pairs` 的查找是 O(1) 平均时间。
  - 因此总时间与字符串长度 n 成正比，**O(n)**。

- **空间复杂度：O(n)**：

  - 额外使用的栈 `stk` 在最坏情况下会存储所有字符。

  - 最坏情况是什么？全为左括号，例如 `"((((((("`，这时栈大小 = n。

  - 哈希表 `pairs` 只存 3 个固定映射，空间 O(1)，可以忽略。

  - 所以整体空间复杂度 **O(n)**。

# 155. 最小栈

- 栈、设计

## 法1：全压入最小栈

- 用主栈 `stk` 正常存放所有元素。
- 用辅助栈 `minstk` 存放**当前栈中的最小值**，且栈顶始终是 `stk` 当前所有元素的最小值。
- 每次 `push` 时，将新元素与 `minstk.top()` 比较，把较小值压入 `minstk`。
- `pop` 时，两个栈同步弹出即可。
- 任何时候想获取最小值，直接返回 `minstk.top()`，`getMin()`时间复杂度 O(1)。

```c++
#include <iostream>
#include <stack>
using namespace std;

class MinStack {
public:
    MinStack() {//初始化堆栈对象
        
    }
    
    void push(int val) {//将元素val推入堆栈
        stk.push(val);
        if(minstk.empty()||val<=minstk.top()){//只有当前元素小于最小值时,压入最小栈并更新
            minstk.push(val);
        }
        else{
            minstk.push(minstk.top());//否则,继续压入最小栈中当前最小值
        }
    }
    
    void pop() {//删除堆栈顶部的元素
        stk.pop();
        minstk.pop();
    }
    
    int top() {//获取堆栈顶部的元素
        return stk.top();
    }
    
    int getMin() {//获取堆栈中的最小元素
        return minstk.top();
    }
private:
    std::stack<int> stk;
    std::stack<int> minstk;
};

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack* obj = new MinStack();
 * obj->push(val);
 * obj->pop();
 * int param_3 = obj->top();
 * int param_4 = obj->getMin();
 */

int main(){

    MinStack* obj = new MinStack();
    obj->push(-2);
    obj->push(0);
    obj->push(-3);
    std::cout<<obj->getMin()<<std::endl;
    obj->pop();
    std::cout<<obj->top()<<std::endl;
    std::cout<<obj->getMin()<<std::endl;

    return 0;
}
```

## 法2：只有最小值发生变化才压入最小栈(优化版)

**用主栈 `stk` 正常存放所有元素。**

**用辅助栈 `minstk` 只记录“最小值发生下降（或持平）”的时刻，栈顶始终为当前 `data` 中所有元素的最小值。**

每次 `push(x)` 时：

- 若 `minstk` 为空，或 `x ≤ minstk.top()`（注意包含等号），说明当前最小值更新为 `x`，则将 `x` 压入 `minstk`。
- 否则 `minstk` 不动，因为 `x` 比当前最小值大，插入后并不改变最小值。

每次 `pop()` 时：

- 先判断 `stk.top()` 是否等于 `minstk.top()`（即弹出的元素恰好是当前最小值）。如果相等，说明最小值被移除了，`minstk` 需要同步弹出，让栈顶变成更早时刻保存的上一级最小值。
- 否则 `minstk` 不动，因为弹出的不是最小值，不影响当前最小值。
- 最后再执行 `stk.pop()`。

任何时候想获取最小值，直接返回 `minstk.top()`，时间复杂度 **O(1)**。

这样，`minstk` 中只保存了 **最小值发生变化的那些时刻**，避免了基础版本中每次 `push` 都复制一份最小值带来的冗余。尤其当连续压入大批大于当前最小值的元素时，`minstk` 完全不增长，从而显著节省内存，同时 `getMin()` 依然是常数时间。

```c++
#include <iostream>
#include <stack>
using namespace std;

class MinStack {
public:
    MinStack() {//初始化堆栈对象
        
    }
    
    void push(int val) {//将元素val推入堆栈
        stk.push(val);
        if(minstk.empty()||val<=minstk.top()){//只有当前元素小于最小值时,压入最小栈并更新最小元素
            minstk.push(val);
        }
    }
    
    void pop() {//删除堆栈顶部的元素
        if(stk.top()==minstk.top()){//只有当最小栈中的最小元素与要删除的元素相同时,才删除最小栈
            minstk.pop();
        }
        stk.pop();//始终删除当前工作栈的元素
    }
    
    int top() {//获取堆栈顶部的元素
        return stk.top();
    }
    
    int getMin() {//获取堆栈中的最小元素
        return minstk.top();
    }
private:
    std::stack<int> stk;
    std::stack<int> minstk;
};

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack* obj = new MinStack();
 * obj->push(val);
 * obj->pop();
 * int param_3 = obj->top();
 * int param_4 = obj->getMin();
 */

int main(){

    MinStack* obj = new MinStack();
    obj->push(-2);
    obj->push(0);
    obj->push(-3);
    std::cout<<obj->getMin()<<std::endl;
    obj->pop();
    std::cout<<obj->top()<<std::endl;
    std::cout<<obj->getMin()<<std::endl;

    return 0;
}
```
