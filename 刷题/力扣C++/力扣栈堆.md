# 20. 有效的括号

- 栈、字符串

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

**有效字符串需满足**：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

> **示例 1：**
>
> ​	**输入：**s = "()"
>
> ​	**输出：**true
>
> **示例 2：**
>
> ​	**输入：**s = "()[]{}"
>
> ​	**输出：**true
>
> **示例 3：**
>
> ​	**输入：**s = "(]"
>
> ​	**输出：**false
>
> **示例 4：**
>
> ​	**输入：**s = "([])"
>
> ​	**输出：**true
>
> **示例 5：**
>
> ​	**输入：**s = "([)]"
>
> ​	**输出：**false

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成

## 史山写法

```c++
#include <iostream>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        for(char i:s){
            stk.push(i);
            if(i == ')' || i == ']' || i == '}'){
                stk.pop();
                if(i==')'&&!stk.empty()){
                    if(stk.top()=='('){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i==']'&&!stk.empty()){
                    if(stk.top()=='['){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i=='}'&&!stk.empty()){
                    if(stk.top()=='{'){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else{
                    return false;
                }
            }
        }
        if(stk.empty()){
            return true;
        }
        else{
            return false;
        }
    }
};

int main(){
    std::string s = "{([])}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 正确代码

**思路**：

括号匹配只需记住一条规则：**遇到左括号就入栈，遇到右括号就检查栈顶是否是对应的左括号**。

- 如果匹配，就弹出栈顶左括号，继续处理下一个字符。
- 如果不匹配（或栈为空），直接返回 `false`。
- 遍历完整个字符串后，栈为空说明全部匹配，否则返回 `false`。

另外，可以用一个哈希表（`unordered_map`）来存右括号到左括号的映射，避免多层 `if-else`。

```c++
#include <iostream>
#include <string>
#include <stack>
#include <unordered_map>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        unordered_map<char,char> pairs = 
        {
            {')','('},
            {']','['},
            {'}','{'}
        };
        for(char ch:s){
            if(ch=='('||ch=='['||ch=='{'){
                stk.push(ch);
            }
            else{
                if(stk.empty()||stk.top()!=pairs[ch]){
                    return false;
                }
                stk.pop();
            }
        }
        return stk.empty();
    }
};

int main(){
    std::string s = "{([])}}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 复杂度分析

- **时间复杂度：O(n)**：
  - 算法只遍历字符串一次，每个字符的处理都是 O(1)：
    - 左括号：入栈 O(1)
    - 右括号：检查栈顶、弹出栈顶 O(1)
  - 哈希表 `pairs` 的查找是 O(1) 平均时间。
  - 因此总时间与字符串长度 n 成正比，**O(n)**。

- **空间复杂度：O(n)**：

  - 额外使用的栈 `stk` 在最坏情况下会存储所有字符。

  - 最坏情况是什么？全为左括号，例如 `"((((((("`，这时栈大小 = n。

  - 哈希表 `pairs` 只存 3 个固定映射，空间 O(1)，可以忽略。

  - 所以整体空间复杂度 **O(n)**。
