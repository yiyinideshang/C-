# 20. 有效的括号

- 栈、字符串

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

**有效字符串需满足**：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

> **示例 1：**
>
> ​	**输入：**s = "()"
>
> ​	**输出：**true
>
> **示例 2：**
>
> ​	**输入：**s = "()[]{}"
>
> ​	**输出：**true
>
> **示例 3：**
>
> ​	**输入：**s = "(]"
>
> ​	**输出：**false
>
> **示例 4：**
>
> ​	**输入：**s = "([])"
>
> ​	**输出：**true
>
> **示例 5：**
>
> ​	**输入：**s = "([)]"
>
> ​	**输出：**false

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成

## 史山写法

```c++
#include <iostream>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        for(char i:s){
            stk.push(i);
            if(i == ')' || i == ']' || i == '}'){
                stk.pop();
                if(i==')'&&!stk.empty()){
                    if(stk.top()=='('){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i==']'&&!stk.empty()){
                    if(stk.top()=='['){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i=='}'&&!stk.empty()){
                    if(stk.top()=='{'){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else{
                    return false;
                }
            }
        }
        if(stk.empty()){
            return true;
        }
        else{
            return false;
        }
    }
};

int main(){
    std::string s = "{([])}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 正确代码

**思路**：

括号匹配只需记住一条规则：**遇到左括号就入栈，遇到右括号就检查栈顶是否是对应的左括号**。

- 如果匹配，就弹出栈顶左括号，继续处理下一个字符。
- 如果不匹配（或栈为空），直接返回 `false`。
- 遍历完整个字符串后，栈为空说明全部匹配，否则返回 `false`。

另外，可以用一个哈希表（`unordered_map`）来存右括号到左括号的映射，避免多层 `if-else`。

```c++
#include <iostream>
#include <string>
#include <stack>
#include <unordered_map>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        unordered_map<char,char> pairs = 
        {
            {')','('},
            {']','['},
            {'}','{'}
        };
        for(char ch:s){
            if(ch=='('||ch=='['||ch=='{'){
                stk.push(ch);
            }
            else{
                if(stk.empty()||stk.top()!=pairs[ch]){
                    return false;
                }
                stk.pop();
            }
        }
        return stk.empty();
    }
};

int main(){
    std::string s = "{([])}}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 复杂度分析

- **时间复杂度：O(n)**：
  - 算法只遍历字符串一次，每个字符的处理都是 O(1)：
    - 左括号：入栈 O(1)
    - 右括号：检查栈顶、弹出栈顶 O(1)
  - 哈希表 `pairs` 的查找是 O(1) 平均时间。
  - 因此总时间与字符串长度 n 成正比，**O(n)**。

- **空间复杂度：O(n)**：

  - 额外使用的栈 `stk` 在最坏情况下会存储所有字符。

  - 最坏情况是什么？全为左括号，例如 `"((((((("`，这时栈大小 = n。

  - 哈希表 `pairs` 只存 3 个固定映射，空间 O(1)，可以忽略。

  - 所以整体空间复杂度 **O(n)**。

# 155. 最小栈

- 栈、设计

## 法1：全压入最小栈

- 用主栈 `stk` 正常存放所有元素。
- 用辅助栈 `minstk` 存放**当前栈中的最小值**，且栈顶始终是 `stk` 当前所有元素的最小值。
- 每次 `push` 时，将新元素与 `minstk.top()` 比较，把较小值压入 `minstk`。
- `pop` 时，两个栈同步弹出即可。
- 任何时候想获取最小值，直接返回 `minstk.top()`，`getMin()`时间复杂度 O(1)。

```c++
#include <iostream>
#include <stack>
using namespace std;

class MinStack {
public:
    MinStack() {//初始化堆栈对象
        
    }
    
    void push(int val) {//将元素val推入堆栈
        stk.push(val);
        if(minstk.empty()||val<=minstk.top()){//只有当前元素小于最小值时,压入最小栈并更新
            minstk.push(val);
        }
        else{
            minstk.push(minstk.top());//否则,继续压入最小栈中当前最小值
        }
    }
    
    void pop() {//删除堆栈顶部的元素
        stk.pop();
        minstk.pop();
    }
    
    int top() {//获取堆栈顶部的元素
        return stk.top();
    }
    
    int getMin() {//获取堆栈中的最小元素
        return minstk.top();
    }
private:
    std::stack<int> stk;
    std::stack<int> minstk;
};

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack* obj = new MinStack();
 * obj->push(val);
 * obj->pop();
 * int param_3 = obj->top();
 * int param_4 = obj->getMin();
 */

int main(){

    MinStack* obj = new MinStack();
    obj->push(-2);
    obj->push(0);
    obj->push(-3);
    std::cout<<obj->getMin()<<std::endl;
    obj->pop();
    std::cout<<obj->top()<<std::endl;
    std::cout<<obj->getMin()<<std::endl;

    return 0;
}
```

## 法2：只有最小值发生变化才压入最小栈(优化版)

**用主栈 `stk` 正常存放所有元素。**

**用辅助栈 `minstk` 只记录“最小值发生下降（或持平）”的时刻，栈顶始终为当前 `data` 中所有元素的最小值。**

每次 `push(x)` 时：

- 若 `minstk` 为空，或 `x ≤ minstk.top()`（注意包含等号），说明当前最小值更新为 `x`，则将 `x` 压入 `minstk`。
- 否则 `minstk` 不动，因为 `x` 比当前最小值大，插入后并不改变最小值。

每次 `pop()` 时：

- 先判断 `stk.top()` 是否等于 `minstk.top()`（即弹出的元素恰好是当前最小值）。如果相等，说明最小值被移除了，`minstk` 需要同步弹出，让栈顶变成更早时刻保存的上一级最小值。
- 否则 `minstk` 不动，因为弹出的不是最小值，不影响当前最小值。
- 最后再执行 `stk.pop()`。

任何时候想获取最小值，直接返回 `minstk.top()`，时间复杂度 **O(1)**。

这样，`minstk` 中只保存了 **最小值发生变化的那些时刻**，避免了基础版本中每次 `push` 都复制一份最小值带来的冗余。尤其当连续压入大批大于当前最小值的元素时，`minstk` 完全不增长，从而显著节省内存，同时 `getMin()` 依然是常数时间。

```c++
#include <iostream>
#include <stack>
using namespace std;

class MinStack {
public:
    MinStack() {//初始化堆栈对象
        
    }
    
    void push(int val) {//将元素val推入堆栈
        stk.push(val);
        if(minstk.empty()||val<=minstk.top()){//只有当前元素小于最小值时,压入最小栈并更新最小元素
            minstk.push(val);
        }
    }
    
    void pop() {//删除堆栈顶部的元素
        if(stk.top()==minstk.top()){//只有当最小栈中的最小元素与要删除的元素相同时,才删除最小栈
            minstk.pop();
        }
        stk.pop();//始终删除当前工作栈的元素
    }
    
    int top() {//获取堆栈顶部的元素
        return stk.top();
    }
    
    int getMin() {//获取堆栈中的最小元素
        return minstk.top();
    }
private:
    std::stack<int> stk;
    std::stack<int> minstk;
};

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack* obj = new MinStack();
 * obj->push(val);
 * obj->pop();
 * int param_3 = obj->top();
 * int param_4 = obj->getMin();
 */

int main(){

    MinStack* obj = new MinStack();
    obj->push(-2);
    obj->push(0);
    obj->push(-3);
    std::cout<<obj->getMin()<<std::endl;
    obj->pop();
    std::cout<<obj->top()<<std::endl;
    std::cout<<obj->getMin()<<std::endl;

    return 0;
}
```

# 394. 字符串解码

- 栈、递归、字符串

> s：该编码的字符串
>
> - `1 <= s.length <= 30`
> - `s` 由小写英文字母、数字和方括号 `'[]'` 组成
> - `s` 保证是一个 **有效** 的输入。
> - `s` 中所有整数的取值范围为 `[1, 300]` 

## 法1：🧑‍💻递归法

函数 `decode` 负责解析从索引 `i` 开始的一个完整片段。当它遇到数字 `num` 和左括号 `[` 时，会递归地调用自身去解析括号内的嵌套部分，返回内层解码后的完整字符串，然后再根据外层的 `num` 进行重复并拼接到结果上。遇到 `]` 则表示本层解析结束，将结果返回给上一层调用者

```c++
class Solution {
public:
    string decodeString(string s) {
        int i = 0; // 使用索引在递归调用中追踪处理到的位置
        return decode(s, i);
    }

    string decode(const string& s, int& i) {
        string res = "";
        int num = 0;
        while (i < s.size()) {
            char c = s[i];
            if (std::isdigit(c)) {
                // 累积数字
                num = num * 10 + (c - '0');
                i++;
            } else if (c == '[') {
                // 跳过'['，递归解析括号内的子串
                i++;
                string inner = decode(s, i);
                // 将解析出的子串重复num次拼接到结果中
                for (int k = 0; k < num; k++) {
                    res += inner;
                }
                num = 0; // 重置重复次数
            } else if (c == ']') {
                // 遇到']'，表示当前递归层结束，返回结果并移动索引
                i++;
                return res;
            } else {
                // 字母，直接拼接到结果
                res += c;
                i++;
            }
        }
        return res;
    }
};
```

## 法2：👩‍💻双栈法

使用两个显式的栈，一个存数字（`nums`），一个存字符串（`strs`），来模拟“进入”和“退出”每一层嵌套括号的过程。

- **变量初始化**：`nums` (存重复次数)、`strs` (存 `[` 之前的字符串)、`curr` (当前构建的字符串)、`num` (当前累积的数字)。
- **遍历字符串**：逐个字符处理：
  - **数字**：处理多位数，累积到 `num` 变量中：`num = num * 10 + (c - '0')`。
  - **`[`**：遇到左括号，代表进入新的一层嵌套。把当前的重复次数 `num` 和字符串 `curr` 分别压入 `nums` 和 `strs` 栈中保存，然后重置它们，为处理括号内的内容做准备。
  - **`]`**：遇到右括号，代表当前这层嵌套结束，需要 **出栈并拼接** 结果。
    1. 从 `nums` 栈顶弹出上一层的重复次数 `times`。
    2. 从 `strs` 栈顶弹出上一层的字符串 `prev`。
    3. 将当前构建的 `curr` 字符串重复 `times` 次，并接到 `prev` 后面。
    4. 将拼接后的完整字符串赋值给 `curr`，作为当前层的字符串，供外层继续拼接。
  - **字母**：直接追加到 `curr` 后。
- **返回结果**：遍历结束后的 `curr` 字符串，就是最终解码结果。

```c++
#include <iostream>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    std::string decodeString(const std::string& s) {
        std::stack<int> nums;        // 存放重复次数
        std::stack<std::string> strs; // 存放 '[' 之前的字符串
        std::string curr;            // 当前正在构建的字符串
        int num = 0;                 // 当前正在累积的数字

        for (char c : s) {
            if (std::isdigit(c)) {
                // 1. 数字：累积到 num 中（处理多位数）
                num = num * 10 + (c - '0');
            } 
            else if (c == '[') {
                // 2. 左括号：进入新的一层嵌套
                //    保存当前数字和字符串，然后重置状态
                nums.push(num);
                strs.push(curr);//每次遇到[将上一次,即[前面的字母串压入栈
                num = 0;
                curr.clear();
            } 
            else if (c == ']') {
                // 3. 右括号：一层嵌套结束，解码并拼接
                int times = nums.top();    // 弹出重复次数
                nums.pop();
                std::string prev = strs.top(); // 弹出上一层的字符串
                strs.pop();

                // 将 curr 重复 times 次，接到 prev 后面
                std::string temp;
                for (int i = 0; i < times; ++i) {
                    temp += curr;
                }
                curr = prev + temp;
            } 
            else {
                // 4. 字母：直接拼接到当前字符串
                curr += c;
            }
        }

        return curr;
    }
};


int main(){
    std::string s = "abc3[d2[ef]]g";
    Solution result;
    std::cout<<result.decodeString(s)<<std::endl;
    return 0;
}
```

## 复杂度分析

N为字符串的长度

| **双栈法（显式栈）** | O(N) | O(N) | 字符串拼接总次数与输出长度线性相关              |
| -------------------- | ---- | ---- | ----------------------------------------------- |
| **递归法（隐式栈）** | O(N) | O(N) | 系统调用栈与递归中持有的临时字符串总量也是 O(N) |

# 739. 每日温度

## 暴力-超时

```c++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        std::vector<int> result(n,0);
        
        for(int i = 0;i<n;i++){
            for(int j = i;j<n;j++){
                if(temperatures[j]>temperatures[i]){
                    result[i] = j-i;
                    break;
                }
            }
        }
        return result;
    }
};
```

## 单调栈

```c++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        //temperatures = {73,74,75,71,69,72,76,73};
        int n = temperatures.size();
        std::vector<int> result(n,0);   // 默认 0，表示没有更高的温度
        //单调栈,从栈底到栈顶是单调递增,从栈顶到栈底是单调递减
        std::stack<int> stk;            //存放teme下标位置(天数位置,从0开始)

        for(int i = 0;i<n;i++){
            //当栈不为空并且当前温度大于栈顶的温度时,
            while(!stk.empty()&&temperatures[i]>temperatures[stk.top()]){
                result[stk.top()]=i-stk.top();//将栈顶(teme下标位置)位置需要等待的天数存放到result中
                //i-stk.top()即为天数差值
                stk.pop();//删除栈顶元素,更新了栈顶元素
            }
            stk.push(i);//将当前天入栈,等待遍历未来天数,查找未来更高的温度
        }
        return result;//如果某天的温度在未来没有出现高于该温度,则该天的结果默认是0
    }
};
```

## 复杂度分析

### 暴力法：

- 时间复杂度：O(n²)

- 空间复杂度：O(1)

### 单调栈：

- 时间复杂度：O(n)
  - **每个元素最多入栈一次、出栈一次。**

- 空间复杂度：O(n)

  - 栈 `stack<int>` 最多存放 `n` 个索引（当气温严格递减时，如 `[5,4,3,2,1]`，所有元素都会留在栈里直到结束）。

  - 答案数组 `vector<int> answer(n)` 本身也占 O(n) 空间（一般视为输出所需空间，不计入额外空间；但即便计入，也是 O(n)）。

# 215. 数组中的第K 个最大元素

- 数组、分治、快速选择、排序、堆（优先队列）

## 法1：暴力排序法（简单直接）

- 将数组排序，然后直接取第 k 大的元素。C++ 中 `std::sort` 默认升序，所以第 k 大就是倒数第 k 个。

```c++
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        std::sort(nums.begin(),nums.end());
        return nums[nums.size()-k];
    }
};
```

### 复杂度分析

- 时间复杂度：**O(N log N)**
- 空间复杂度：**O(log N)**（取决于 sort 的栈深度）

## 法2：最小堆(优先队列)

### 思路

> 我们要从一群人里选出实力第 K 强的人，但不想把所有人全排一遍。
> 于是我们搞了一个 **VIP 房间，名额只有 K 个**，并且规定：房间里永远只保留**当前见到的最强的 K 个人**。
> 房间门口贴着一张“**房间最弱者排行榜**”（最小堆的堆顶），写着现在房间里最弱的是谁。
> 新人一个个过来：
>
> - 如果房间还没满，直接进；
> - 如果房间满了，先看一眼门口那张纸：
>   - 新人如果不比那个最弱的人强，连门都别想进；
>   - 新人如果比那个最弱的人强，就把那个最弱的踢出去，自己进去，门口的名册随之更新。
>
> 所有人都过了一遍之后，VIP 房间里站着的就是**全场最强的 K 个人**，而门口名册上那位（堆顶）正好是这 K 个人里最弱的——也就是**全场第 K 强的人**。

### 过程

假设 `nums = [3, 2, 1, 5, 6, 4]`，`K = 2`（想找第 2 大的元素，应该是 5）。

- ### 初始状态

```
minHeap: []
K = 2
```

目标：每次操作后，保持堆的大小 ≤ 2。

- ### 遍历过程

**第 1 步：读入 3**

- 堆不满（size = 0 < 2），直接插入。
- 堆变成：

```
[3]  （堆顶是3）
```

**第 2 步：读入 2**

- 堆不满（size = 1 < 2），直接插入。
- 插入后堆内部会调整，使最小元素在堆顶：

```
   2
  /
 3
```

或者用数组看：`[2, 3]`，`minHeap.top()` = 2。

**第 3 步：读入 1**

- 堆已满（size = 2）。
- 比较 `1` 和堆顶 `2`：`1` 比堆顶**小**，说明 `1` 根本没资格进入“当前最大的 2 个数”，因为最大的 2 个数目前是 `3` 和 `2`，`1` 还比不上它们中最小的 `2`。
- 于是**不做任何操作**，堆保持 `[2, 3]`。

**第 4 步：读入 5**

- 堆已满。
- 比较 `5` 和堆顶 `2`：`5` > `2`，说明 `5` 应该取代堆里最小的那个数，来构成新的“最大的 2 个数”。
- **弹出堆顶** `2`，然后插入 `5`。
- 弹出后堆是 `[3]`，插入 5 后堆变成：

```
   3
  /
 5
```

调整后：`[3, 5]`，堆顶是 3。（最大的 2 个数现在是 5 和 3）

**第 5 步：读入 6**

- 堆已满。
- 比较 `6` 与堆顶 `3`：`6` > `3`，弹出 `3`，插入 `6`。
- 堆变成 `[5, 6]`，堆顶是 5。（最大的 2 个数：6 和 5）

```
   5
  /
 6
```

**第 6 步：读入 4**

- 堆已满。
- 比较 `4` 与堆顶 `5`：`4` < `5`，不比堆顶大，直接忽略。

遍历结束，堆里存的正是**整个数组里最大的 2 个元素**：`[5, 6]`。
堆顶是这两个数里最小的那个 → `5`，也就是**整个数组的第 2 大元素**。

✅ 答案：5。

### 代码1-原始思路版

```c++
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        // 声明一个最小堆：priority_queue<int, 底层容器, 比较器>
        // greater<int> 意味着小的元素优先级高 → 堆顶最小
        std::priority_queue<int,std::vector<int>,std::greater<int>> minHeap;
        for(int num:nums){ 			// 遍历数组中每个数
            if(minHeap.size()<k){   // 堆不满,直接插入
                minHeap.push(num);
            }
            //堆满,比较本次遍历的num与堆顶元素
            else if(num>minHeap.top()){ //如果num大于堆顶,则弹出堆顶,并插入该num
                minHeap.pop();
                minHeap.push(num);
            }//否则(堆已满且num小于等于堆顶),不进行任何操作
        }

        // 最后堆顶就是第 k 大的元素
        return minHeap.top();
    }
};
```

### 代码2-优化版

> **细节说明**：
>
> - 这个写法稍微不同：每次都先插入，再判断是否超量。这等价于之前讲到的“满了就比较再决定”的逻辑，因为如果当前数很小，它进去后可能马上又作为堆顶被弹出去。
> - `push()` 会触发向上调整，保持最小堆性质。
> - `pop()` 会把堆顶移走，并让最后一个元素移到堆顶后向下沉。
> - 如果堆大小超过 k 就弹出，保证最终堆的大小恰好为 k（除非 nums 元素不足 k 个，但题目保证 k 有效）。
>
> 你可能会想：会不会把本来应该留在堆里的数错误地弹走了？
> 不会，因为堆里永远是**当前最大的 K 个数**，弹走的都是最小的那个“守门员”，而它已经不够格代表“第 K 大”了。

```c++
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        // 声明一个最小堆：priority_queue<int, 底层容器, 比较器>
        // greater<int> 意味着小的元素优先级高 → 堆顶最小
        priority_queue<int, vector<int>, greater<int>> minHeap;

        for (int num : nums) {         // 遍历数组中每个数
            minHeap.push(num);         // 先无脑插入
            if (minHeap.size() > k) {  // 如果堆的大小超过 k
                minHeap.pop();         // 把最小的那个（堆顶）弹走
            }
        }

        // 最后堆顶就是第 k 大的元素
        return minHeap.top();
    }
};

int main(){
    vector<int> nums = {3,2,3,1,2,4,5,5,6};
    Solution s;
    std::cout<<s.findKthLargest(nums,4)<<std::endl;

    return 0;
}
```

### 复杂度分析

- **时间复杂度**：**O(N log K)**
  - 每次插入或删除堆顶需要 **O(log K)** 的时间（因为堆的高度是 log K）。
  
  - 一共 N 个元素，最坏情况每个元素都需要入堆一次（或比较一次），所以总时间 **O(N log K)**。
  
  - 当 K 远小于 N 时，这比排序的 O(N log N) 快很多。
  
- **空间复杂度**：**O(K)**。
  - 我们只用了大小为 K 的堆

## ==法3：快速选择（Quickselect，分治）==

-  [排序算法.md->快速排序](D:\Typora\typora_work\2数据结构与基本算法\排序算法.md) 

```c++
#include <vector>
#include <cstdlib>
#include <ctime>
using namespace std;

class Solution {
    // 在子数组 [left, right] 中随机选择一个基准元素 pivot
    // 根据 pivot 重新排列子数组 [left, right]
    // 重新排列后，<= pivot 的元素都在 pivot 的左侧，>= pivot 的元素都在 pivot 的右侧
    // 返回 pivot 在重新排列后的 nums 中的下标
    // 特别地，如果子数组的所有元素都等于 pivot，我们会返回子数组的中心下标，避免退化
    int partition(vector<int>& nums, int left, int right) {
        // 1. 在子数组 [left, right] 中随机选择一个基准元素 pivot
        int i = left + rand() % (right - left + 1);
        int pivot = nums[i];
        // 把 pivot 与子数组第一个元素交换，避免 pivot 干扰后续划分，从而简化实现逻辑
        swap(nums[i], nums[left]);

        // 2. 相向双指针遍历子数组 [left + 1, right]
        // 循环不变量：在循环过程中，子数组的数据分布始终如下图
        // [ pivot | <=pivot | 尚未遍历 | >=pivot ]
        //   ^                 ^     ^         ^
        //   left              i     j         right

        i = left + 1;
        int j = right;
        while (true) {
            while (i <= j && nums[i] < pivot) {
                i++;
            }
            // 此时 nums[i] >= pivot

            while (i <= j && nums[j] > pivot) {
                j--;
            }
            // 此时 nums[j] <= pivot

            if (i >= j) {
                break;
            }

            // 维持循环不变量
            swap(nums[i], nums[j]);
            i++;
            j--;
        }

        // 循环结束后
        // [ pivot | <=pivot | >=pivot ]
        //   ^             ^   ^     ^
        //   left          j   i     right

        // 3. 把 pivot 与 nums[j] 交换，完成划分（partition）
        // 为什么与 j 交换？
        // 如果与 i 交换，可能会出现 i = right + 1 的情况，已经下标越界了，无法交换
        // 另一个原因是如果 nums[i] > pivot，交换会导致一个大于 pivot 的数出现在子数组最左边，不是有效划分
        // 与 j 交换，即使 j = left，交换也不会出错
        swap(nums[left], nums[j]);

        // 交换后
        // [ <=pivot | pivot | >=pivot ]
        //               ^
        //               j

        // 返回 pivot 的下标
        return j;
    }

public:
    int findKthLargest(vector<int>& nums, int k) {
        srand(time(NULL));
        int n = nums.size();
        int target_index = n - k; // 第 k 大元素在升序数组中的下标是 n - k
        int left = 0, right = n - 1; // 闭区间
        while (true) {
            int i = partition(nums, left, right);
            if (i == target_index) {
                // 找到第 k 大元素
                return nums[i];
            }
            if (i > target_index) {
                // 第 k 大元素在 [left, i - 1] 中
                right = i - 1;
            } else {
                // 第 k 大元素在 [i + 1, right] 中
                left = i + 1;
            }
        }
    }
};
```

### 复杂度分析

- 平均时间复杂度：**O(N)**
- 最差时间复杂度：**O(N²)**（随机化后概率极低）
- 空间复杂度：**O(log N)**（递归栈）或 **O(1)**（迭代版）

**分治**的思想就体现在这里：把大问题划分成小问题，只在包含答案的那一半继续求解。

## 法4：STL 库函数 `std::ranges::nth_element`

 [容器的一些函数.md](D:\Typora\typora_work\c++_md\3高级面向对象\10顺序容器\容器的一些函数.md) 

```c++
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        std::ranges::nth_element(nums,nums.end()-k);
        return nums[nums.size()-k];
    }
};
```

- 目标是找到数组中**第 `k` 个最大的元素**，即如果将数组**升序排序**，它应该位于索引 `n - k` 处（`n = nums.size()`）。
- `ranges::nth_element(nums, nums.end() - k)` 的作用是：
  - 将 `nums` 重新排列，使得**第 `(n-k)` 个位置上的元素**就是全数组排序后该位置应出现的值。
  - 同时保证该位置**之前的元素全部 ≤ 它**，**之后的元素全部 ≥ 它**。
  - **但前后两部分内部不一定有序**。
- 最后直接返回 `nums[n-k]` 即可得到答案。

### 复杂度分析

- 平均时间复杂度：**O(N)**，最坏情况是 O(N) 还是 O(N²) 取决于实现，但常见实现有很好的平均性能。
- 这是最简洁的高效写法，适合竞赛或实际工程。

## 法5：暴力移除

如果完全不在乎效率，可以每次都找出当前最大值，然后把它移除（或标记为非常小的数），重复 k 次。这种类似选择排序的思想，只需要循环 k 次。

```c++
int findKthLargest/*_bruteforce*/(vector<int>& nums, int k) {
    int n = nums.size();
    for (int i = 0; i < k; ++i) {
        int maxIdx = 0;
        // 找出当前最大值的下标
        for (int j = 1; j < n; ++j) {
            if (nums[j] > nums[maxIdx]) {
                maxIdx = j;
            }
        }
        if (i == k - 1) return nums[maxIdx];
        // “移除”该最大值：把它设为一个极小的数
        nums[maxIdx] = INT_MIN;
    }
    return -1; // 不会到这里
}
```

### 复杂度分析

- 时间复杂度：**O(N·k)**，当 k 接近 N/2 时退化为 **O(N²)**。
- 也可以用冒泡排序 k 趟，让最大的 k 个元素“浮”到末尾，同样 O(N·k)。

虽然不实用，但它直观地展示了“找第 k 大”这个动作的原始意义。
