# 20. 有效的括号

- 栈、字符串

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

**有效字符串需满足**：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

> **示例 1：**
>
> ​	**输入：**s = "()"
>
> ​	**输出：**true
>
> **示例 2：**
>
> ​	**输入：**s = "()[]{}"
>
> ​	**输出：**true
>
> **示例 3：**
>
> ​	**输入：**s = "(]"
>
> ​	**输出：**false
>
> **示例 4：**
>
> ​	**输入：**s = "([])"
>
> ​	**输出：**true
>
> **示例 5：**
>
> ​	**输入：**s = "([)]"
>
> ​	**输出：**false

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成

## 史山写法

```c++
#include <iostream>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        for(char i:s){
            stk.push(i);
            if(i == ')' || i == ']' || i == '}'){
                stk.pop();
                if(i==')'&&!stk.empty()){
                    if(stk.top()=='('){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i==']'&&!stk.empty()){
                    if(stk.top()=='['){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else if(i=='}'&&!stk.empty()){
                    if(stk.top()=='{'){
                        stk.pop();
                    }
                    else{
                        return false;
                    }
                }
                else{
                    return false;
                }
            }
        }
        if(stk.empty()){
            return true;
        }
        else{
            return false;
        }
    }
};

int main(){
    std::string s = "{([])}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 正确代码

**思路**：

括号匹配只需记住一条规则：**遇到左括号就入栈，遇到右括号就检查栈顶是否是对应的左括号**。

- 如果匹配，就弹出栈顶左括号，继续处理下一个字符。
- 如果不匹配（或栈为空），直接返回 `false`。
- 遍历完整个字符串后，栈为空说明全部匹配，否则返回 `false`。

另外，可以用一个哈希表（`unordered_map`）来存右括号到左括号的映射，避免多层 `if-else`。

```c++
#include <iostream>
#include <string>
#include <stack>
#include <unordered_map>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        std::stack<char> stk;
        unordered_map<char,char> pairs = 
        {
            {')','('},
            {']','['},
            {'}','{'}
        };
        for(char ch:s){
            if(ch=='('||ch=='['||ch=='{'){
                stk.push(ch);
            }
            else{
                if(stk.empty()||stk.top()!=pairs[ch]){
                    return false;
                }
                stk.pop();
            }
        }
        return stk.empty();
    }
};

int main(){
    std::string s = "{([])}}";
    Solution result;
    std::cout<<result.isValid(s)<<std::endl;
    return 0;
}
```

## 复杂度分析

- **时间复杂度：O(n)**：
  - 算法只遍历字符串一次，每个字符的处理都是 O(1)：
    - 左括号：入栈 O(1)
    - 右括号：检查栈顶、弹出栈顶 O(1)
  - 哈希表 `pairs` 的查找是 O(1) 平均时间。
  - 因此总时间与字符串长度 n 成正比，**O(n)**。

- **空间复杂度：O(n)**：

  - 额外使用的栈 `stk` 在最坏情况下会存储所有字符。

  - 最坏情况是什么？全为左括号，例如 `"((((((("`，这时栈大小 = n。

  - 哈希表 `pairs` 只存 3 个固定映射，空间 O(1)，可以忽略。

  - 所以整体空间复杂度 **O(n)**。

# 155. 最小栈

- 栈、设计

## 法1：全压入最小栈

- 用主栈 `stk` 正常存放所有元素。
- 用辅助栈 `minstk` 存放**当前栈中的最小值**，且栈顶始终是 `stk` 当前所有元素的最小值。
- 每次 `push` 时，将新元素与 `minstk.top()` 比较，把较小值压入 `minstk`。
- `pop` 时，两个栈同步弹出即可。
- 任何时候想获取最小值，直接返回 `minstk.top()`，`getMin()`时间复杂度 O(1)。

```c++
#include <iostream>
#include <stack>
using namespace std;

class MinStack {
public:
    MinStack() {//初始化堆栈对象
        
    }
    
    void push(int val) {//将元素val推入堆栈
        stk.push(val);
        if(minstk.empty()||val<=minstk.top()){//只有当前元素小于最小值时,压入最小栈并更新
            minstk.push(val);
        }
        else{
            minstk.push(minstk.top());//否则,继续压入最小栈中当前最小值
        }
    }
    
    void pop() {//删除堆栈顶部的元素
        stk.pop();
        minstk.pop();
    }
    
    int top() {//获取堆栈顶部的元素
        return stk.top();
    }
    
    int getMin() {//获取堆栈中的最小元素
        return minstk.top();
    }
private:
    std::stack<int> stk;
    std::stack<int> minstk;
};

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack* obj = new MinStack();
 * obj->push(val);
 * obj->pop();
 * int param_3 = obj->top();
 * int param_4 = obj->getMin();
 */

int main(){

    MinStack* obj = new MinStack();
    obj->push(-2);
    obj->push(0);
    obj->push(-3);
    std::cout<<obj->getMin()<<std::endl;
    obj->pop();
    std::cout<<obj->top()<<std::endl;
    std::cout<<obj->getMin()<<std::endl;

    return 0;
}
```

## 法2：只有最小值发生变化才压入最小栈(优化版)

**用主栈 `stk` 正常存放所有元素。**

**用辅助栈 `minstk` 只记录“最小值发生下降（或持平）”的时刻，栈顶始终为当前 `data` 中所有元素的最小值。**

每次 `push(x)` 时：

- 若 `minstk` 为空，或 `x ≤ minstk.top()`（注意包含等号），说明当前最小值更新为 `x`，则将 `x` 压入 `minstk`。
- 否则 `minstk` 不动，因为 `x` 比当前最小值大，插入后并不改变最小值。

每次 `pop()` 时：

- 先判断 `stk.top()` 是否等于 `minstk.top()`（即弹出的元素恰好是当前最小值）。如果相等，说明最小值被移除了，`minstk` 需要同步弹出，让栈顶变成更早时刻保存的上一级最小值。
- 否则 `minstk` 不动，因为弹出的不是最小值，不影响当前最小值。
- 最后再执行 `stk.pop()`。

任何时候想获取最小值，直接返回 `minstk.top()`，时间复杂度 **O(1)**。

这样，`minstk` 中只保存了 **最小值发生变化的那些时刻**，避免了基础版本中每次 `push` 都复制一份最小值带来的冗余。尤其当连续压入大批大于当前最小值的元素时，`minstk` 完全不增长，从而显著节省内存，同时 `getMin()` 依然是常数时间。

```c++
#include <iostream>
#include <stack>
using namespace std;

class MinStack {
public:
    MinStack() {//初始化堆栈对象
        
    }
    
    void push(int val) {//将元素val推入堆栈
        stk.push(val);
        if(minstk.empty()||val<=minstk.top()){//只有当前元素小于最小值时,压入最小栈并更新最小元素
            minstk.push(val);
        }
    }
    
    void pop() {//删除堆栈顶部的元素
        if(stk.top()==minstk.top()){//只有当最小栈中的最小元素与要删除的元素相同时,才删除最小栈
            minstk.pop();
        }
        stk.pop();//始终删除当前工作栈的元素
    }
    
    int top() {//获取堆栈顶部的元素
        return stk.top();
    }
    
    int getMin() {//获取堆栈中的最小元素
        return minstk.top();
    }
private:
    std::stack<int> stk;
    std::stack<int> minstk;
};

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack* obj = new MinStack();
 * obj->push(val);
 * obj->pop();
 * int param_3 = obj->top();
 * int param_4 = obj->getMin();
 */

int main(){

    MinStack* obj = new MinStack();
    obj->push(-2);
    obj->push(0);
    obj->push(-3);
    std::cout<<obj->getMin()<<std::endl;
    obj->pop();
    std::cout<<obj->top()<<std::endl;
    std::cout<<obj->getMin()<<std::endl;

    return 0;
}
```

# 394. 字符串解码

> s：该编码的字符串
>
> - `1 <= s.length <= 30`
> - `s` 由小写英文字母、数字和方括号 `'[]'` 组成
> - `s` 保证是一个 **有效** 的输入。
> - `s` 中所有整数的取值范围为 `[1, 300]` 

## 法1：🧑‍💻递归法

函数 `decode` 负责解析从索引 `i` 开始的一个完整片段。当它遇到数字 `num` 和左括号 `[` 时，会递归地调用自身去解析括号内的嵌套部分，返回内层解码后的完整字符串，然后再根据外层的 `num` 进行重复并拼接到结果上。遇到 `]` 则表示本层解析结束，将结果返回给上一层调用者

```c++
class Solution {
public:
    string decodeString(string s) {
        int i = 0; // 使用索引在递归调用中追踪处理到的位置
        return decode(s, i);
    }

    string decode(const string& s, int& i) {
        string res = "";
        int num = 0;
        while (i < s.size()) {
            char c = s[i];
            if (std::isdigit(c)) {
                // 累积数字
                num = num * 10 + (c - '0');
                i++;
            } else if (c == '[') {
                // 跳过'['，递归解析括号内的子串
                i++;
                string inner = decode(s, i);
                // 将解析出的子串重复num次拼接到结果中
                for (int k = 0; k < num; k++) {
                    res += inner;
                }
                num = 0; // 重置重复次数
            } else if (c == ']') {
                // 遇到']'，表示当前递归层结束，返回结果并移动索引
                i++;
                return res;
            } else {
                // 字母，直接拼接到结果
                res += c;
                i++;
            }
        }
        return res;
    }
};
```

## 法2：👩‍💻双栈法

使用两个显式的栈，一个存数字（`nums`），一个存字符串（`strs`），来模拟“进入”和“退出”每一层嵌套括号的过程。

- **变量初始化**：`nums` (存重复次数)、`strs` (存 `[` 之前的字符串)、`curr` (当前构建的字符串)、`num` (当前累积的数字)。
- **遍历字符串**：逐个字符处理：
  - **数字**：处理多位数，累积到 `num` 变量中：`num = num * 10 + (c - '0')`。
  - **`[`**：遇到左括号，代表进入新的一层嵌套。把当前的重复次数 `num` 和字符串 `curr` 分别压入 `nums` 和 `strs` 栈中保存，然后重置它们，为处理括号内的内容做准备。
  - **`]`**：遇到右括号，代表当前这层嵌套结束，需要 **出栈并拼接** 结果。
    1. 从 `nums` 栈顶弹出上一层的重复次数 `times`。
    2. 从 `strs` 栈顶弹出上一层的字符串 `prev`。
    3. 将当前构建的 `curr` 字符串重复 `times` 次，并接到 `prev` 后面。
    4. 将拼接后的完整字符串赋值给 `curr`，作为当前层的字符串，供外层继续拼接。
  - **字母**：直接追加到 `curr` 后。
- **返回结果**：遍历结束后的 `curr` 字符串，就是最终解码结果。

```c++
#include <iostream>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    std::string decodeString(const std::string& s) {
        std::stack<int> nums;        // 存放重复次数
        std::stack<std::string> strs; // 存放 '[' 之前的字符串
        std::string curr;            // 当前正在构建的字符串
        int num = 0;                 // 当前正在累积的数字

        for (char c : s) {
            if (std::isdigit(c)) {
                // 1. 数字：累积到 num 中（处理多位数）
                num = num * 10 + (c - '0');
            } 
            else if (c == '[') {
                // 2. 左括号：进入新的一层嵌套
                //    保存当前数字和字符串，然后重置状态
                nums.push(num);
                strs.push(curr);//每次遇到[将上一次,即[前面的字母串压入栈
                num = 0;
                curr.clear();
            } 
            else if (c == ']') {
                // 3. 右括号：一层嵌套结束，解码并拼接
                int times = nums.top();    // 弹出重复次数
                nums.pop();
                std::string prev = strs.top(); // 弹出上一层的字符串
                strs.pop();

                // 将 curr 重复 times 次，接到 prev 后面
                std::string temp;
                for (int i = 0; i < times; ++i) {
                    temp += curr;
                }
                curr = prev + temp;
            } 
            else {
                // 4. 字母：直接拼接到当前字符串
                curr += c;
            }
        }

        return curr;
    }
};


int main(){
    std::string s = "abc3[d2[ef]]g";
    Solution result;
    std::cout<<result.decodeString(s)<<std::endl;
    return 0;
}
```

## 复杂度分析

N为字符串的长度

| **双栈法（显式栈）** | O(N) | O(N) | 字符串拼接总次数与输出长度线性相关              |
| -------------------- | ---- | ---- | ----------------------------------------------- |
| **递归法（隐式栈）** | O(N) | O(N) | 系统调用栈与递归中持有的临时字符串总量也是 O(N) |
