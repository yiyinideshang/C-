# ==105. 从前序与中序遍历序列构造二叉树==

给定一个前序遍历的数组和一个中序遍历的数组能够唯一确定该二叉树

给定一个后序遍历的数组和一个中序遍历的数组能够唯一确定该二叉树

## 代码

```c++
#include <iostream>
#include <queue>
#include <unordered_map>
#include <vector>
#include <algorithm>
using namespace std;

// 二叉树节点的定义:
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};

// 层序遍历输出:
vector<string> levelOrderSerialize(TreeNode *root)
{
    vector<string> result;
    if (!root)
        return result;
    queue<TreeNode *> q;
    q.push(root);
    while (!q.empty())
    {
        TreeNode *curr = q.front();
        q.pop();
        if (curr)
        {
            // 无论子节点是否为空，都入队，以保持占位
            result.push_back(to_string(curr->val));
            q.push(curr->left);
            q.push(curr->right);
        }
        else
        {
            result.push_back("null");
        }
    }
    // 去除末尾多余的 "null"，避免序列过长
    while (!result.empty() && result.back() == "null")
    {
        result.pop_back();
    }
    return result;
}

// 后序释放
void deleteTree(TreeNode *root)
{
    if (!root)
        return; // 空节点本身就指向nullptr,不用释放
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

class Solution
{
private:
    unordered_map<int, int> index; // 存储 中序值 → 索引

public:
    // 实际递归构造
    TreeNode *myBuildTree(const vector<int> &preorder, const vector<int> &inorder,
                          int preLeft, int preRight, int inLeft, int inRight)
    {
        if (preLeft > preRight)
            return nullptr;

        // 1. 取出根节点的值
        int rootVal = preorder[preLeft];
        TreeNode *root = new TreeNode(rootVal);

        // 2. 找到根在中序中的位置
        int inRoot = index[rootVal];

        // 3. 左子树节点个数
        int leftSize = inRoot - inLeft;

        // 4. 递归构造左右子树
        root->left = myBuildTree(preorder, inorder,
                                 preLeft + 1, preLeft + leftSize,
                                 inLeft, inRoot - 1);
        root->right = myBuildTree(preorder, inorder,
                                  preLeft + leftSize + 1, preRight,
                                  inRoot + 1, inRight);
        return root;
    }

    TreeNode *buildTree(vector<int> &preorder, vector<int> &inorder)
    {
        int n = preorder.size();
        for (int i = 0; i < n; ++i)
            index[inorder[i]] = i; // 构建哈希表
        return myBuildTree(preorder, inorder, 0, n - 1, 0, n - 1);
    }
};

int main()
{
    Solution s;
    vector<int> preoreder = {3, 9,5, 20, 15, 7};
    vector<int> inorder = {5,9, 3, 15, 20, 7};
    TreeNode *result;
    result = s.buildTree(preoreder, inorder);

    vector<string> s1 = levelOrderSerialize(result);
    ;
    std::cout << "[";
    for (int i = 0; i < s1.size(); ++i)
    {
        std::cout << s1[i];
        if (i != s1.size() - 1)
        {
            std::cout << ",";
        }
    }
    std::cout << "]";

    return 0;
}
```

## 复杂度分析

### 时间复杂度：O(n)

- **建哈希表**：遍历 `inorder` 数组，存储 `值 → 索引` 映射，耗时 O(n)。
- **递归构造**：每个节点都会作为一次递归的根被创建，共 n 个节点。
  - 每次递归中，通过哈希表查找根在中序中的位置，耗时 O(1)。
  - 计算左子树节点数及递归传参，均为 O(1)。
  - 因此每个节点的处理时间是常数级别。
- 总时间：O(n) + n × O(1) = **O(n)**。

> 若不用哈希表，每次递归都线性扫描 `inorder` 找根，最坏情况下（树退化为链表）每次扫描 O(n)，共 n 层，时间复杂度退化为 O(n²)。

------

### 空间复杂度：O(n)

1. **哈希表**
   存储了 n 个键值对，占用 **O(n)** 空间。
2. **递归栈**
   最坏情况：树是一个单链表（每个节点只有左子或只有右子），递归深度 = n，栈空间 **O(n)**。
   平均情况：树比较平衡时，递归深度 O(log n)，但空间复杂度按最坏情况估算，仍为 **O(n)**。
3. **构造的二叉树**
   题目要求返回的二叉树本身包含 n 个节点，占用 O(n) 空间。
   但通常空间复杂度只计算**额外辅助空间**（不计返回结果），因此答案中一般说“额外空间复杂度 O(n)”，或者明确列出各部分后总结为 O(n)。

> 若不计返回的树，总辅助空间 = 哈希表 O(n) + 递归栈 O(n) = **O(n)**。

# 437. 路径总和 III

## 法1:暴力(以每个节点为起点向下搜索)

**思路**：

- 外层递归遍历每个节点，内层递归以该节点为起点向下累加，统计和为 `targetSum` 的路径数。

- 从当前节点 `node`开始，不断向下延伸，一旦当前 `curSum == targetSum` 就计数一次（路径可以中间停下，不一定到叶子）

- 外层`pathSum`递归遍历每个节点，将每个节点作为起点（获取当前节点作为起点时，节点值之和等于 `targetSum` 的个数），返回每个节点作为起点时最终的累加结果。

```c++
class Solution {
public:
    long long pathSum(TreeNode* root, int targetSum) {
        if(!root)   return 0;
   // 以当前节点为起点的路径数 + 左子树中的路径数 + 右子树中的路径数
        return countFromNode(root,0,targetSum) 
            + pathSum(root->left,targetSum) 
            + pathSum(root->right,targetSum);
    }
private:
    // 从节点 node 开始，以当前累积和 curSum 向下搜索
    long long countFromNode(TreeNode* node,long long curSum,int targeSum){
        if(!node)   return 0;
        curSum += node->val;
        return (curSum == targeSum ? 1:0)
            + countFromNode(node->left,curSum,targeSum)
            + countFromNode(node->right,curSum,targeSum);
    }
};
```

### 复杂度分析

- **时间复杂度** O(n²)，最坏情况（链状树）。
- **空间复杂度** O(n)（递归栈）。

## 法2：前缀和 + 哈希表（最优解）

### 思路

- 定义**前缀和**：从根节点到当前节点的路径上所有节点值的和，记为 `curSum`。
- 对于当前节点，如果我们能知道**之前某个祖先节点**（包括根）到根的前缀和为 `curSum - targetSum`，那么从这个祖先节点的**下一个节点**到当前节点的路径和就是 `targetSum`。
- 于是问题转化为：在 DFS 过程中，实时维护一个哈希表 `prefix`，记录“从根到当前节点”路径上出现过的所有前缀和及其出现次数。对每个节点，只需要查询 `prefix[curSum - targetSum]` 的值，累加到答案中。

```c++
        10
       /  \
      5   -3
     / \    \
    3   2    11
   / \   \
  3  -2   1
```

当`targetSum = 8`：`ans = 3`

- 10+5+3 = 18，18-8=10，pre[10]=1,ans=0+1=1; `5->3`
- 10+5+2+1 = 18, 18-8=10，pre[10]=1,ans=1+1=2; `5->2->1`
- 10+-3+11=18,18-8=10，pre[10]=1,ans=2+1=3; `-3->11`

当`targetSum = 6`：`ans = 2`

- 10+5+3+3=21,21-6=15,pre[15]=1,ans=0+1=1; `3->3`当`curSum=21`(`10->5->3->3`)时,如果有某个祖先节点到根节点的前缀和为15(`21-6`)时(`10->5`),则路径的剩余节点前缀和(从该祖先节点的下一个节点到当前节点`3->3`)为 `targetSum`
- 10+5+3+-2=16,16-6=10,pre[10],ans=1+1=2; `5->3->-2`当`curSum=16`(`10->5->3->-2`)时,如果有某个祖先节点到根节点的前缀和为10(`16-6`)时(`10`),则路径的剩余节点前缀和(从该祖先节点的下一个节点到当前节点`5->3->-2`)为 `targetSum`

### 关键点详解

#### 1. 为什么 `prefix[0] = 1` ？

- 空前缀表示“还没有选任何节点”。如果 `curSum == targetSum`，那么 `curSum - target = 0`，这时 `prefix[0] = 1` 就能正确统计这条从根到当前节点的路径。

#### 2. 为什么先查询，后插入？

- **顺序固定：`ans += prefix[curSum - target];` 必须放在 `prefix[curSum]++;` 之前**。
- 原因：如果 `targetSum == 0`，则查询条件是 `prefix[curSum]`。若先插入再查询，就会把当前节点自己也算作一条“空路径”（长度 0），这是不合法的。先查询可以保证当前节点不会被统计到自己的路径中。
- 示例：单节点 `[1]`，`targetSum = 0`
  - 先查询：`curSum=1`，`prefix[1]` 此时为 0，ans 不变 → 正确 0
  - 先插入：`prefix[1]` 变成 1，再查询 `prefix[1]` 得到 1 → 错误地认为有 1 条路径

#### 3. 为什么 `curSum` 用值传递而不是引用？

- 因为每个递归调用需要独立保存自己路径上的累积和，子节点只需要父节点传递过来的值，不需要修改父节点的值。
- 值传递让每个递归层级拥有自己的 `curSum` 副本，互不干扰，逻辑简单安全。
- 若用引用，子节点会改变父节点的 `curSum`，导致兄弟节点计算错误。

#### 4. 为什么需要回溯 `prefix[curSum]--` ?

- 因为哈希表记录的是**当前递归路径**上前缀和出现的次数。当递归返回上一层时，当前节点及其子节点的路径已经结束，继续保留该前缀和会干扰其他分支（不同路径上的前缀和可能相同，但不应跨路径累计）。
- 回溯就是“撤销”本次添加，保证哈希表里始终只保存从根到当前正在访问的节点这条路径上的前缀和。

### 代码

```c++
class Solution {
private:
    unordered_map<long long, int> prefix;  // 前缀和 -> 出现次数
    int ans = 0;
    int target = 0;

public:
    void dfs(TreeNode* node, long long curSum) {
        if (!node) return;

        // 1. 更新当前前缀和
        curSum += node->val;

        // 2. 查询：有多少个祖先节点的前缀和等于 curSum - target
        //    这些祖先节点到当前节点的路径和就是 target
        ans += prefix[curSum - target];

        // 3. 记录当前前缀和，供子孙节点使用
        prefix[curSum]++;

        // 4. 递归处理左右子树
        dfs(node->left, curSum);
        dfs(node->right, curSum);

        // 5. 回溯：当前节点处理完毕，从哈希表中移除当前前缀和
        //    避免影响其他分支（因为路径已经结束）
        prefix[curSum]--;
    }

    int pathSum(TreeNode* root, int targetSum) {
        // 初始化：空前缀和为 0，出现 1 次（表示从根节点直接开始的路径）
        prefix[0] = 1;
        target = targetSum;
        dfs(root, 0);
        return ans;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)，每个节点访问一次，哈希表操作 O(1)。
- **空间复杂度**：O(n)，递归栈深度最坏 O(n)，哈希表大小 O(n)。

### 易错点提醒

| 易错点                      | 正确做法                                         |
| :-------------------------- | :----------------------------------------------- |
| 忘记初始化 `prefix[0] = 1`  | 必须初始，否则从根开始的路径会被漏掉             |
| 先插入后查询                | 先查询后插入，防止 `targetSum == 0` 时统计空路径 |
| 用 `int` 保存前缀和         | 可能溢出，使用 `long long`                       |
| 忘记回溯 `prefix[curSum]--` | 导致不同分支的前缀和错误累加                     |
| 递归参数 `curSum` 使用引用  | 必须用值传递，确保兄弟子树独立                   |

# 236. 二叉树的最近公共祖先

**最近公共祖先**（Lowest Common Ancestor，LCA）。

**提示：**

- 树中节点数目在范围 `[2, 105]` 内。
- `-109 <= Node.val <= 109`
- 所有 `Node.val` `互不相同` 。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

```c++
          3
        /   \
       5     1
      / \   / \
     6   2 0   8
        / \
       7   4
```

## 法1:递归后序遍历

### 思路

**核心思想**：**自底向上**寻找 `p` 和 `q`。用递归在左右子树中分别查找，然后根据左右子树的结果判定当前节点是否为 LCA。

**递归函数的定义**：

- 如果当前节点为 `null`，返回 `null`，表示该路径没找到任何目标节点。
- 如果当前节点是 `p` 或 `q`，直接返回当前节点（表示找到了其中一个）。
- 否则，递归查找左子树和右子树，得到 `left` 和 `right`。
  - **左右子树各找到一个节点**（即 `left != null && right != null`）：说明 `p` 和 `q` 分别在当前节点的左右两侧，那么当前节点就是它们的最近公共祖先，返回当前节点。
  - **只有一侧找到节点**：说明两个节点都在其中一侧（或者已经在这侧找到了 LCA），将找到的那个非空结果向上传递。
  - **两侧都没找到**：返回 `null`。

这样递归回到根节点时，最终返回的就是 LCA。

**关键点**：题目保证 `p` 和 `q` 一定在树中且节点值各不相同，所以上述逻辑不需要额外判断节点是否存在。

### 代码

```c++
#include <iostream>
#include <vector>
#include <string>
#include <unordered_map>
#include <queue>
using namespace std;

// 二叉树节点的定义:
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};


// 根据层序遍历序列构建二叉树（"null" 表示空节点）
TreeNode* build_levelOrder(const vector<string>& nodes){
    if (nodes.empty() || nodes[0] == "null") return nullptr;

    // 创建根节点
    TreeNode* root = new TreeNode(stoi(nodes[0]));
    queue<TreeNode*> q;
    q.push(root);

    int i = 1;  // 从第二个元素开始处理
    while (!q.empty() && i < nodes.size()) {
        TreeNode* current = q.front();
        q.pop();

        // 处理左子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->left = new TreeNode(stoi(nodes[i]));
            q.push(current->left);
        }
        i++;

        // 处理右子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->right = new TreeNode(stoi(nodes[i]));
            q.push(current->right);
        }
        i++;
    }
    return root;
}

void printPreorder(TreeNode* root){
    if(!root){
        cout<<"null"<<" ";//可以输出时不加null
        return ;
    }
       
    cout<<root->val<<" ";
    printPreorder(root->left);
    printPreorder(root->right);
}

//层序遍历输出:
vector<string> levelOrderSerialize(TreeNode* root){
    vector<string> result;
    if(!root)   
        return result;
    queue<TreeNode*> q;
    q.push(root);
    while(!q.empty()){
        TreeNode* curr = q.front();
        q.pop();
        if(curr){
            // 无论子节点是否为空，都入队，以保持占位
            result.push_back(to_string(curr->val));
            q.push(curr->left);
            q.push(curr->right);
        }
        else{
            result.push_back("null");
        }
    }
    // 去除末尾多余的 "null"，避免序列过长
    while(!result.empty() && result.back() == "null"){
        result.pop_back();
    }
    return result;
}

//后序释放
void deleteTree(TreeNode* root){
    if(!root)
        return;//空节点本身就指向nullptr,不用释放
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // 递归终止条件：空节点、或找到了 p/q 之一
        if (root == nullptr || root == p || root == q) {
            return root;
        }

        // 后序遍历：先左、再右
        TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        // 处理“根”：左右都找到了 → 当前 root 就是 LCA
        if (left != nullptr && right != nullptr) {
            return root;
        }

        // 否则，哪个非空就向上传递哪个（可能是已找到的 LCA，或 p/q，或 nullptr）
        return left != nullptr ? left : right;
    }

    //获取p,q节点
    TreeNode* dfsnode(TreeNode* node,int target){
        if(!node)   return nullptr;
        //如果自己节点值是target则直接返回自己节点
        if(node->val == target)  return node;//返回自己节点

        //递归调用左子树,并用leftresult节点接收结果,
        //如果直接用node接收结果,node将发生改变1.目标节点2.nullptr,会导致无法进行右子树的递归
        TreeNode* leftresult =  dfsnode(node->left,target);
        //如果左子树递归结果leftresult的节点值是target则直接返回左子树递归结果
        if(leftresult) return leftresult;//返回左子树节点
        //(只需检查 leftresult 是否非空即可，因为递归返回的节点值一定等于 target（如果非空）。)

        //递归调用右子树
        return dfsnode(node->right,target);//返回右子树节点
    }
};

int main()
{
    //通过vector构建二叉树
    //预先将层序遍历序列存入 vector（"null" 表示空节点）
    vector<string> levelOrder = 
    {"3","5","1","6","2","0","8","null","null","7","4"};
    
    TreeNode* root = build_levelOrder(levelOrder);
    cout<<"生成的二叉树的先序遍历为:"<<endl;
    printPreorder(root);
    cout<<endl;

    Solution s;
    TreeNode *p = s.dfsnode(root,5);
    TreeNode* q = s.dfsnode(root,4);
    TreeNode* result = s.lowestCommonAncestor(root,p,q);

    std::cout<<p->val<<"节点和"<<q->val<<"节点的最近公共祖先为:"<<result->val<<std::endl;

    deleteTree(root);
    return 0;   
}
```

### 过程

#### 例 1：p = 5, q = 1

我们要找 5 和 1 的最近公共祖先。

- 从根节点 `3` 开始：
  - 当前不是 5 也不是 1，递归进入左子树（节点 5）和右子树（节点 1）。
- 左子树递归调用（节点 5）：
  - 当前节点是 `p = 5`，命中！直接返回节点 `5`（不再往下找）。
- 右子树递归调用（节点 1）：
  - 当前节点是 `q = 1`，命中！直接返回节点 `1`。
- 回到节点 `3`：
  - `left = 5`，`right = 1`，均非空 → 说明 5 在左，1 在右，节点 `3` 就是它们的最近公共祖先。

**结果：3** ✅

---

#### 例 2：p = 5, q = 4

找 5 和 4 的 LCA。此时 5 本身就是 4 的祖先。

- 根节点 `3` 递归：
  - 左子树（节点 5）：
    - 当前节点是 `p = 5`，命中，直接返回节点 `5`。
    - 注意：因为命中 `p`，不会再继续遍历 5 的子树，所以底下的 4 暂时不会被访问。
  - 右子树（节点 1）：
    - 不是 5 也不是 4，递归左右子树：
      - 左子节点 `0`：不是，左右子均为 null → 返回 null。
      - 右子节点 `8`：同理返回 null。
    - 节点 1 的 `left = null, right = null` → 返回 null。
- 回到根节点 `3`：
  - `left = 5`，`right = null`，一侧非空 → 将 `5` 向上返回。

**结果：5** ✅
解释：5 命中后直接返回，右子树完全没找到 4（因为 4 在 5 下面，但被提前截断了），此时意味着另一个节点也在 5 的子树中，所以 5 就是 LCA。

---

#### 例 3：p = 7, q = 4

找 7 和 4 的 LCA，它俩都在节点 2 的下面。

- 根节点 `3`：
  - 左子树（节点 5）：
    - 不是 7 也不是 4，递归左右：
      - 左子 `6`：非，左右空 → null
      - 右子 `2`：
        - 不是 7 或 4，递归左右：
          - 左子 `7`：是 p，返回节点 `7`
          - 右子 `4`：是 q，返回节点 `4`
        - 节点 2 得到 `left = 7, right = 4`，均非空 → 返回节点 `2`（LCA 找到！）
    - 节点 5 得到 `left = null, right = 2` → 返回 `2`
  - 右子树（节点 1）：
    - 查找完全找不到 p 和 q → 返回 null
- 回到根节点 `3`：
  - `left = 2, right = null` → 返回 `2`

**结果：2** ✅

---

#### 例 4：p = 6, q = 4

1. 从根 `3` 开始，不是 `p` 也不是 `q`，先递归左子树 `5`，再右子树 `1`。
2. **递归左子树节点 `5`**：
   - 不是 `p/q`，先左子树 `6`，再右子树 `2`。
   - 递归左 `6`：`root == p`，立即返回 `6`。
     → 节点 `5` 的 `left = 6`。
   - 递归右 `2`：
     - 不是 `p/q`，先左子树 `7`，再右子树 `4`。
     - 左 `7`：不是 `p/q`，左右均返回 `null`，返回 `null`。
     - 右 `4`：`root == q`，立即返回 `4`。
     - `2` 的 `left = null, right = 4`，不同时非空，返回非空的那个 → 返回 `4`。
   - 回到 `5`：`left = 6，right = 4`，**两者都非空** → `5` 就是最近公共祖先，返回 `5`。
3. **递归右子树节点 `1`**：
   - 不是 `p/q`，递归左 `0`（返回 `null`），右 `8`（返回 `null`），最终返回 `null`。
4. 回到根 `3`：`left = 5，right = null`，返回非空的 `5`。

**最终结果：5** ✅

### 复杂度分析

- **时间复杂度**：O(N)，最坏情况需要遍历整棵树的所有节点。
- **空间复杂度**：O(H)，H 为树的高度，递归调用栈的深度。最坏情况（树呈链表状）为 O(N)，平衡树为 O(log N)。

## ==法2:存储父节点(迭代 + 哈希表)==

### 思路

1. **构建父节点哈希表**
   - 使用**栈**进行深度优先遍历（DFS），当然也可以用队列进行广度优先遍历（BFS）。
   - 遍历过程中，对于每个孩子节点，记录其父节点到 `parent` 哈希表中。
   - 根节点的父节点设为 `nullptr`。
2. **标记 p 的祖先**
   - 创建哈希集合 `ancestors`。
   - 从 `p` 开始，沿着 `parent` 不断向根方向移动，将沿途所有节点插入 `ancestors` 集合。
   - 这样 `ancestors` 就包含了 `p` 自己以及所有祖先节点。
3. **寻找 LCA**
   - 从 `q` 开始，同样沿着 `parent` 向上移动。
   - 对每个节点检查是否在 `ancestors` 中。
   - **第一个**在集合中出现的节点，就是 `p` 和 `q` 的最近公共祖先。

### 代码

```c++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // 1. 存储每个节点的父节点（用栈模拟DFS/或队列BFS）
        unordered_map<TreeNode*, TreeNode*> parent;
        stack<TreeNode*> stk;
        
        parent[root] = nullptr;   // 根节点没有父节点
        stk.push(root);
        
        // 遍历整棵树，记录所有节点的父节点
        while (!stk.empty()) {
            TreeNode* node = stk.top();
            stk.pop();
            
            if (node->left) {
                parent[node->left] = node;
                stk.push(node->left);
            }
            if (node->right) {
                parent[node->right] = node;
                stk.push(node->right);
            }
        }
        
        // 2. 标记 p 到根路径上的所有节点
        unordered_set<TreeNode*> ancestors;
        TreeNode* cur = p;
        while (cur != nullptr) {
            ancestors.insert(cur);
            cur = parent[cur];   // 向上跳转
        }
        
        // 3. 从 q 向上查找，第一个出现在 ancestors 中的节点就是 LCA
        cur = q;
        while (ancestors.find(cur) == ancestors.end()) {
            cur = parent[cur];
        }
        return cur;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(N)，遍历树 O(N)，向上跳转路径长度最坏 O(N)，总体 O(N)。
- **空间复杂度**：O(N)，`parent` 哈希表存储所有节点的父节点，O(N)；`ancestors` 集合存储 p 的祖先，最坏 O(N)。
