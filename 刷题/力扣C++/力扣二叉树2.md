# ==二叉搜索树（BST）和平衡二叉搜索树（如 AVL 树）==

## 一、什么是二叉搜索树（BST）

**二叉搜索树**是一种二叉树，它满足以下性质：

- 对于任意节点 `N`：
  - 左子树中所有节点的值 **<** `N` 的值
  - 右子树中所有节点的值 **>** `N` 的值
- 通常假设没有重复值（也可以约定放左或放右）。

**优点**：查找、插入、删除的平均时间复杂度为 **O(log n)**。
**缺点**：最坏情况下（顺序插入）会退化成链表，时间复杂度变为 **O(n)**。

## 二、什么是平衡二叉搜索树

**平衡二叉搜索树**是在 BST 的基础上，增加了“平衡条件”，使得树的高度始终保持 **O(log n)**，避免性能退化。

常见的平衡 BST 有：

- **AVL 树**：严格平衡，任意节点左右子树高度差 ≤ 1。
- **红黑树**：弱平衡，通过颜色约束保证最长路径 ≤ 2 × 最短路径（`std::map` 通常用它实现）。

# 108. 将有序数组转换为二叉搜索树

- 树、二叉搜索树、数组、分治、二叉树

二叉搜索树的中序遍历就是一个升序序列。要想从一个升序序列反推回一个平衡二叉树，最直接的方式是：**“二分递归”**：

1. 找到数组的**中间元素**作为根节点。
2. 用中间元素左边的子数组递归构建**左子树**。
3. 用中间元素右边的子数组递归构建**右子树**。

> 由于每次取中点，左右子树的元素个数最多相差 1，天然满足高度平衡。
>
> **中点选择**：当数组长度为偶数时，左中/右中都可以，题目没有强制要求。一般习惯取 `mid = left + (right - left) / 2`或 `(left + right) / 2` （偏左），即偶数时选取中间偏左的节点作为中间元素。

## 法一：二分递归，总是选择中间位置左边的数字作为根节点

-  `mid = left + (right - left) / 2`或 `(left + right) / 2` 

```c++
#include <iostream>
#include <queue>
#include <vector>
#include <algorithm>
using namespace std;

// 二叉树节点的定义:
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};

//中序遍历输出:
void printInorder(TreeNode* root){
    if(!root){
        cout<<"null"<<" ";//可以输出时不加null
        return ;
    }
    printInorder(root->left);
    cout<<root->val<<" ";
    printInorder(root->right);
}

//层序遍历输出:
vector<string> levelOrderSerialize(TreeNode* root){
    vector<string> result;
    if(!root)   
        return result;
    queue<TreeNode*> q;
    q.push(root);
    while(!q.empty()){
        TreeNode* curr = q.front();
        q.pop();
        if(curr){
            // 无论子节点是否为空，都入队，以保持占位
            result.push_back(to_string(curr->val));
            q.push(curr->left);
            q.push(curr->right);
        }
        else{
            result.push_back("null");
        }
    }
    // 去除末尾多余的 "null"，避免序列过长
    while(!result.empty() && result.back() == "null"){
        result.pop_back();
    }
    return result;
}

//后序释放
void deleteTree(TreeNode* root){
    if(!root)
        return;//空节点本身就指向nullptr,不用释放
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

class Solution {
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums,0,nums.size()-1);
    }
    TreeNode* build(const vector<int>& nums,int left,int right){
        if(left > right) return nullptr;//空区间

        //取中间节点(偏左)
        int mid = (left + right)/2;//left +(right-left)/2
        TreeNode* root = new TreeNode(nums[mid]);

        //递归构建左、右子树
        root->left = build(nums,left,mid-1);
        root->right = build(nums,mid+1,right);

        return root;
    }
};

int main(){
    Solution s;
    vector<int> nums = {1,2,3,4,5};
    TreeNode* root = s.sortedArrayToBST(nums);

    cout<<"生成的二叉树中序遍历为:"<<endl;
    printInorder(root);
    cout<<endl;


    cout<<"生成的二叉树层序遍历为:"<<endl;
    vector<string> result = levelOrderSerialize(root);
    for(const string& s: result){
        std::cout<<s<<" ";
    }
    cout<<endl;

    return 0;
}
```

`mid = (left + right + rand() % 2)/2`

## 复杂度分析

- **时间复杂度**：`O(n)`，每个元素只访问一次。
- **空间复杂度**：`O(log n)`（递归栈深度，树是平衡的），如果不计递归栈则可视为 `O(n)`（生成整棵树）。

# 98. 验证二叉搜索树

给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：

- 节点的左子树只包含 **严格小于** 当前节点的数。
- 节点的右子树只包含 **严格大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

**提示：**

- 树中节点数目范围在`[1, 104]` 内
- -2^31^ <= Node.val <= 2^31^-1

## 法一：中序遍历-严格递增检查法+sort排序

- 利用BST的特性，将二叉搜索树的节点值存储到`vector<int>`中
- BST 特性：（左 < 中 < 右）
  - 对于任意节点 `N`：
    - 左子树中所有节点的值 **<** `N` 的值
    - 右子树中所有节点的值 **>** `N` 的值
- 二叉搜索树的中序遍历就是一个升序序列。
- 如果一个二叉树的中序遍历是一个升序序列，则说明这是一个二叉搜索树。
- 法1：将这棵树的中序遍历存储到数组result中，在将这个数组的升序序列存储到sort_result中，如果`result == sort_resul`t并且在`sort_result`中元素值严格单调递增，则说明这棵树是二叉搜索树。

```c++
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        vector<int> result;
        In_order_traversal(root,result);
        vector<int> sort_result = result;
        std::sort(sort_result.begin(),sort_result.end());
        if(result != sort_result) return false;
        for(int i = 1;i<sort_result.size();++i){
            if(sort_result[i] == sort_result[i-1])  return false;
        }
        return true;
    }
    void In_order_traversal(TreeNode* root,vector<int>& result){
        if(!root) return;
        In_order_traversal(root->left,result);
        result.push_back(root->val);
        In_order_traversal(root->right,result);
    }
};
```

## 法二：中序遍历-严格递增检查法+直接判断单调递增

法2：将这棵树的中序遍历存储到数组result中，并直接判断result是否是单调递增的，如果不是则返回false，否则返回true。

```c++
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        vector<int> result;
        In_order_traversal(root,result);
        for(int i = 1;i<result.size();++i){
            if(result[i] <= result[i-1])
                return false;
        }
        return true;
    }
    void In_order_traversal(TreeNode* root,vector<int>& result){
        if(!root) return;
        In_order_traversal(root->left,result);
        result.push_back(root->val);
        In_order_traversal(root->right,result);
    }
};
```

## 法三：上下界递归+long long无穷值

- 根据 BST 的定义，**每个节点**的值都必须落在一个**合法的开区间**内。
- 对于根节点，范围是 `(-∞, +∞)`。
- 对于左子节点，范围变为 `(父节点的下界, 父节点的值)`。
- 对于右子节点，范围变为 `(父节点的值, 父节点的上界)`。
- 递归地检查每个节点是否满足它自己的范围。

- **为何用 `long long而不用int`**：因为节点值可能是 `INT_MIN` 或 `INT_MAX`

  （-2^31^ <= Node.val <= 2^31^-1），如果直接用 `int` 表示无穷，则无法区分“边界值”，所以用 `long long` 的极值。

  - 当这个二叉树是一个只包含根节点`INT_MAX`或是`INT_MIN`时
    - 初始调用 `validate(root, INT_MIN, INT_MAX)`
    - 判断条件：当root->val = INT_MAX时，INT_MAX >= hight，函数直接返回 `false`
    - 判断条件：当root->val = INT_MIN时，INT_MIN  <=  low，函数直接返回 `false`
    - 但一个仅包含根节点 `INT_MAX`或是`INT_MIN` 的二叉树，**其实是合法的 BST**。会导致误判

- **提前终止**：一旦发现当前节点值越界，立即返回 `false`，不再深入子树。

- **信息流向**：**自顶向下**传递限制条件。

```c++
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        // 初始范围：负无穷到正无穷
        // 使用 long long 最小值/最大值来表示无穷，避免节点值为 INT_MIN/INT_MAX 时的边界问题
        return validate(root, LONG_MIN, LONG_MAX);
    }

    // 检查以 root 为根的子树中，所有节点的值是否都在 (low, high) 区间内
    bool validate(TreeNode* root, long long low, long long high) {
        // 空节点自然满足 BST
        if (!root) return true;

        // 当前节点值必须严格大于 low 且严格小于 high
        if (root->val <= low || root->val >= high) 
            return false;

        // 递归检查左右子树，同时缩小范围
        // 左子树：上界变为当前节点值
        // 右子树：下界变为当前节点值
        return validate(root->left, low, root->val) 
            && validate(root->right, root->val, high);
    }
};
```

## 法四：上下界递归+nullptr无穷值

```c++
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        // 初始调用：根节点没有上下界限制
        return validate(root, nullptr, nullptr);
    }

    // low: 指向当前子树允许的最小值（不含该值，即必须严格大于 *low）
    // high: 指向当前子树允许的最大值（不含该值，即必须严格小于 *high）
    // nullptr 表示该侧无限制
    bool validate(TreeNode* root, const int* low, const int* high) {
        if (!root) return true;   // 空节点一定合法

        // 如果有下界限制，检查当前节点值是否严格大于下界
        if (low != nullptr && root->val <= *low) 
            return false;

        // 如果有上界限制，检查当前节点值是否严格小于上界
        if (high != nullptr && root->val >= *high) 
            return false;

        // 递归检查左子树：上界变为当前节点值地址，下界保持不变
        // 递归检查右子树：下界变为当前节点值地址，上界保持不变
        return validate(root->left, low, &(root->val)) 
            && validate(root->right, &(root->val), high);
    }
};
```

## 法五：中序遍历+记录前驱-递归隐式栈

```c++
#include <iostream>
#include <vector>
#include <string>
#include <queue>
#include <algorithm>
using namespace std;

// 二叉树节点的定义:
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};

// 根据层序遍历序列构建二叉树（"null" 表示空节点）
TreeNode* build_levelOrder(const vector<string>& nodes){
    if (nodes.empty() || nodes[0] == "null") return nullptr;

    // 创建根节点
    TreeNode* root = new TreeNode(stoi(nodes[0]));
    queue<TreeNode*> q;
    q.push(root);

    int i = 1;  // 从第二个元素开始处理
    while (!q.empty() && i < nodes.size()) {
        TreeNode* current = q.front();
        q.pop();

        // 处理左子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->left = new TreeNode(stoi(nodes[i]));
            q.push(current->left);
        }
        i++;

        // 处理右子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->right = new TreeNode(stoi(nodes[i]));
            q.push(current->right);
        }
        i++;
    }
    return root;
}

class Solution {
public:
    // 用于记录中序遍历中刚刚访问过的节点值
    long long prev = LONG_MIN;// 初始化为负无穷
    
    bool isValidBST(TreeNode* root) {
        // 空树是 BST
        if(!root) return true;

        //1. 递归检查左子树
        //当左子树递归结果isValidBST(root->left)不为true时,进入if,返回false
        //如:当左子树为nullptr时,isValidBST(nullptr) = true;
        if(!isValidBST(root->left))
            return false;
        
        //2.检查当前节点
        //当前节点必须严格大于前驱值
        if(root->val <= prev)
            return false;//更新前驱值
        prev = root->val;

        //3.递归检查右子树
        return isValidBST(root->right);
    }
};

//后序释放
void deleteTree(TreeNode* root){
    if(!root)
        return;//空节点本身就指向nullptr,不用释放
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main()
{
    //通过vector构建二叉树
    //预先将层序遍历序列存入 vector（"null" 表示空节点）
    vector<string> levelOrder = {"2","1","3"};
    TreeNode* root = build_levelOrder(levelOrder);

    Solution s;
    bool flag = s.isValidBST(root);
    std::cout<<flag<<std::endl;

    deleteTree(root);
    return 0;   
}
```

## 法六：中序遍历+记录前驱-迭代显式栈

```c++
#include <iostream>
#include <vector>
#include <string>
#include <queue>
#include <stack>
#include <algorithm>
using namespace std;

// 二叉树节点的定义:
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};

// 根据层序遍历序列构建二叉树（"null" 表示空节点）
TreeNode* build_levelOrder(const vector<string>& nodes){
    if (nodes.empty() || nodes[0] == "null") return nullptr;

    // 创建根节点
    TreeNode* root = new TreeNode(stoi(nodes[0]));
    queue<TreeNode*> q;
    q.push(root);

    int i = 1;  // 从第二个元素开始处理
    while (!q.empty() && i < nodes.size()) {
        TreeNode* current = q.front();
        q.pop();

        // 处理左子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->left = new TreeNode(stoi(nodes[i]));
            q.push(current->left);
        }
        i++;

        // 处理右子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->right = new TreeNode(stoi(nodes[i]));
            q.push(current->right);
        }
        i++;
    }
    return root;
}

class Solution {
public:
    bool isValidBST(TreeNode* root) {
        stack<TreeNode*> stk;
        long long prev = LONG_MIN;

        TreeNode* curr = root;
        while (curr || !stk.empty()) {
            // 一路向左，将所有左节点入栈
            while (curr) {
                stk.push(curr);
                curr = curr->left;
            }
            // 弹出栈顶节点，此时即为中序访问的节点
            curr = stk.top(); stk.pop();

            // 检查是否严格大于前驱
            if (curr->val <= prev) 
                return false;
            prev = curr->val;

            // 转向右子树
            curr = curr->right;
        }
        return true;
    }
};

//后序释放
void deleteTree(TreeNode* root){
    if(!root)
        return;//空节点本身就指向nullptr,不用释放
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main()
{
    //通过vector构建二叉树
    //预先将层序遍历序列存入 vector（"null" 表示空节点）
    vector<string> levelOrder = {"2","1","3"};
    TreeNode* root = build_levelOrder(levelOrder);

    Solution s;
    bool flag = s.isValidBST(root);
    std::cout<<flag<<std::endl;

    deleteTree(root);
    return 0;   
}
```

## 复杂度分析

| 解法                          | 时间复杂度                          | 空间复杂度（平均/最坏）             |
| :---------------------------- | :---------------------------------- | :---------------------------------- |
| **法一 中序+sort+去重**       | O(n + n log n + n) = **O(n log n)** | O(n)（递归栈 O(h) + 两个数组 O(n)） |
| **法二 中序+直接检查递增**    | **O(n)**                            | O(n)（递归栈 O(h) + 数组 O(n)）     |
| **法三 上下界递归 long long** | **O(n)**                            | O(h) → 最坏 O(n)（递归栈）          |
| **法四 上下界递归 nullptr**   | **O(n)**                            | O(h) → 最坏 O(n)（递归栈）          |
| **法五 中序递归+前驱变量**    | **O(n)**                            | O(h) → 最坏 O(n)（递归栈）          |
| **法六 中序迭代栈+前驱变量**  | **O(n)**                            | O(h) → 最坏 O(n)（显式栈）          |

- **法一** 多了一步 `std::sort`，将线性时间复杂度提升到 O(n log n)，且额外存储两个大小 n 的数组，空间效率较差。
- **法二** 省去了排序，时间降至 O(n)，但仍需要存储全节点值的数组，空间 O(n)。
- **法三/四** 只维护递归栈，空间最优为 O(h)，时间 O(n)，且能提前终止。
- **法五** 同样是 O(n) 时间、O(h) 空间，但依赖递归；若树不平衡可能栈溢出，故 **法六** 用迭代栈更安全，复杂度不变。

**总结**：最优的时间复杂度是 O(n)，最优的空间复杂度是 O(h)（最坏 O(n)），**法三～法六** 都能达到。其中 **法六** 在不使用递归的情况下兼顾了效率和栈安全，是工程中最常用的写法之一。

# 230. 二叉搜索树中第 K 小的元素

**进阶：**如果二叉搜索树经常被修改（插入/删除操作）并且你需要频繁地查找第 `k` 小的值，你将如何优化算法？

## 法1：中序遍历+存储到`vector<int>`中

**思路**：因为二叉搜索树的中序遍历是有序的，将二叉搜索树的中序遍历的结果存储到`vector<int>`中可以得到一个升序序列，要找到二叉搜索树的第K小值（K从1开始），即找到数组的第K-1下标所对应的元素值即可。

```c++
#include <iostream>
#include <vector>
#include <string>
#include <queue>
using namespace std;

// 二叉树节点的定义:
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};

// 根据层序遍历序列构建二叉树（"null" 表示空节点）
TreeNode* build_levelOrder(const vector<string>& nodes){
    if (nodes.empty() || nodes[0] == "null") return nullptr;

    // 创建根节点
    TreeNode* root = new TreeNode(stoi(nodes[0]));
    queue<TreeNode*> q;
    q.push(root);

    int i = 1;  // 从第二个元素开始处理
    while (!q.empty() && i < nodes.size()) {
        TreeNode* current = q.front();
        q.pop();

        // 处理左子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->left = new TreeNode(stoi(nodes[i]));
            q.push(current->left);
        }
        i++;

        // 处理右子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->right = new TreeNode(stoi(nodes[i]));
            q.push(current->right);
        }
        i++;
    }
    return root;
}

class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        vector<int> vec;
        In_order_traveral(root,vec);
        return vec[k-1];
    }
    void In_order_traveral(TreeNode* root,vector<int>& vec){
        if(!root)   return;
        In_order_traveral(root->left,vec);
        vec.push_back(root->val);
        In_order_traveral(root->right,vec);
    }
};
```

## 法2：中序遍历+迭代显式栈

**核心原理**
二叉搜索树的中序遍历会得到一个**严格递增**的序列，因此中序遍历到的第 K 个节点就是整棵树的第 K 小元素。

1. **数据结构准备**

   - **使用一个栈 `stk` 来显式保存待处理的节点。**
   - 用一个指针 `root` 指向当前正在访问的子树的根节点（初始为整棵树的根）。

2. **外部循环：模拟中序遍历的推进**
   条件：`root != nullptr || !stk.empty()`
   只要还有未处理的节点（当前子树的根不空，或栈里还有节点），就继续遍历。

3. **内部循环：一路向左，压栈**

   ```cpp
   while(root != nullptr) {
       stk.push(root);
       root = root->left;
   }
   ```

   - 这个循环会将当前节点及其**所有左后代**依次压入栈中。
   - 执行完后，`root` 变为 `nullptr`，此时栈顶存放的是**整棵树（或子树）中最靠左、且尚未访问的节点**。
   - 这正是中序遍历“左 – 根 – 右”中，第一个应该被访问的节点（最左节点）。

4. **弹出并访问节点**

   - 从栈顶弹出节点：`root = stk.top(); stk.pop();`
   - 这个弹出的节点就是当前中序序列中的下一个节点。
   - 访问该节点：计数器 `k` 减 1。

5. **检查是否命中第 K 小**

   - 若 `--k == 0`，说明当前节点恰好是第 K 小的元素，跳出循环（或直接返回其值）。
   - 否则，当前节点不是目标，准备处理它的右子树。

6. **转向右子树**

   - 将 `root` 更新为刚弹出节点的右子节点：`root = root->right;`
   - 然后回到外部循环，`while(root != nullptr || !stk.empty())`
     - 如果右子树为不为空，继续上面第 3 步的“一路向左”，相当于对右子树进行相同的中序遍历操作。`while(root != nullptr){// 一路向左走到底`
     - 如果右子树为空，下一次循环会直接从栈中弹出下一个待处理节点（即某个祖先），这正好模拟了中序的“回溯”过程。`root = stk.top();// 弹出栈顶节点并访问`

7. **返回结果**

   - 当命中 K 后，循环提前结束。
   - 最终 `root` 指向的节点即为第 K 小元素，返回 `root->val`。

> **始终先处理最左节点（左），访问并计数（根），然后转到右子树（右），用栈记录回到祖先的路径。** 计数器从 K 递减到 0 的节点就是答案。

```c++

#include <vector>
#include <string>
#include <queue>
#include <stack>
using namespace std;

    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};

// 根据层序遍历序列构建二叉树（"null" 表示空节点）

    TreeNode* root = new TreeNode(stoi(nodes[0]));
    queue<TreeNode*> q;
    q.push(root);

    int i = 1;  // 从第二个元素开始处理
    while (!q.empty() && i < nodes.size()) {
        TreeNode* current = q.front();
        q.pop();

        // 处理左子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->left = new TreeNode(stoi(nodes[i]));
            q.push(current->left);
        }
        i++;

        // 处理右子节点
        if (i < nodes.size() && nodes[i] != "null") {
            current->right = new TreeNode(stoi(nodes[i]));
            q.push(current->right);
        }
        i++;
    }
    return root;
}

class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        stack<TreeNode*> stk;
        while(root != nullptr || !stk.empty()){
            // 一路向左，将所有左节点入栈
            while(root!=nullptr){
                stk.push(root);
                root = root->left;
            }
            // 弹出栈顶节点，此时即为中序访问的节点
            root = stk.top();
            stk.pop();
            //取出栈顶节点后,k的值-1
            --k;
            if(k == 0){//如果k的值为0,则表示当前节点的元素值就是原第K小的元素
                break;
            }
            //转向右子树
            root = root->right;
        }
        return root->val;//函数返回为该节点的元素值
    }
};

//后序释放
void deleteTree(TreeNode* root){
    if(!root)
        return;//空节点本身就指向nullptr,不用释放
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main()
{
    //通过vector构建二叉树
    //预先将层序遍历序列存入 vector（"null" 表示空节点）
    vector<string> levelOrder = {"3","1","4","null","2"};
    TreeNode* root = build_levelOrder(levelOrder);

    int k = 2;
    int result = 0;
    Solution s;
    result = s.kthSmallest(root,k);
    std::cout<<result<<std::endl;

    deleteTree(root);
    return 0;   
}
```

# 199. 二叉树的右视图

## 法1：层序遍历+队列+数组

- 思路：将二叉树的每一层存放到`vector<int>`类型的数组vec中，用`vector<int>`类型的数组`result`存储二叉树的右视图的结果数组。取得每一层中的最右侧节点，即每一层数组`vec`中的最后一个位置依次存入`result`中即可得到二叉树的右视图数组。

```c++
vector<string> levelOrderSerialize(TreeNode* root){
```

## 法2：层序遍历+队列+数组优化

- 思路：层序遍历时，每一层的节点直接判断该节点是否是该层的最后一个节点，即`i == q_size -1`，省去额外 vector 的开销。

```c++
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> result;
        queue<TreeNode*> q;
        if(root) 
            q.push(root);

        while(!q.empty()){
            int q_size = q.size(); // 先记录本层节点数
            for(int i = 0;i<q_size;++i){ // 固定循环次数
                TreeNode* curr = q.front();
                q.pop();
                if(i == q_size -1) // 当前层的最后一个节点
                    result.push_back(curr->val);
                if(curr->left) q.push(curr->left);
                if(curr->right) q.push(curr->right);
            }
           
        }
        return result;
    }
};
```
