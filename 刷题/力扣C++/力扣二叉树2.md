# ==二叉搜索树（BST）和平衡二叉搜索树（如 AVL 树）==

## 一、什么是二叉搜索树（BST）

**二叉搜索树**是一种二叉树，它满足以下性质：

- 对于任意节点 `N`：
  - 左子树中所有节点的值 **<** `N` 的值
  - 右子树中所有节点的值 **>** `N` 的值
- 通常假设没有重复值（也可以约定放左或放右）。

**优点**：查找、插入、删除的平均时间复杂度为 **O(log n)**。
**缺点**：最坏情况下（顺序插入）会退化成链表，时间复杂度变为 **O(n)**。

## 二、什么是平衡二叉搜索树

**平衡二叉搜索树**是在 BST 的基础上，增加了“平衡条件”，使得树的高度始终保持 **O(log n)**，避免性能退化。

常见的平衡 BST 有：

- **AVL 树**：严格平衡，任意节点左右子树高度差 ≤ 1。
- **红黑树**：弱平衡，通过颜色约束保证最长路径 ≤ 2 × 最短路径（`std::map` 通常用它实现）。

# 108. 将有序数组转换为二叉搜索树

- 树、二叉搜索树、数组、分治、二叉树

二叉搜索树的中序遍历就是一个升序序列。要想从一个升序序列反推回一个平衡二叉树，最直接的方式是：**“二分递归”**：

1. 找到数组的**中间元素**作为根节点。
2. 用中间元素左边的子数组递归构建**左子树**。
3. 用中间元素右边的子数组递归构建**右子树**。

> 由于每次取中点，左右子树的元素个数最多相差 1，天然满足高度平衡。
>
> **中点选择**：当数组长度为偶数时，左中/右中都可以，题目没有强制要求。一般习惯取 `mid = left + (right - left) / 2`或 `(left + right) / 2` （偏左），即偶数时选取中间偏左的节点作为中间元素。

## 法一：二分递归，总是选择中间位置左边的数字作为根节点

-  `mid = left + (right - left) / 2`或 `(left + right) / 2` 

```c++
#include <iostream>
#include <queue>
#include <vector>
#include <algorithm>
using namespace std;

// 二叉树节点的定义:
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};

//中序遍历输出:
void printInorder(TreeNode* root){
    if(!root){
        cout<<"null"<<" ";//可以输出时不加null
        return ;
    }
    printInorder(root->left);
    cout<<root->val<<" ";
    printInorder(root->right);
}

//层序遍历输出:
vector<string> levelOrderSerialize(TreeNode* root){
    vector<string> result;
    if(!root)   
        return result;
    queue<TreeNode*> q;
    q.push(root);
    while(!q.empty()){
        TreeNode* curr = q.front();
        q.pop();
        if(curr){
            // 无论子节点是否为空，都入队，以保持占位
            result.push_back(to_string(curr->val));
            q.push(curr->left);
            q.push(curr->right);
        }
        else{
            result.push_back("null");
        }
    }
    // 去除末尾多余的 "null"，避免序列过长
    while(!result.empty() && result.back() == "null"){
        result.pop_back();
    }
    return result;
}

//后序释放
void deleteTree(TreeNode* root){
    if(!root)
        return;//空节点本身就指向nullptr,不用释放
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

class Solution {
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums,0,nums.size()-1);
    }
    TreeNode* build(const vector<int>& nums,int left,int right){
        if(left > right) return nullptr;//空区间

        //取中间节点(偏左)
        int mid = (left + right)/2;//left +(right-left)/2
        TreeNode* root = new TreeNode(nums[mid]);

        //递归构建左、右子树
        root->left = build(nums,left,mid-1);
        root->right = build(nums,mid+1,right);

        return root;
    }
};

int main(){
    Solution s;
    vector<int> nums = {1,2,3,4,5};
    TreeNode* root = s.sortedArrayToBST(nums);

    cout<<"生成的二叉树中序遍历为:"<<endl;
    printInorder(root);
    cout<<endl;


    cout<<"生成的二叉树层序遍历为:"<<endl;
    vector<string> result = levelOrderSerialize(root);
    for(const string& s: result){
        std::cout<<s<<" ";
    }
    cout<<endl;

    return 0;
}
```

### 输出

```tex
        3
       / \
      1   4
       \   \
        2   5
生成的二叉树中序遍历为:
null 1 null 2 null 3 null 4 null 5 null
生成的二叉树层序遍历为:
3 1 4 null 2 null 5
```

## 法二：二分递归，总是选择中间位置右边的数字作为根节点

- `mid = (left + right + 1)/2 或 left + (right - left + 1)/2`

```c++
class Solution {
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums,0,nums.size()-1);
    }
    TreeNode* build(const vector<int>& nums,int left,int right){
        if(left > right) return nullptr;//空区间

        //取中间节点(偏左)
        int mid = (left + right + 1)/2;//left + (right - left + 1)/2
        TreeNode* root = new TreeNode(nums[mid]);

        //递归构建左、右子树
        root->left = build(nums,left,mid-1);
        root->right = build(nums,mid+1,right);

        return root;
    }
};
```

### 输出

```tex
      2   5
     /   /
    1   4
生成的二叉树中序遍历为:
null 1 null 2 null 3 null 4 null 5 null
生成的二叉树层序遍历为:
3 2 5 1 null 4
```

## 法三：二分递归，选择任意一个中间位置数字作为根节点

`mid = (left + right + rand() % 2)/2`

```c++
class Solution {
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums,0,nums.size()-1);
    }
    TreeNode* build(const vector<int>& nums,int left,int right){
        if(left > right) return nullptr;

        int mid = (left + right + rand() % 2)/2;
        TreeNode* root = new TreeNode(nums[mid]);

        root->left = build(nums,left,mid-1);
        root->right = build(nums,mid+1,right);

        return root;
    }
};
```

## 复杂度分析

- **时间复杂度**：`O(n)`，每个元素只访问一次。
- **空间复杂度**：`O(log n)`（递归栈深度，树是平衡的），如果不计递归栈则可视为 `O(n)`（生成整棵树）。
