## 法1：使用`vector`数组

思路：由于每次可以爬1或2个台阶，用 *f*(*x*) 表示爬到第 *x* 级台阶的方案数，则有 *f*(*x*)=*f*(*x*−1)+*f*(*x*−2)，即爬到第 *x* 级台阶的方案数是爬到第 *x*−1 级台阶的方案数和爬到第 *x*−2 级台阶的方案数的和。

因为每次只能爬 1 级或 2 级，所以 *f*(*x*) 只能从 *f*(*x*−1) 和 *f*(*x*−2) 转移过来，此时就可以确定dp数组了，

- `dp[n]`：爬到第n级台阶，有`dp[n]`中方法

- 递推公式：`dp[n] = dp[n-1] +dp[n-2];`
  - **(在推导dp[i]的时候，一定要时刻想着dp[i]的定义，否则容易跑偏。)**

- 初始化：
  - 考虑`dp[0]`
    - `dp[0] = 1;//什么都不做也就是一种方法,相当于直接站在楼顶。`
    - ``dp[1] = 1;//爬第1级台阶只有一种方案,即爬1级`
  - 不考虑`dp[0]`时，直接只初始化dp[1] = 1，dp[2] = 2，然后从i = 3开始递推
- 遍历顺序：
  - `for(int i = 2;i<=n;i++)`
- 例子：爬第2级台阶的方案为：在第1级台阶的基础上再爬1级 或 在第0级台阶的基础上直接爬2级

### 考虑dp[0]的代码

- 1. 最直接

```c++
class Solution {
public:
    int climbStairs(int n) {
        std::vector<int> dp(n+1,0);
        dp[0] = 1;
        dp[1] = 1;
        for(int i = 2;i<=n;i++){//这里始终从i=2开始,因为从dp[2]开始都还没进行初始
            dp[i] = dp[i-1] + dp[i-2];//进行递推公式
        }
        return dp[n];
    }
};
```

## 法2:优化数组或两个`int`

### 考虑dp[0]的代码

- 1. 只用一个固定大小为2的数组，每次遍历第n阶的方案时,更新`dp`数组（类似滚动窗口），`dp[0]`存原`dp[1]`的值，`dp[1]`存递推公式的结果，最终返回`dp[1]`即可。

```c++
class Solution {
public:
    int climbStairs(int n) {
        int dp[2];
        dp[0]=1;
        dp[1]=1;
        for(int i = 2;i<=n;i++){
           int sum = dp[0] + dp[1];
           dp[0] = dp[1];
           dp[1] = sum;
        }
        return dp[1];
    }
};
```

- 2. 或使用两个int变量表示原来的`dp[0]` 和 `dp[1]`，思路以上述相同


### 不考虑dp[0]的代码

- 1. 只用一个固定大小为3的数组，每次遍历第n阶的方案时,更新`dp`数组（类似滚动窗口），`dp[1]`存原`dp[2]`的值，`dp[2]`存递推公式的结果，最终返回`dp[2]`即可。

```c++
class Solution {
public:
    int climbStairs(int n) {
        
         //在n<=1时直接返回n,是因为:当n=1时,如果不返回n,则会直接返回dp[2]的结果2,但是应该返回的是dp[1]的结果1，所以要判断是否要提前返回
        if(n<=1){
            return n;//注意,这里要判断是否要提前返回,避免返回错误问题
            
            //这里为了直观确保每种情况,选择n<=1,当然,因为推算出dp[1]=1;dp[2]=2;dp[3]=3;
            //此时if的判断条件可以改为:if(n<=2)甚至是if(n<=3);
        }   
        int dp[3];
        dp[0] = 1;//不对dp[0]进行操作
        dp[1] = 1;//表示爬到第1级台阶,有dp[1] = 1中方法
        dp[2] = 2;//表示爬到第2级台阶,有dp[2] = 2中方法,即 "爬1个台阶+爬一个台阶" 和 "直接爬2个台阶"
        for(int i = 3;i<=n;i++){
            int sum = dp[1] + dp[2];
            dp[1] = dp[2];
            dp[2] = sum;
        }
        return dp[2];//返回更新后的dp[2];
    }
};
```

## 复杂度分析

- **时间复杂度**：**O(n)**，所有算法均包含一个从 `i=2` 或 `i=3` 到 `n` 的循环，循环体内执行常数次操作（加法、赋值等）。
  - 对于 `n` 较小的情况（如 `n<=1`），部分代码会提前返回，但常数级别的判断不影响渐进复杂度。

- **空间复杂度**
  - **使用 `vector<int> dp(n+1)` 的写法**（如“法1”中的所有实现）：
    需要存储 `n+1` 个整数的数组，**空间复杂度为 O(n)**。
  - **使用固定大小数组或两个整型变量的写法**（如“法2”）：
    - 大小为2或3的数组：占用常数空间，**空间复杂度为 O(1)**。
    - 两个独立 `int` 变量（如 `dp1`, `dp2`）：同样常数空间，**O(1)**。

| 实现方式                                                     | 时间复杂度 | 空间复杂度 |
| :----------------------------------------------------------- | :--------- | :--------- |
| `vector<int> dp(n+1)` + 循环                                 | O(n)       | O(n)       |
| 固定大小数组（`int dp[2]` 或 `int dp[3]`）                   | O(n)       | O(1)       |
| 两个整型变量（`int dp1, dp2`）或三个整型变量（`int dp1, dp2,dp3`） | O(n)       | O(1)       |
