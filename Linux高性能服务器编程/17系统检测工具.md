# lsof命令

**`lsof`**：列出当前系统打开的文件描述符（包括普通文件、目录、网络连接、设备等）。

#### 1. 按进程筛选

- **查看指定 PID 打开的文件**

  ```bash
  lsof -p 1234
  ```

- **查看指定命令名称（如所有 nginx 进程）**

  ```bash
  lsof -c nginx
  ```

#### 2. 按用户筛选

- **查看特定用户打开的文件**

  ```bash
  lsof -u username
  ```

- **排除某个用户**

  ```bash
  lsof -u ^root   # 不显示 root 用户的文件
  ```

#### 3. 按文件/目录筛选

- **查看哪个进程在使用某个文件**

  ```bash
  lsof /var/log/syslog
  ```

- **查看某个目录下被打开的文件**

  ```bash
  lsof +D /var/log   # 递归搜索目录
  ```

#### 4. 网络连接相关

`-i`：显式socket文件描述符

```bash
$ lsof -i [46] [protocol][@hostname][ipaddr][:service|port]
```

其中，4表示IPV4协议，6表示IPV6协议；protocol指定传输层协议（TCP/UDP）；

hostname指定主机名；ipaddr指定主机的IP地址

service指定服务名；port指定端口号。

如：要显示所有连接到主机192.168.1.108的ssh服务的socket文件描述符，可以使用以下命令：
```bash
$ lsof -i &192.168.1.108:22
```

如果`-i`后不指定任何参数，则`lsof`命令将显示所有`socket`文件描述符

- **查看所有网络连接（IPv4 和 IPv6）**

  ```bash
  lsof -i
  ```

- **查看特定端口（如 80）**

  ```bash
  lsof -i :80
  ```

- **查看特定协议的连接**

  ```bash
  lsof -i tcp
  lsof -i udp
  ```

- **查看处于 LISTEN 状态的端口（通常用于查看服务监听）**

  ```bash
  lsof -i tcp:80 | grep LISTEN
  ```

  - **`|`**：管道符，将前一个命令的输出作为后一个命令的输入。
  - `grep LISTEN`：从 `lsof` 的输出中筛选出包含 `LISTEN` 的行，即只显示处于监听状态的连接。

#### 5. 其他实用选项

- **查看所有打开的普通文件**

  ```bash
  lsof -a -p 1234 -f -F  # 组合条件（-a 表示 AND）
  ```

- **不解析主机名（显示 IP 地址）**

  ```bash
  lsof -i -n
  ```

- **不解析端口名（显示端口号）**

  ```bash
  lsof -i -P
  ```

- **列出被删除但仍被进程占用的文件**

  ```bash
  lsof | grep deleted
  ```

# netstat

网络信息统计工具

# 现代命令 (`iproute2`)与传统命令 (`net-tools`)

| 功能类别                            | 传统命令 (`net-tools`) | 现代命令 (`iproute2`)  |
| :---------------------------------- | :--------------------- | :--------------------- |
| **网络接口配置** (查看/设置IP、MAC) | `ifconfig`             | `ip link` 和 `ip addr` |
| **路由表管理** (查看/添加/删除路由) | `route`                | `ip route`             |
| **邻居/ARP管理**                    | `arp`                  | `ip neigh`             |

# vmstat

实时输出系统的各类资源的使用情况，比如进程信息、内存使用、CPU使用率以及I/O使用情况

# ifstat

简单的网络流量检测工具

# mpstat

实时检测多处理器系统上的每个CPU的使用情况。

`mpstat`和`iostat`命令被集成在 包 `sysstat`中。
