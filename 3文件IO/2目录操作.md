# 目录操作

在Linux下对于**目录**其实也是一个**文件**。但是目录不能直接进行读写因为目录中所存储的是**目录项数据**

**目录项**： 其实就是记录了该目录下面的子目录和文件的一些信息 

- 文件名字，
- 文件大小...

对目录进行操作，无非就是去读取目录项来一个一个的获取该目录下的文件夹和文件。

```c
// 目录项结构体
struct dirent {
	// 子目录/文件的inode编号
    ino_t d_ino; /* Inode number */
    
    // 子目录/文件在目录文件的中偏移量
    off_t d_off; /* Not an offset; see below */
    
    // 结构体的大小
    unsigned short d_reclen; /* Length of this record */
    
    // 子目录/文件的类型
    unsigned char d_type; /* Type of file; not supported by all filesystem
    types */
    
    // 子目录/文件的名称 （不包含路径）
    char d_name[256]; /* Null-terminated filename */
};
```

==注意：该结构体成员变量：是所有Linux系统都支持的。如果想让代码具有更好的可移植性，该结构体 代码中，只能用 d_ino、d_name 这两个成员变量。==

## ==示例：读取并关闭目录opendir/readir/closedir==

```c
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <iostream>
#include <unistd.h>
#include <dirent.h>
#include <cstring> // 需要包含这个头文件来使用 strcmp

int main()
{
    DIR* dir_p = opendir("test");
    if(dir_p == nullptr)
    {
        perror("打开失败");
        return -1;
    }
    
    std::cout << "打开成功" << std::endl;
    struct dirent *dt = nullptr;
    while((dt = readdir(dir_p)) != nullptr)
    {
        // 过滤掉 "." 和 ".." 这两个特殊目录
        if (strcmp(dt->d_name, ".") == 0 || strcmp(dt->d_name, "..") == 0) {
            continue; // 跳过本次循环，不打印
        }
        std::cout << dt->d_name << std::endl;
    }
    
    closedir(dir_p); // 良好的习惯是关闭打开的目录流
    return 0;
}
```
