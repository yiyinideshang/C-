# 什么是条件编译指令

条件编译是 C/C++ 预处理器提供的一组指令，允许根据某些条件决定哪些代码被编译器编译，哪些被忽略。它在跨平台开发、调试输出、功能开关等场景中非常有用。

# 1.  为什么需要条件编译？

- **跨平台兼容**：不同操作系统或编译器需要不同的代码（例如头文件、系统调用）。
- **调试与发布**：调试时打印详细信息，发布时移除这些打印以减小体积、提高效率。
- **功能配置**：根据用户需求启用或禁用某些功能（如付费版与免费版）。
- **临时屏蔽代码**：使用 `#if 0` 快速注释大段代码，比 `/* */` 更安全（可以嵌套）。
- **避免重复包含**：结合头文件防护 `#ifndef` 防止重复定义。

# 2. 常用条件编译指令

| 指令        | 含义                                                         |
| :---------- | :----------------------------------------------------------- |
| `#if`       | 如果后面的常量表达式为真（非0），则编译后续代码。            |
| `#ifdef`    | 如果某个宏已定义（无论值是多少），则编译后续代码。           |
| `#ifndef`   | 如果某个宏未定义，则编译后续代码（常用于头文件防护）。       |
| `#elif`     | 相当于 `else if`，与 `#if`、`#ifdef` 等配合使用。            |
| `#else`     | 当前面条件不满足时，编译此分支。                             |
| `#endif`    | 结束一个条件编译块。                                         |
| `defined()` | 运算符，用于 `#if` 中，检查宏是否定义，例如 `#if defined(DEBUG)`。 |

# 3. 指令详解与示例

## 3.1 `#if` 指令

`#if` 后跟常量表达式，可以是整数、宏或它们的组合。表达式为真（非0）则编译。

```c
#define VERSION 2

#if VERSION == 1
    printf("版本1的功能\n");
#elif VERSION == 2
    printf("版本2的功能\n");
#else
    printf("未知版本\n");
#endif
```

输出：`版本2的功能`

## 3.2 `#ifdef` 和 `#ifndef`

- `#ifdef`：若宏已定义，编译。
- `#ifndef`：若宏未定义，编译。

```c
#define DEBUG

#ifdef DEBUG
    printf("调试模式：变量x=%d\n", x);
#endif

#ifndef RELEASE
    printf("这不是发布版本\n");
#endif
```

由于定义了 `DEBUG`，第一个 `printf` 会被编译；而 `RELEASE` 未定义，第二个 `printf` 也会被编译。

## 3.3 `defined()` 运算符

用于 `#if` 中，可以更灵活地组合条件。

```c
#define FEATURE_A
#define FEATURE_B 0

#if defined(FEATURE_A) && !defined(FEATURE_B)
    printf("功能A启用，功能B禁用\n");
#endif
```

这里 `defined(FEATURE_A)` 为真，`defined(FEATURE_B)` 也为真（因为宏存在），但 `!defined(FEATURE_B)` 为假，所以不编译。

## 3.4 头文件防护（经典用法）

防止头文件被多次包含。

```c
// myheader.h
#ifndef MYHEADER_H
#define MYHEADER_H

// 头文件内容...
void myFunction();

#endif // MYHEADER_H
```

# 4. 综合示例：跨平台 + 调试开关

```c
// 定义平台宏（通常在编译器命令行或项目设置中）
// 例如：gcc -DWINDOWS 或 gcc -DLINUX

#include <stdio.h>

// 调试开关：0 关闭，1 打开
#define DEBUG 1
//#define WINDOWS
//#define LINUX

int main() {
    #if DEBUG
        printf("进入main函数\n");
    #endif

    // 根据不同平台调用不同函数
    #if defined(WINDOWS)
        system("dir");
    #elif defined(LINUX)
        system("ls");
    #else
        printf("未知操作系统\n");
    #endif

    #if DEBUG
        printf("退出main函数\n");
    #endif
    return 0;
}
```

如果编译时定义了 `WINDOWS` 且 `DEBUG=1`，则程序会打印进入/退出信息，并执行 `dir` 命令。若定义 `LINUX`，则执行 `ls`。若没有定义任何平台，则显示未知操作系统。

# 5. 注意事项

- **常量表达式**：`#if` 后的表达式必须在预处理时就能计算出结果，不能包含变量或函数调用。
- **宏定义位置**：条件编译依赖的宏需要在指令之前定义（或通过编译器命令行 `-D` 传入）。
- **嵌套限制**：虽然可以嵌套，但过多嵌套会降低可读性，应尽量避免。
- **与 `if` 语句的区别**：条件编译是在编译之前处理的，不参与运行时代码执行；而普通的 `if` 是在运行时判断。
