| OSI层级              | TCP/IP层级             | 作用                                                   |
| -------------------- | ---------------------- | ------------------------------------------------------ |
| **应用层**           |                        | 提供网络服务和应用程序接口（HTTP、FTP、SMTP 等）。     |
| **表示层**           |                        | 数据格式转换、加密解密、数据压缩。                     |
| **会话层**           | **应用层**             | 管理会话和连接。                                       |
| **传输层（运输层）** | **传输层（运输层）**   | 提供端到端的通信服务，确保数据的完整传输（TCP、UDP）。 |
| **网络层**           | **网络层**             | 数据包的路由和转发，实现网络间的通信。                 |
| **数据链路层**       |                        | 节点之间的可靠数据传输，数据帧的发送与接收。           |
| **物理层**           | **网络接口层(链路层)** | 传输原始比特流，通过物理媒介传输数据。                 |

# 各层的协议

### 应用层 

- 应用协议： `http` , `https` , `tftp` , `ftp` , `DNS` , `QQ协议` , `BT`

### 运输层 TCP/UDP

- 主要作用：解决**数据如何传输的问题**

- 协议： `TCP` ， `UDP` 

- **TCP** ： `Transmission Control protocol` 传输层控制协议 

  - 是一种**面向连接**的传输层协议，它可以提供高**可靠**的通信。  -- **面向字节流**

  - 高可靠的通信：即**数据无误**、**数据无丢失**、**数据无失序**、**数据无重复**到达的一 种通信

  - 建立连接/断开连接：**三次握手**和**四次挥手**

    - **三次握手**：

  - 重发机制

  - **“面向连接的”**

- `UDP`:`User Datagram Protocol` 用户数据报协议

  - 它是**不可靠**的**无连接**协议。 -- **面向数据报**
    - 在数据发送之前，因为不需要进行连接就可以直接发送数据
  - **"实时应用“**

- 常用的熟知端口号

### 网络层

- `IP` ： `IP地址 `（网卡的逻辑上的编号）
- `ICMP` :(`Internet Control Message Protocol`,**互联网控制消息协议**）
- `IGMP`(`Internet Group Management Ptotocol`,**互联网组管理协议**)

### 网络接口层(设备驱动与硬件层)

- 硬件：
  -  网卡
  -  网线
- `MAC` 协议：
  -  `MAC`地址（网卡的物理地址 `48bits` ）

### **1. DHCP DISCOVER**

- **源端口**: 68 (客户端)
- **目标端口**: 67 (服务器)
- **传输层协议**: UDP
- **网络层**: 源IP 0.0.0.0，目标IP 255.255.255.255 (广播)
- **数据链路层**: 源MAC = 客户端MAC，目标MAC = FF:FF:FF:FF:FF:FF

### **2. DHCP OFFER**

- **源端口**: 67 (服务器)
- **目标端口**: 68 (客户端)
- **传输层协议**: UDP
- **网络层**: 源IP = 服务器IP，目标IP = 255.255.255.255 或 客户端IP（取决于标志位）
- **包含信息**: 提供的IP地址、子网掩码、租期等

### **3. DHCP REQUEST**

- **源端口**: 68 (客户端)
- **目标端口**: 67 (服务器)
- **传输层协议**: UDP
- **网络层**: 源IP 0.0.0.0，目标IP 255.255.255.255
- **作用**: 正式请求使用OFFER中提供的IP

### **4. DHCP ACK**

- **源端口**: 67 (服务器)
- **目标端口**: 68 (客户端)
- **传输层协议**: UDP
- **网络层**: 源IP = 服务器IP，目标IP = 客户端新获得的IP或广播
- **作用**: 确认租约，客户端可正式使用IP
