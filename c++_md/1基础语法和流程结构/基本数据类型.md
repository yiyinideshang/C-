# 基本数据类型的大小

## 64位系统（x86-64）

| 数据类型    | Windows | Linux/macOS                      |
| :---------- | :------ | :------------------------------- |
| `char`      | 1字节   | 1字节                            |
| `short`     | 2字节   | 2字节                            |
| `int`       | 4字节   | 4字节                            |
| `float`     | 4字节   | 约 ±3.4×10³⁸（6-7位有效数字）    |
| `double`    | 8字节   | 约 ±1.7×10³⁰⁸（15-16位有效数字） |
| `long`      | 4字节   | **8字节**                        |
| `long long` | 8字节   | 8字节                            |
| 指针        | 8字节   | 8字节                            |

| 数据类型                                   | 32位系统（字节）   | 64位系统（字节）                   | 变化说明                    |
| :----------------------------------------- | :----------------- | :--------------------------------- | :-------------------------- |
| `char`                                     | 1                  | 1                                  | 不变                        |
| `short`                                    | 2                  | 2                                  | 不变                        |
| `int`                                      | 4                  | 4                                  | 不变                        |
| `long`                                     | **4** (ILP32)      | **8** (LP64) **4** (LLP64-Windows) | 在 Linux/Unix 中变为 8 字节 |
| `long long`                                | 8                  | 8                                  | 不变                        |
| `size_t`                                   | 4                  | 8                                  | 变为 8 字节（与指针同宽）   |
| **数据类型**                               | **32位系统**       | **64位系统**                       | **变化说明**                |
| 所有指针类型 (`void*`, `int*`, 函数指针等) | **4**              | **8**                              | 地址空间扩展                |
| **数据类型**                               | **32位系统**       | **64位系统**                       | **变化说明**                |
| `float`                                    | 4                  | 4                                  | 不变                        |
| `double`                                   | 8                  | 8                                  | 不变                        |
| `long double`                              | 8/12（编译器相关） | 8/16（编译器相关）                 | 可能增大                    |
| **数据类型**                               | **32位系统**       | **64位系统**                       | **变化说明**                |
| `bool`                                     | 1                  | 1                                  | 不变                        |
| `wchar_t`                                  | 2 或 4             | 2 或 4                             | 编译器相关                  |

## 最小保证大小

- `sizeof(long long) >= sizeof(long)`

- `sizeof(long) >= sizeof(int)` 

- `sizeof(int) >= sizeof(short)` 

- `sizeof(short) >= 2`


# 2的次幂

 2 的幂次在计算机科学和数学中非常重要，尤其在二进制、数据存储和内存寻址等领域。以下是 2 的各次幂结果（从 \(2^0\) 到 \(2^{30}\) 以及部分常见单位）：

| 次幂 (n)   | 2^n (十进制)  | 近似单位（二进制） |
| ---------- | ------------- | ------------------ |
| \(2^0\)    | 1             | 1                  |
| \(2^1\)    | 2             | 2                  |
| \(2^2\)    | 4             | 4                  |
| \(2^3\)    | 8             | 8                  |
| \(2^4\)    | 16            | 16                 |
| \(2^5\)    | 32            | 32                 |
| \(2^6\)    | 64            | 64                 |
| \(2^7\)    | 128           | 128                |
| \(2^8\)    | 256           | 256                |
| \(2^9\)    | 512           | 512                |
| \(2^{10}\) | 1,024         | 1 KiB（千字节）    |
| \(2^{11}\) | 2,048         | 2 KiB              |
| \(2^{12}\) | 4,096         | 4 KiB              |
| \(2^{13}\) | 8,192         | 8 KiB              |
| \(2^{14}\) | 16,384        | 16 KiB             |
| \(2^{15}\) | 32,768        | 32 KiB             |
| \(2^{16}\) | 65,536        | 64 KiB             |
| \(2^{17}\) | 131,072       | 128 KiB            |
| \(2^{18}\) | 262,144       | 256 KiB            |
| \(2^{19}\) | 524,288       | 512 KiB            |
| \(2^{20}\) | 1,048,576     | 1 MiB（兆字节）    |
| \(2^{21}\) | 2,097,152     | 2 MiB              |
| \(2^{22}\) | 4,194,304     | 4 MiB              |
| \(2^{23}\) | 8,388,608     | 8 MiB              |
| \(2^{24}\) | 16,777,216    | 16 MiB             |
| \(2^{25}\) | 33,554,432    | 32 MiB             |
| \(2^{26}\) | 67,108,864    | 64 MiB             |
| \(2^{27}\) | 134,217,728   | 128 MiB            |
| \(2^{28}\) | 268,435,456   | 256 MiB            |
| \(2^{29}\) | 536,870,912   | 512 MiB            |
| \(2^{30}\) | 1,073,741,824 | 1 GiB（吉字节）    |

更大的次幂：
- \(2^{40} = 1,099,511,627,776\)（1 TiB，太字节）
- \(2^{50} = 1,125,899,906,842,624\)（1 PiB，拍字节）
- \(2^{60} = 1,152,921,504,606,846,976\)（1 EiB，艾字节）
- \(2^{70} \approx 1.18 \times 10^{21}\)（1 ZiB，泽字节）
- \(2^{80} \approx 1.21 \times 10^{24}\)（1 YiB，尧字节）

重要提示：

- **二进制前缀**：计算机中常用二进制前缀（如 KiB、MiB、GiB）表示 \(2^{10}\) 的倍数，区别于十进制前缀（如 KB、MB、GB）的 \(10^3\) 倍数。
- **溢出注意**：在编程中，使用整数类型存储 2 的幂次时需注意类型范围（如 32 位整数最大为 \(2^{31}-1\)，无符号 32 位整数最大为 \(2^{32}-1\)）。
