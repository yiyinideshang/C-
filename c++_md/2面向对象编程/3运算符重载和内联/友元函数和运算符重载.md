# 1.友元函数和运算符重载

## 1.1友元函数

友元（friend）：在某些情况下，允许**特定的**非成员函数访问**一个类的私有成员**，**同时仍然阻止**一般的 访问，这种操作可以实现很多操作，利用友元可以很方便的实现这种操作。友元是对类封装机制的一种 补充。

在**函数声明**前加**friend**，就变成了友元函数。

- 普通的全局函数作为类的友元函数

     - 友元函数是某些不是类的成员函数却能够访问类的所有成员函数，类授予它特别的访问权，这 样该友元函数就能够访问类中的所有成员

     - 友元函数的声明

          - 在授权类中声明访问权限

          - 格式

            ````c++
            friend 返回值类型 函数名(形参表); 
            ````

<!--举例 在这个例子中定义了4个函数，A类中的构造函数 A(int , int); 、成员函数 void memberFun(); 类中的友元函数 friend void globalFun_friend(const A&that); 只是在A类中声明，并不属 于A类， void globalFun(const A& that); 是全局函数，与类A无关。 因此在构造函数、成员函数和友元函数中都能访问private和protected属性 友元函数不属于类，因此没有this指针-->

````c++
#include<iostream>
using namespace std;
class A
{
public:
	void memberFun();
	friend void globalFun_friend(const A& that);//友元函数的声明--在授权类中声明访问权限
	A(int, int);
private:
	int m_private;
protected:
	int m_protected;
};
void globalFun(const A& that);
//在类外进行了构造函数和成员函数的定义
A::A(int data1 = 0, int data2 = 0) : m_private(data1), m_protected(data2)
{
	cout << "构造函数 " << endl;
	cout << "m_private = " << m_private << ", m_protected = " << m_protected <<
		endl;
}
void A::memberFun()
{
	cout << "成员函数 " << endl;
	cout << "m_private = " << m_private << ", m_protected = " << m_protected <<
		endl;
}

void globalFun_friend(const A& that)
{
	cout << "友元函数 " << endl;
	cout << "m_private = " << that.m_private << ", m_protected = " <<
		that.m_protected << endl;
}
void globalFun(const A& that)//非友元函数，私有成员不对其开放
{
	cout << "全局函数 " << endl;
	//cout << "m_private = " << that.m_private << ", m_protected = " <<that.m_protected << endl;//error	
}
int main()
{
	A a(1, 2);//这句话调用了类中的构造函数
	cout << endl;
	a.memberFun();//调用了类中成员函数
	cout << endl;
	//a.globalFun_friend(a);//error globalFun_friend 友元函数 是不是类的成员函数
	globalFun_friend(a);//这句话调用了友元函数，在该友元函数内部，可以访问类的所以成员
	cout << endl;
	globalFun(a);
	return 0;
}
````

### 1.2-1 双目运算符的重载

#### 左值和右值

<!--左值和右值的本质就是该参数或返回值是否会被修改-->

- 在C++编程语境中，左值（l value）与右值（rvalue）是两个至关重要的概念，它们主要描述了表达式的身份与属性。

- ````
  int a = 5;  
  int b = 10;  
  int c = a + b;  
  ````

  // 这里 a 和 b 是左值，a + b 的结果是右值
  在这个例子中：a 和 b 都是左值，因为它们都是变量，有明确的内存位置，并且可以被取地址。
  a + b 的结果是右值，因为这是一个临时结果，它存储在某个临时位置（如果有的话），并且不能被取地址。
  c 是一个左值，因为它是一个变量，用于存储a + b的结果。
  
  **左值（lvalue）**
  
  左值通常指的是那些具有持久存储位置的对象或函数。它们能够出现在赋值语句的左侧，意味着我们可以为它们分配新的值。左值的核心特性是它们可以被取地址，即我们可以使用`&`运算符来获取其内存地址。例如，变量就是典型的左值，因为它们占据内存中的固定位置，并且我们能够通过赋值来改变它们的值。
  
  **右值（rvalue）**

  与左值相对，右值通常指的是那些没有持久存储位置的值，例如临时对象或字面量。它们不能出现在赋值语句的左侧（尽管在C++11及更高版本中，通过右值引用，我们可以使右值表现得像左值一样）。右值通常不能被直接取地址，因为它们在表达式求值完成后可能就不再存在。右值可以分为纯右值（prvalue）和将亡值（xvalue）两类，其中纯右值包括字面量、函数返回的非引用临时对象等，而将亡值则与右值引用和移动语义紧密相关。

  **关键点总结**

  - **持久性**：左值具有持久的存储位置，而右值则没有。
  - **赋值能力**：左值可以出现在赋值语句的左侧，右值则不能（尽管在C++11及更高版本中，通过右值引用可以实现某种形式的“赋值”）。
  - **取地址能力**：左值可以被取地址，而右值通常不能。
  - **示例**：变量是左值的典型例子，而字面量和临时对象则是右值的典型例子。
  
  在C++编程中，理解左值和右值的区别对于掌握值的传递、对象的生命周期管理以及优化代码性能等方面都至关重要。特别是在C++11及更高版本中，随着右值引用、移动语义和完美转发的引入，左值和右值的区分变得更加重要和复杂。

#### 1.2.1.1运算类的双目运算符 +-*/

C++ 的语法规则将一些运算符（如 **= 、 [] 、 () 、 ->** 等）限制为**只能被定义为成员函数，而不能作为 全局函数进行重载。**这是为了确保运算符重载可以在正确的上下文中使用，并且能够访问所需的对象状态。

常见的运算类的双目运算符有 + - * /

````
int a =1; 
int b = 2; i
nt c = a + b;//加法的返回值为右值
````

- 特点 

  - 左右操作数既可以是左值也可以是右值 

  - 表达式结果是右值

- 实现方式

  * 成员函数方式

  * ```c++
    L#R 的表达式可以被编译器翻译成 **L.operator#(R)** 
    ```

    L#R 的表达式可以被编译器翻译成 **L.operator#(R)** 这样成员函数调用形式,该函数的返回结果就是表达式的结果。 L.operator=(R)

    其中L表示**左操作数**、R表示**右操作数**、#表示**运算符**，**L必须是类类型变量，才可调用 operator# 函 数。**

     **operator** 是一个特殊的关键字，用于定义或重载运算符。在**定义或重载运算符**时，我们需要使用 operator 关键字来指定要定义或重载的运算符。

  * 全局函数形式

  L#R的表达式可以被编译器翻译成 **::operator#(L, R)** 这样成员函数调用形式,该函数的返回结果就是 表达式的结果 

  其中L表示左操作数、R表示右操作数,L、R至少有一个是类类型的变量。 

  <!--复数的加减运算--> 
  
  <!--形如a+bi（a、b均为实数）的数为复数，其中，a被称为实部，b被称为虚部，i为虚数单位 负数的加减即对应的实部和虚部相互加减-->
  
   <!--使用"friend"关键字,可以把一个全局函数声明为某个类的友元,友元函数可以访问类中的任何成员-->

  using namespace std;
  class Complex
  {
  public:
  	Complex(int r, int i) :m_r(r), m_i(i) {}//构造函数
  	void print(void)const
  	{
  		cout << m_r << "+" << m_i << "i" << endl;
  	}
  	//c1+c2==>c1.operator+(c2)
  	/*
  	*1)const Complex (const)修饰返回值,为了返回右值 //防止出现c1 + c2 = c3;这种现象，只能出现c3 = c1 + c2

  	*3)常函数,为了支持常对象调用该函数//当c1为常对象是可以运算
  	* *///123分别为const

  	//不返回引用的原因是局部变量在声明周期结束后就消失了，会形成悬空引用。

  	{
  		Complex res(m_r + c.m_r, m_i + c.m_i);
  		return res;
  	}
  	//这个方法重载了加法运算符+。
  	// 它接受一个const Complex&类型的参数（表示另一个复数），并返回一个新的Complex对象，其实部和虚部分别是两个复数对应部分的和。
      //即接受＋右面的参数，将c1+c2的结果->(c1.m_r+c2.m_r,c1.m_i+c2.m_i)返回
      //在函数体内，我们计算两个复数对应部分的和，即实部相加和虚部相加。
  //返回结果：最后，我们返回一个新的Complex对象，其实部和虚部是计算得到的和。
  //方法返回const Complex是为了防止返回的临时对象被修改（例如，防止c1 + c2 = c3这样的赋值操作）。

  const Complex operator-(const Complex& l, const Complex& r)

  //函数接受两个类型为const Complex&的参数，分别表示被减数和减数。

#### 1.2.1.2赋值类的双目运算符  += -= *= /= =

````c++
int a = 1;
int b = 2;
a += b;
````



- 特点
  - 左操作数必须是左值,右操作数可以使左值也可以是右值
  - 表达式的结果是左值,就是左操作数的自身，因此不能是常函数

- 实现方式

  - 成员函数形式

    L#R 的表达式可以被编译器翻译成 L.operator#(R) 这样成员函数调用形式,该函数的返回结果就是左操 作数。

  - 全局函数形式

    L#R 的表达式可以被编译器翻译成 ::operator#(L, R) 这样成员函数调用形式,该函数的返回结果就是 左操作数
    
    ````c++
    #include<iostream>
    using namespace std;
    class Complex
    {
    public:
    	Complex(int r, int i) :m_r(r), m_i(i) {}
    	void print(void)const
    	{
    		cout << m_r << "+" << m_i << "i" << endl;
    	}
    	//+=成员函数形式
    	//返回值是左值，不加const
    	//左操作数必须是左值，因此不能是常函数
    	Complex& operator+=(const Complex& c) 
    	{
    		m_r += c.m_r;
    		m_i += c.m_i;
    		return *this;
    	}
    	Complex& operator=(const Complex& that)//拷贝赋值
    	{
    		if (this == &that)
    		{
    			return *this;
    		}
    		m_r = that.m_r;
    		m_i = that.m_i;
    		return *this;
    	}
    private:
    	int m_r;//实部
    	int m_i;//虚部
    	//友元函数可以把定义直接写在类的内部,但是它不属于类,本质还是全局函数
    	//左操作数必须是左值，因此不能加const
    	friend Complex& operator-=(Complex& l, const Complex& r)
    	{
    		l.m_r -= r.m_r;
    		l.m_i -= r.m_i;
    		return l;
    	}
    };
    int main()
    {
    	Complex c1(1, 2);
    	Complex c2(3, 4);
    	c1 += c2;//c1.operator+=(c2)
    	c1.print();//4+6i
    	c1 -= c2;//::operator-=(c1,c2)
    	c1.print();//1+2i;
    	Complex c3(5, 6);
    	c3 = c2;
    	c3.print();
    	return 0;
    }
    ````

###  1.2-2单目运算符的重载

#### 1.2.2.1计算类的单目操作符 \- ~

````c++
int a = 1;
int b = -a;
int c = ~a;
````

- 特点
  - 操作数可以是左值也可以是右值
  - 表达式结果为右值

- 实现方式

  - 成员函数方式

    \#O 的表达式可以被编译器翻译成 O.operator#() 这样成员函数调用形式,该函数的返回值是左值。

    <!--为什么不是 operator#(O) ？因为需要一个对象来调用该函数。-->

  - 全局函数方式

    #O 的表达式可以被编译器翻译成 ::operator#(O) 这样成员函数调用形式,该函数的返回值是左值。

````c++
#include<iostream>
using namespace std;
class Int
{
public:
	Int(int data = 0) : m_data(data)
	{
	}
	const Int operator -()
	{
		Int res(-m_data);
		return res;
	}
	friend const Int operator~(const Int&);
	void print()
	{
		cout << "m_data = " << m_data << endl;
	}
private:
	int m_data;
};
const Int operator~(const Int& i)
{
	Int res(~i.m_data);
	return res;
}
int main()
{
	Int i1(10);
	Int i2 = -i1;
	Int i3 = ~i1;
	i1.print();
	i2.print();
	i3.print();
	return 0;
}
````

#### 1.2.2.2自增/减单目操作符 前++、--  后++、--

- 前++、- - 

  ````c++
  int a = 1;
  int b = ++a;//2
  int c = --a; 
  ````

  - 特点
    - 操作数必须是左值
    - 表达式的结果也是左值，就是操作数本身

- 实现方式

  - 成员函数方式

    \#O 的表达式可以被编译器翻译成 O.operator#() 这样成员函数调用形式,该函数的返回值是左值。

  - 全局函数形式

    \#O 的表达式可以被编译器翻译成 ::operator#(O) 这样成员函数调用形式,该函数的返回值是左值。

````c++
#include<iostream>
using namespace std;
class Integer
{
public:
    Integer(int i = 0) :m_i(i) {}
    void print(void)const
    {
    cout << m_i << endl;
    }
    //前++:成员函数形式
    Integer& operator++(void)	//a.operator++()
    {
        ++m_i;
        return *this;
    }
    //前--:全局函数形式
    friend Integer& operator--(Integer& i) //operator++(a)
    {
        --i.m_i;
        return i;
    }
private:
    int m_i; 
};
int main()
{
    Integer i(100);
    Integer j = ++i; //j = i.operator++();
    i.print();//101
    j.print();//101
    j = ++++++i;//ok
    i.print();//104
    j.print();//104
    j = --i; //j = operator--(i);
    i.print();//103
    j.print();//103
    j = ------i;//ok
    i.print();//100
    j.print();//100
    return 0;
}
````

  ````c++
  int a = 1;
  //1++ error
  int b = a++;//1	a.operator++(1);
  int c = a--;
  ````

  **只有类型没有形参名的叫做哑元**

  - 特点
    - 操作数必须是左值 
    - 表达式结果是右值,是操作数自增减前的副本

- 实现方式

  - 成员函数方式 

    #O 的表达式可以被编译器翻译成 O.operator#(哑元) 这样成员函数调用形式,该函数的返回值是左值。

  - 全局函数形式

     #O 的表达式可以被编译器翻译成 ::operator#(O，哑元) 这样成员函数调用形式,该函数的返回值是左 值。

<!--在C++中，前缀增量运算符(++i)的语义是：先对i加1，然后返回i。由于这个操作只涉及到一个操作 数，也就是i本身，因此对应的重载函数不需要额外的参数。 在 C++ 中，后缀增量运算符（i++）的语义是：先返回 i，然后对 i 加1。为了区分前缀和后缀版本 的运算符，C++ 标准规定了一种特殊的函数签名来重载后缀增量运算符。-->

后++，后--是先返回原来值，所有返回值不能为引用， operator++(int)

````c++
#include<iostream>
using namespace std;
class Integer
{
public:
	Integer(int i = 0) :m_i(i) {}
	void print(void)const
	{
		cout << m_i << endl;
	}
	//后++:成员函数形式
	const Integer operator++(int /*哑元*/)// a.operator++(1)
	{
		Integer old = *this;
		++this->m_i;//++m_i;
		return old;
	}
	//后--:全局函数形式
	friend const Integer operator--(Integer& i, int/*哑元*/) //operator++(a,1)
	{
		Integer old = i;
		--i.m_i;
		return old;
	}
private:
	int m_i;
};
int main()
{
	Integer i(100);
	Integer j = i++;//i.operator++(100)
	i.print();//101
	j.print();//100
	j = i--;//i.operator--(100)
	i.print();//100
	j.print();//101
	return 0;
}
````

#### 1.2.2.3插入和提取运算符 << >>

- << >>

  ````c++
  int a = 1;
  cin >> a;
  cout << a
  ````

  

- 功能

  实现自定义类型对象的直接输出或者输入

- 实现方式

  只能用全局函数形式

  - 全局函数形式

    <!--ostream表示输出流、istream表示输入流-->

````c++
friend ostream &operator<<(ostream &os,const 类型名& 对象)
friend istream &operator>>(istream &is,类型名& 对象)
````

<!--在这个重载函数中，我们将 ostream 对象 os 和 Complex 对象 c 作为参数传入。 在函数体内，我们使用流插入运算符 << 将 c.m_r （实部）输出到流中，然后连接一个加号 + ， 再输出 c.m_i （虚部），最后连接字符 i 表示虚数单位。 最后，我们返回 os 对象本身，以便支持链式输出操作。 在函数体内，我们使用流提取运算符 >> 从标准输入里提取两个数组分别作为这个复数的实部和 虚部。 最后，我们返回 os 对象本身，以便支持链式输出操作。-->

````c++
#include<iostream>
using namespace std;
class Complex
{
public:
    Complex(int r, int i) :m_r(r), m_i(i) {}
    friend ostream& operator<<(ostream& os, const Complex& c)
    {
        os << c.m_r << "+" << c.m_i << "i";
        return os;
    }
    friend istream& operator>>(istream& is, Complex& c)
    {
        is >> c.m_r >> c.m_i;
        return is;
    }
private:
    int m_r;//实部
    int m_i;//虚部
};
int main()
{
    Complex c1(1, 2);
    Complex c2(3, 4);
    cout << c1 << endl;
    cout << c1 << ',' << c2 << endl;
    Complex c3(0, 0);
    cout << "请输入实部和虚部";
    cin >> c3;//operator
    cout << c3;
    return 0;
}
````

### 1.2-3运算符重载的限制

在C++中，大部分的运算符都可以重载，程序员可以根据不同的需求来实现不同的功能。但是存在一些运算符是不能重载的。这些运算符不能被重载的原因是因为它们在语义上具有特殊的含义，不能被改变。

-  :: （作用域解析运算符）运算符用于访问全局命名空间或类的静态成员。它在语法上具有固定的 含义和用途。它用于指定作用域，以解决命名冲突和访问作用域中的成员。如果允许重载双冒号运 算符，可能会导致混淆和不一致的语义。这是 C++ 语言设计的决策，目的是确保代码的可读性和一 致性。
-  . 和 -> （成员访问运算符）运算符用于访问对象的成员。 

在C++中，点运算符 . 和箭头运算符 -> 用于访问对象的成员，而点运算符 . 用于直接访问对象的成 员，箭头运算符 -> 用于通过指针访问对象的成员。

- `new` 和 `delete` （动态内存管理运算符） **可以重载，但是不建议**

- `.*` （成员指针访问运算符）
- `?:`（三目运算符）
- `sizeof`(大小运算符)
- 类型转换运算符（ `static_cast` 、 `dynamic_cast` 、 `const_cast` 、 `reinterpret_cast` ）

# 2. 内联函数

内联函数是定义在类声明或实现体中的函数，其前面用 `inline` 关键字修饰。当编译器遇到内联函数调用时，它通常会==将整个函数的代码体插入到调用该函数的地方，而不是进行常规的函数调用。==这样做的**目的**是为了==消除函数调用的开销，从而提升程序的运行效率==。

- 如果类的成员函数,在类中定义,而不是把声明和定义分开,这种情况成员函数自动成为内联函数 ( 在类的声明中定义该函数 `inline` ) 如果类的成员函数,手动声明为 `inline` 那么定义必须写在调用这个函数的文件中 使

用**inline关键字**(要写在**函数定义**处才会生效)修饰的函数,表示这个函数是内联函数,编译器会 尝试进行内联优化,减小函数调用的开销。

- 使用场景

  - 多次调用，小而简单的函数适合 做内联优化

  -  调用次数极少或者大而复杂的函数不适合内联
-  递归函数不能内联

**内联只是一种建议而不是强制要求，一个函数能否内联优化，主要区别于编译器**
