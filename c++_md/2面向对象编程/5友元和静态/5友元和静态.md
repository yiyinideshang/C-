# 友元和静态

# 1.友元：友元函数和友元类

友元（**friend**）：在某些情况下，允许特定的非成员函数访问一个类的私有成员，同时仍然阻止一般的 访问，这种操作可以实现很多操作，利用友元可以很方便的实现这种操作。友元是对类封装机制的一种 补充。

如果一个函数或者类（A） 与另一个类（B）存在这种**友元关系**（B声明A是它的朋友），那么这个函数 或者类（A）就可以访问另一个类（B）的私有成员和保护成员。

**友元的优缺点**

**友元提高了程序的运行效率，但是它破坏了类的封装性和因此性，使得其他的非成员函数或者其他类的 成员函数可以访问类的私有成员。**

友元分为两种：**友元函数**和**友元类**

## 1.1 友元函数

在**函数声明**前加**friend**，这个函数可以是**全局函数**，也可以是另一个类的成员函数。

- ### **1.普通的全局函数作为类的友元函数**

- - 友元函数是某些是不类的成员函数却能够访问类的所有成员函数，类授予它特别的访问权，这样友元函数就能够访问类中的所有成员

  - 友元函数的声明

  - - 在授权类中声明

    - 格式

      ```c++
      friend 返回值类型 函数名(形参列表)
      ```


- ### **2.类的成员函数作为另一个类的友元函数**
- - 声明不包含该友元函数的类
  - 定义包含该友元函数的类，在类中声明友元函数(函数声明前不加friend,且只声明不定义)
  - 不包括该友元函的类的定义，在类中声明友元函数(函数声明前加friend)
  - 包含该友元函数类的实现

```c++
#include <iostream>
using namespace std;
// Boy 类中的一个成员函数是Girl的友元函数
// - 声明不包含该友元函数的类
// - 定义包含该友元函数的类，在类中声明友元函数(函数声明前不加friend,且只声明不定义)
// - 不包括该友元函的类，在类中声明友元函数(函数声明前加friend)
// - 包含该友元函数类的实现
class Girl;
class Boy
{
public:
    void memberFunctionA(const Girl& objGirl);
};

class Girl
{
public:
    Girl(int data):privateData(data){}
    
    friend void Boy::memberFunctionA(const Girl& objGirl);
private:
    int privateData;
};

void Boy::memberFunctionA(const Girl& objGirl)
{
    cout<<"这是Boy类的成员函数作为Girl类的友元函数,"<<endl;
    cout<<"Boy类的成员函数访问Girl类的私有对象"<<endl;
    cout<<":"<<objGirl.privateData<<endl;
}
int main()
{
    Boy boy;
    Girl girl(100);
    boy.memberFunctionA(girl);
}
```



## 1.2友元类

**友元类**（Friend Class）是C++中的一个特性，它允许一个类拥有对另一个类的私有成员(全体成员)的访问权限。通过将**一个类声明为另一个类的友元类**，**被授权的类可以访问友元类的私有成员和保护成员。**如果类B是 类A的朋友（类A声明B是它的朋友），那么类B的所有成员函数都可以访问类A的私有成员。

- 格式

```c++
firend class 类名;
```

- 友元类的注意事项
  - 因为友元函数不是授权类的成员，所以它不受访问修饰词（public/private）的影响。但是我 们为了代码的可读性，会把所有的友元声明组织到一起放到类的开头。
  - 友元声明是以 friend 关键字开始，它只能出现在类的声明中，它的目的是声明某一个函数/ 类是它的朋友。
  - 友元关系是单项的
  - 友元关系是无法传递的,类B是A的朋友(B能访问A)，类A是类C的朋友(A能访问C)，类B和类C不一定是朋友。

### 例1类B是类A的友元类

**在类A中声明类B是类A的友元类（B是A的朋友），则类B可以访问类A**

**类B是类A的友元类，B能访问A，但是没有说明类A是类B的友元类，则A不能访问B**

**访问关系:  B->A**(B能访问A)

**声明关系：A->B**（A说B你是我的朋友）

```c++
#include <iostream>
using namespace std;
class A;
class B
{
    private:
        int m_private_B;
    public:
        B(int,int);
        void memberFun_B(const A& a);
    protected:
        int m_protected_B;
};
class A
{
    public:
        friend class B;
        A(int, int);
        void memberFun_A(const B& b);
    private:
        int m_private_A;
    protected:
        int m_protected_A;
};
    A::A(int data1, int data2):m_private_A(data1),m_protected_A(data2)
    {
    }
    B::B(int data1, int data2):m_private_B(data1),m_protected_B(data2)
    {
    }
    void B::memberFun_B(const A& a)
    {
        cout<<"这是通过B类的函数来访问A类的全部成员"<<endl;
        cout<<"A的成员函数"<<endl;
        cout<<"m_privat_A="<<a.m_private_A<<",m_protected_A="<<a.m_protected_A<<endl;
        cout<<"B的成员函数"<<endl;
        cout<<"m_privat_B="<<this->m_private_B<<",m_protected_B="<<this->m_protected_B<<endl;
    }
int main()
{
    A a(10,20);
    B b(1,2);
    b.memberFun_B(a);
    return 0;
}
```

### 例2,类B是类A的友元类，类A是类C的友元类

**类B是A的朋友(B能访问A)，类A是类C的朋友(A能访问C)，类B和类C 不一定是朋友**

**声明关系：C->A,A->B**(C说A你是我的朋友)（A说B你是我的朋友）

**访问关系：B->A,A->C**（A能访问C）(B能访问A)

# 2.静态

1.声明周期：与程序相同

2.在类中也可以包含静态成员,普通的成员属于对象,而静态成员变量不属于对象

## 2.1静态成员变量

**类中可以包含静态成员，在变量类型前面加static**

- 格式

```c++
class 类名
{
	static 类型 变量名;
}
```

- **静态成员变量的特征**
  -  普通的成员属于对象,而**静态成员变量不属于对象**。
  -  不能在构造函数中定义和初始化,需要**在类的外部单独定义和初始化**。 
  - 静态成员变量和全局变量一样存放在全局区,可以把静态成员变量理解成是被限制在类中去使 用的全局变量。 
  - **使用方法**: 
    - 类名::静态成员变量名;//推荐 
    - 对象名.静态成员变量名;//和上面方法本质一样
- 静态数据成员是**属于类的**,而不是属于某个具体对象的。它在所有对象间共享,只占用一份内存空间。所有对象都共享相同的静态数据成员值。

## 例 将学生类中的m_name声明为静态成员变量

```c++
#include<iostream>
using namespace std;
class Student
{
    public:
        Student(int age) /*: m_name(name), m_age(age)*///error 不能在构造函数中定义和初始化,需要在类的外部单独定义和初始化。
        {
            //m_name = name;
            m_age = age;
        }
        static string s_name;
        int m_age;
};
string Student::s_name = "def";//不能在构造函数中定义和初始化,需要在类的外部单独定义和初始化。

    cout << "sizeof(Student) = " << sizeof(Student) << endl;

    cout << "stu1.m_age = " << stu1.m_age << endl;

    cout << "stu2.s_name = " << stu2.s_name << endl;

    return 0;
}
```

## 2.2静态成员函数

同静态成员变量一样，类内可以包含静态成员函数，在成员函数前加static即可。

- 格式

  ```c++
  class 类名
  {
  	static 返回类型 函数名(形参表){...}
  };
  ```

- 静态成员函数的特征

  - 静态成员函数没有this指针，没有`const`属性，但是可以重载(静态与非静态成员函数名字相同且参数不构成重载)
  - 访问方式
    - 类名：静态成员函数（实参表）;//推荐
    - 对象名：静态成员函数（实参表）;//和上面方法本质一样

- ### 静态成员函数与普通成员函数

  - **在静态成员函数中只能访问静态成员，不能访问普通成员**，
  - **在普通的成员函数中，既可以访问静态的成员，也可以访问普通的成员。**

- ### 常函数与普通函数

  - **常对象只能调用常函数**
  - **普通对象既可以调用普通函数，也可以调用常函数**

## 1.全局变量

- ## 基本的全局变量定义： 

  直接在主函数main外进行定义和初始化，可以在main函数中访问和修改，也可以在其他函数中访问和修改

  ```c++
  // 在函数外部直接定义
  int globalVar = 10;          // 定义并初始化
  double pi = 3.14159;
  std::string appName = "MyApp";
  
  int main() {
      std::cout << globalVar << std::endl;  // 在main函数中访问
      return 0;
  }
  
  void someFunction() {
      globalVar = 20;  // 在其它函数中访问和修改
  }
  ```

- ## 推荐方式：在头文件中声明，在源文件中定义

全局变量是定义在函数外部，整个程序范围内都可见的变量。通常将全局变量的声明放在`.h`文件中，以避免多层包含可能引起的重复定义错误。

为了在其他文件中使用这些变量，可以在相应的头文件中使用 **extern** 关键字进行声明。

```c++
// global_variables.h
extern int globalVar;  // 声明全局变量 （使用extern关键字）

// global_variables.cpp
int globalVar = 42;  // 定义全局变量
```

## 2.静态全局变量

![静态全局变量](D:\Typora\typora_work\c++_md\2面向对象编程\5友元和静态\静态全局变量.png)

静态全局变量是使用 **static** 修饰的全局变量。与普通全局变量不同，静态全局变量的**作用域被限制在定义它的源文件内****，不能被其他源文件引用**。在头文件中声明和定义静态全局变量时一体化，不需要额外的 extern 关键字。

```c++
// static_global_variable.h erro
static int staticGlobalVar = 24;  // 静态全局变量的声明和定义
```

多个编译单元包含相同的头文件也不会引起重定义错误，因为每个编译单元都有独立的空间存储静态全局变量。

## 3.全局常量

全局常量是使用 **const** 关键字定义的全局变量，其值在定义时被初始化，并且不能在程序运行过程中修改。在.cpp文件中定义并赋初值，在头文件中使用 **extern** 进行声明。

```c++
// global_constants.h
extern const double PI;  // 声明全局常量

// global_constants.cpp
const double PI = 3.14159;  // 定义全局常量
```

虽然多个编译单元中的全局常量有不同的内存地址，但由于其为常量，其值不可修改，因此不会影响程序的行为。

## 4.区别

4.1 静态变量与普通变量的区别
普通全局变量的作用域是整个源程序，而静态全局变量的作用域被限制在定义该变量的源文件内，避免在其他源文件中引起错误。

4.2 static全局变量与普通的全局变量
静态全局变量只初始化一次，防止在其他文件单元中被引用。

4.3 static局部变量和普通局部变量
静态局部变量只被初始化一次，下一次依据上一次结果值。

4.4 static函数与普通函数
静态函数在内存中只有一份，普通函数在每个被调用中维持一份拷贝。

## 5. static的用途

在函数体内，被声明为静态的变量在函数调用过程中保持其值不变。
在模块内，被声明为静态的变量和函数只能在模块内部访问，不被模块外其他函数或文件访问，起到限制作用域的作用。

## 6.静态变量的使用

**static** 是C++语言的关键字之一，用于给变量创建永久存储空间。静态变量的生存期远远超过了创建它的函数，可以在多次函数调用中保持其值不变。其可见性与普通变量相似，向下可见，但需要注意未定义标识符时会导致编译器提醒。

```c++
#include <iostream>
using namespace std;

void fun(int x) {
    static int a = x;
    static int b = 0;
    a++;
    cout << a;
}

int main() {
    for (int i = 10; i > 0; i--) {
        fun(i);
    }
    system("pause");
    return 0;
}
运行结果：
a = 11 
a = 12 
a = 13 
a = 14 
a = 15 
a = 16 
a = 17 
a = 18
a = 19
a = 20
```

由于 **static int a** 是一个静态变量，它在第一次调用 fun 函数时被初始化为 x 的值，即 10。在随后的每次调用中，a 不会保持其值，并且由于它是静态变量，不会被重新初始化。因此，每次都是 a 在上一次的基础上自增1。

## 7.静态变量的原理


静态变量在内存中的存储位置不同于栈区的局部变量，而是在数据区。当静态变量被创建时，在数据区为其分配了一段空间，并分配了一个标志符，初始化时标志符被设为 1。之后标志符被设为 0，限制了之后对其的赋值，从而保持其值不变。这使得静态变量的生存期超过了函数本身的生存期。
