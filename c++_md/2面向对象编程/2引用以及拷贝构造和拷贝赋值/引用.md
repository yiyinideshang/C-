# 1.引用

# 1.1普通引用

1.**引用**就是为已存在的变量起个**别名**，对引用的操作技术对原变量的操作，它**不占用内存**

2.引用在定义时必须**初始化**（即指定这个引用到底是谁的别名），

3.引用初始化以后**绑定的变量不能再变**（即这个引用只能是这个变量的别名，不能再是别人的别名）

4.引用的类型与初始化的绑定的变量**类型必须保持一致**

## 引用与基本类型

```C++
#include<iostream>
using namespace std;
int main()
{
	int a = 1;
	int& r_a = a;//b引用a,b就是a的别名
	cout << "&a = " << &a << ",a = " << a << endl;
	cout << "&r_a = " << &r_a << ",b = " << r_a << endl;
	r_a = 2;
	cout << "a = " << a << endl;//2
	cout << "r_a = " << r_a << endl;
	a = 3;
	cout << "a = " << a << endl;//3
	cout << "r_a = " << r_a << endl;
	//引用定义时必须初始化
	//int &r;//error没有初始化，即说明r是谁的别名
	int c = 4;
	r_a = c;//将c的值赋值给b,而不是修改引用目标，即r_a仍然是a的别名,a与r_a的地址仍相同,与c的地址不同
	cout << "a = " << a << endl;//4
	cout << "r_a = " << r_a << endl;
	cout << "&a = " << &a << ",a = " << a << endl;
	cout << "&r_a = " << &r_a << ",b = " << r_a << endl;
	cout << "&c = " << &c << ",c = " << c << endl;
	//引用类型和绑定的目标类型要一致
	//double &d = c;
	return 0;
}
```

# 1.2常引用

使用引用时，由于可以通过引用去修改变量的值，所以为了防止出现这种情况，可以将引用定义为常引用。

- 定义引用时加**`const`**修饰,即为常引用,不能通过常引用修改引用的目标

- 格式：`const` 类型 &引用名 = 变量名;

```c++
const 类型 &引用名 = 变量名;
类型 const &引用名 = 变量名;
//const在&前即可
```

- **常引用与常对象一样，只能调用常函数**
- **普通对象既可以调用常函数也可以调用普通函数**

## 普通对象的常引用

```c++
#include<iostream>
using namespace std;
int main()
{
    int a = 1;
    const int& r_a = a;
    cout<<"a="<<a<<endl;
    cout<<"r_a="<<r_a<<endl;

    a = 2;
    cout<<"a="<<a<<endl;
    cout<<"r_a="<<r_a<<endl;

    // r_a = 3;//error 不能通过常引用修改引用的目标
    //cout<<"a="<<a<<endl;
    //cout<<"r_a="<<r_a<<endl;
    return 0;
}
```

## 常对象的常引用

- 对于**非常对象(普通对象)，可以绑定到常引用或非常引用**。
- 对于**常对象，只能绑定到常引用**；如果尝试绑定到非常引用，编译器会报错

```c++
int x = 5;
const int cx = 10;

const int& r1 = x;   // 正确：非常对象绑定到常引用
int& r2 = x;         // 正确：非常对象绑定到非常引用

const int& r3 = cx;  // 正确：常对象绑定到常引用
int& r4 = cx;        // 错误：常对象不能绑定到非常引用
```

## 左值和右值

- 普通引用只能引用左值，**常引用也叫万能 引用，既能引用左值也能引用右值**

  - 左值和右值

    **左值**：可以放在赋值运算符(=)左侧,一般普通的变量都是左值表示了一个占据内存中某个可识别的位置 （**也就是一个地址**）的对象

    - 普通的变量  

       ```c++
       如 int a = 10;//a就是一个左值,a有一个地址
       ```

    - 赋值表达式结果

      ​     如int a = 3,b=5;(a=1)=10//运算结果就是等号左边，结果a=10

    - 前++,前--表达式结果
    
       ```c++
       如int a = 3;++++a;//结果a=5
       
       又如int a = 10,++a = 20;//结果a=20
       ```

    **右值**:只能放在赋值运算符(=)右侧,一般常量都是右值，**在内存中不占据位置**

    - **常量**

       	 如10

    - **大多数表达式的结果** ，后++,后--。

      ​	如int a = 3, b = 5;//a + b = 10;Error,a+b表达式返回的结果是右值不能放到左侧

    - **函数返回链式变量(将亡右值，即函数返回值)**
    
         如：
    
      ```C++
      int func(void)
      {
          int num = 30;
          cout << "&num = " << &num << endl;
          return num;//临时变量保存num
      }
      fun() = 10;//error 函数返回值是一个右值，不能放到等号左侧
      ```
    
      **此时函数返回的对象是一个局部变量，是一个右值**

 

## 常引用右值

**常对象引用右值**

```c++
#include<iostream>
using namespace std;
int func(void)
{
    int num = 30;
    cout << "&num = " << &num << endl;//局部变量的地址，在函数执行完毕后被销毁
    return num;//num离开作用域(本函数)就失效了
}
int main()
{
    //res = 临时变量
    const int& res = func();//相当于res = 30;func()是一个右值
    cout << "&res = " << &res << endl;//常引用res的地址
    cout << res << endl;//30
    // C++允许将返回值绑定到一个常量引用，这样做的目的是为了延长临时对象的生命周期。
    // 这里res并不是指向num的地址，而是指向了一个临时对象(保存了返回值30)，
    // 这个临时对象的地址（&res）与&num是一个不同的地址。
    return 0;
}
```



# 1.3引用型函数参数

## 引用作为函数参数

- 将引用用于函数的参数,这时**形参就是实参的别名**,可以**通过形参直接修改实参的值**,同时**避免**参数**值 传递**过程,**减小函数调用开销。**

```C++
#include<iostream>
using namespace std;
void swap1(int *a, int *b)
{
    int tmp = 1;
    int *p_tmp = &tmp;
    *p_tmp = *a;
    *a = *b;
    *b = *p_tmp;
}
void swap2(int& a, int& b)
{
    int tmp = 1;
    tmp = a;
    a = b;
    b = tmp;
}
void swap3(int a, int b)
{
    int tmp = 1;
    tmp = a;
    a = b;
    b = tmp;
}
int main()
{
    int a =3, b = 5;
    cout<<"a="<<a<<",b="<<b<<endl;
    // swap1(&a,&b);
    // swap2(a,b);
    swap3(a,b);
    cout<<"a="<<a<<",b="<<b<<endl;
}
```

- 引用型参数有可能意外修改实参的值,如果不希望修改实参本身,可以**将形参定义为常引用**,提高传参 效率的同时还可以接收常量型的实参

## 常引用作为函数参数

引用型函数参数定义为常引用

```c++
#include<iostream>
using namespace std;
class Student
{
public:
    Student(const string& name, int age) : m_name(name), m_age(age)
    {
    }
public:
    string m_name;
    int m_age;
};
void print(const Student& s) //常引用
{
    cout << s.m_name << ',' << s.m_age << endl;
    // s.m_age++;//不允许通过常引用修改变量的值
}
int main()
{
    /*const*/ Student student("蔡徐坤", 18);
    print(student);
    return 0;
}
```

# 1.4引用型函数返回值

- 可以将函数的返回值声明为引用,避免返回值所带来的内存开销

  **不要从函数中返回局部变量的引用,因为所引用的变量内存会在函数返回以后被释放,但是可以返回成员变量,静态变量以及全局变量的引用**

```c++
#include<iostream>
using namespace std;
class A
{
public:
    A(int data = 0) : m_data(data)
    {
    }

// 如果一个函数返回值类型被声明为普通引用(普通引用返回 左值，函数调用时可以被读取和修改)  a.getValue()
    int& getValue(void)
    {
        cout<<"函数返回普通引用"<<endl;
        return m_data;
    }
//函数返回普通int（非引用） 函数返回值a.getValue2() 是一个右值（临时对象）
    int getValue2() {
        cout<<"函数返回普通int"<<endl;
        return m_data;  // 返回值是类的成员变量m_data的拷贝
    }
    //不能返回局部变量的引用
    // int& fun(void)
    // {
    //     int a = 123;
    //     return a;
    // }
// 函数返回值为常引用（常引用返回 常量左值,函数调用时可以被读取但不能被修改） a.getvalue1()
    const int& getValue1(void)
    {
        cout<<"函数返回常引用"<<endl;
        return m_data;
    }

private:
    int m_data;
};
int main()
{
    A a(100);
    cout<<a.getValue()++<<endl; //左值可以++
    cout<<a.getValue1()<<endl;
    cout<<a.getValue2()<<endl;
    // cout<<a.getValue1()++<<endl;//error 常量左值不能++
    // cout<<a.getValue2()++<<endl;//error 右值不能++
    return 0;
}

```

#  1.5使用引用的时机（函数的参数和返回值）

- **返回普通引用**：返回的是**非常量左值**，可以被读取和修改
- **返回常引用**：返回的是**常量左值**，可以被读取但不能被修改
- **返回非引用类型**：返回的是**右值**（临时对象）

- **类别**：
  - 如果是基本类型，使用值传递或者指针
  -    如果是数组，只能以指针方式传递
  - 如果是结构体类型，指针、引用都可以
  - 如果是类/对象，使用引用

# 1.6指针和引用的区别

- 相同点

  如果从C的角度看引用,其本质就是指针

  - 引用和指针都允许对其他变量进行间接访问，通过引用或指针可以修改或获取其他变量的值。 
  - 两者都可以用于函数参数传递，允许在函数内修改调用者传递的变量。 
  - 但是在C++中建议使用引用,而不是指针

  ```c++
  int a = 100;
  int &ra = a;
  int * const pa = &a;
  *pa <=等价=> ra
  ```

- 区别

  - 指针可以不做初始化,其目标可以随便改变(指针常量除外),而引用必须初始化,而且其引用目标不能该改变

赋值操作并不改变引用的目标

# 1.7使用引用的注意事项

- **避免返回局部变量的引用**： 不要返回函数内部局部变量的引用，因为局部变量的生命周期在函数结 束时结束，返回对应的引用会导致悬空引用。
-  **确保引用指向有效的内存**： 确保引用在其生命周期内始终指向有效的内存，避免使用悬空引用。 
- 引用作为函数返回值时的生命周期： 当函数返回引用时，确保返回的引用指向的对象在函数调用后仍然有效。 
- 避免引用和指针混淆： 引用和指针是不同的概念，虽然它们都可以用于访问内存，但它们有着不同 的语法和语义。避免混淆引用和指针的用法。
-  避免滥用引用： 引用是一种强大的工具，但滥用它可能导致代码的可读性和维护性下降。在确实需 要引用的情况下使用它，而不是为了避免传值而过度使用引用。
