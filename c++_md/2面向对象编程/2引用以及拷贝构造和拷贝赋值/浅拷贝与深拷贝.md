# 3.浅拷贝与深拷贝

# 3.1浅拷贝

拷贝构造函数是一种特殊的构造函数，它在创建对象的时候，是利用同类中，之前实例化的对象来初始 化新的对象的。拷贝赋值是一个赋值函数，是使用一个已存在的对象对为另一个已存在的对象赋值。 

不管是拷贝构造实例化出来的新对象还是拷贝赋值用一个已存在的对象为另一个已存在的对象赋值，参与该过程的两个对象都是“ 一模一样 ”的。 

如果一个类中没有显性的声明拷贝构造函数，编译器会自动生成一个拷贝构造函数；如果一个类中没有 显性的声明拷贝赋值函数，编译器会自动生成一个拷贝赋值函数。

**编译器会自动为类提供的函数： 一旦某个函数用户自己定义了，那么编译器就不会再提供了。**

```c++
构造函数（无参构造函数）
析构函数
拷贝构造函数
拷贝赋值函数

```

自动生成的（默认的、缺省的）拷贝构造函数和拷贝赋值函数，函数体不为空，执行对象的逐成员赋值

指针变量，指针变量指向的区域

- **逐成员赋值**：对于类中的每一个数据成员，默认拷贝构造函数会执行相应的拷贝操作。对于基本数 据类型（如int、float等）类型的成员，逐成员赋值就是直接复制其值。对于类类型的成员，会调 用其拷贝构造函数进行拷贝。对于**指针类型的成员**，则是**直接复制指针值**，**而不是复制指针所指向的内容**。

**注意**

- 自动生成的拷贝函数的默认操作是“ 逐成员赋值 ”，这种拷贝方式叫做 “ **浅拷贝** ”，这种拷贝方式存 在一些问题。浅拷贝将会导致不同对象间的数据共享,同时会在析构函数中**引发"double free"异常**

**默认的拷贝构造和拷贝赋值会存在问题**

```c++
A a2(a1);
a2.m_p_age = a1.m_p_age;
两个对象都指向了同一块区域，调用析构函数后这块区域被释放了两次从而造成错误
```

```c++
#include<iostream>
using namespace std;
class A
{
private:
    double m_height;
    int* m_p_age;
    string m_name;
public:
    A(double height = 0, int age = 0,const string &name = ""):m_height(height),m_p_age(new int(age)),m_name(name)
    {
        cout<<"构造"<<endl;
    }
    ~A()
    {
        cout<<"析构"<<endl;
        delete m_p_age;
    }
    void print()
    {
       cout << "m_height = " << m_height << ", *m_p_age = " << *m_p_age 
       << ",m_name = " << m_name << endl;

    }
};
int main()
{
    A a1(180.1,18,"蔡徐坤");
    a1.print();

    // A a2(a1);
    A a2 = a1;
    a2.print();

    return 0;
}

构造
m_height = 180.1, *m_p_age = 18,m_name = 蔡徐坤
m_height = 180.1, *m_p_age = 18,m_name = 蔡徐坤
析构
析构
```

- 直接写 `m_p_age = that.m_p_age;`，那么两个对象的 `m_p_age` 就会指向同一块堆内存，这就是浅拷贝。
- 浅拷贝会导致两个对象共享同一个 `int`，当其中一个对象被析构时，会 `delete m_p_age`，另一个对象的指针就变成了“野指针”，再次析构时就会发生“double free”错误。
- 深拷贝则为每个对象都分配自己独立的堆内存，并复制源对象的值，这样每个对象都拥有自己的副本，析构时各自释放各自的内存，安全可靠。

# 3.2深拷贝

既然默认的拷贝构造和拷贝赋值函数有问题，就必须自己定义一个**支持复制指针所指向内容**的拷贝构造函数和拷贝赋值函数,即深拷贝。

深拷贝，它是指源对象与拷贝对象互相独立，其中任何一个对象的改动都不会对另外一个对象造成影响。

深拷贝会创建一个新的对象，并且将原对象中的元素，通过创建新的子对象拷贝到新对象中。因此,新对象和原对象**没有任何关联**。深拷贝会拷贝所有的属性，并拷贝属性指向的动态分配的内存。



```c++
#include<iostream>
using namespace std;
class A
{
private:
    double m_height;
    int* m_p_age;
    string m_name;

public:
   A(double height = 0, int age = 0, const string&name = "") 
   :m_height(height),m_p_age(new int(age)), m_name(name)
    {
        cout << "构造函数" << endl;
       	//m_p_age(new int(age)) 先为age在堆中申请一个int大小的内存地址空间，然后将age的地址给到m_p_age;
        // 即m_p_age 不再是一个野指针,而是合法的指向我们申请的堆地址int* m_p_age = &age;
        //堆区：是供程序员  手动管理  的动态内存区域，可以在程序运行时按需分配和释放。
    }
    ~A()
    {
        cout << "析构函数" << endl;
        delete m_p_age;
    }
    void print()
    {
        cout << "m_height = " << m_height << ", *m_p_age = " << *m_p_age 
        <<",m_name = " << m_name << endl;
    }
    A(const A& that)//深拷贝
    {
        cout<<"拷贝构造函数的深拷贝"<<endl; //A a2(a1);
        m_name = that.m_name;
        m_height = that.m_height;
        m_p_age = new int(*that.m_p_age);
        // that.m_p_age 是一个指向 int 的指针，表示它存储着一个 int 类型的值的内存地址。
        // 使用 * 运算符来解引用指针，访问该指针指向的整数值，也就是获取原对象 that 中的年龄值。
        //申请一块新内存，把原对象 age 的值复制进去，返回新内存的地址，然后赋给当前对象的 m_p_age。
        //new的使用:new int(初始值)
       		// - 它会在堆上动态分配一块足以存放 int 的内存，并用括号内的值（这里是 *that.m_p_age，即源对象的年龄值）来初始化这块内存。
    }
  
    // 返回值引用，避免多调用拷贝构造
    A& operator = (const A& that)//深拷贝
    {
        cout << "拷贝赋值函数的深拷贝" << endl;
        // A a3(a2)
        // a3 = a1;
        //防止自赋值
        if (this != &that)
        {
            m_height = that.m_height;
            m_name = that.m_name;

            //m_p_age = that.m_p_age;error 这是浅拷贝
            // 
            //a1已经存在 int * m_p_age;需要释放旧资源（如果不释放旧资源，则之前申请的空间没有释放，会内存泄露）
            delete m_p_age; //先去释放旧资源，将原本绑定的内存地址空间释放，否则就内存泄漏了
            				//例如a3在初始化时使用a2的拷贝构造函数，调用拷贝构造函数时为a3的m_p_age分配了一个内存空间，需要 先将其释放掉
            //分配新资源
            m_p_age = new int(*that.m_p_age); //绑定新资源
        }
        return *this;
        //对this指针进行解引用，得到当前对象本身 函数返回值类型是 当前类型的引用 
        //最终能返回当前对象的引用
    }
    
};

int main()
{
    A a1(180.1, 18 , "蔡徐坤");
    a1.print();

    //A a2(a1);
    A a2 = a1;
    a2.print();

    A a3(180.1, 18, "鸡哥");
    a3.print();
    a3 = a1;
    // a3 = a3;//自赋值
    return 0;
}
```

# 3.3 深拷贝和浅拷贝的一些注意事项

深拷贝（拷贝指针变量指向的内存区域）

浅拷贝（只拷贝指针变量的值，不拷贝指针变量指向的内存区域）

深拷贝：含有指针类型的成员变量

其他情况下直接使用默认拷贝构造和拷贝赋值就行

**浅拷贝只要不涉及到指针都是没有问题的**
