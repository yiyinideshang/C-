# 2.迭代器模式

### 迭代器的解释

在C++中，**迭代器**是一种对象，它提供了一种访问容器（如数组、向量、列表、字符串等）中元素的方式，而不需要直接使用索引。迭代器可以被视为指向容器中元素的指针，允许程序员以统一的方式遍历不同类型的容器。

### 迭代器的特点

1. **统一接口**：迭代器提供了一组统一的操作，如递增、解引用等，使得不同的容器可以用相同的方式遍历。
2. **抽象**：迭代器隐藏了容器的内部实现细节，允许程序员专注于算法的实现，而不需要关心容器的具体类型。
3. **灵活性**：迭代器可以是输入迭代器、输出迭代器、前向迭代器、双向迭代器或随机访问迭代器，针对不同的需求提供不同的功能。

### 迭代器的基本操作

以下是一些常见的迭代器操作：

- **解引用**：通过 `*iter` 来访问迭代器指向的元素。
- **递增**：使用 `++iter` 将迭代器移动到下一个元素。
- **递减**：使用 `--iter` 将迭代器移动到前一个元素（如果是双向迭代器）。
- **比较**：可以使用 `==` 和 `!=` 来比较两个迭代器是否相等。

### 示例代码

以下是一个简单的示例，展示了如何使用迭代器遍历 `std::vector` 和 `std::string`：

```c++
#include <iostream>
#include <vector>
#include <string>

int main() {
    // 使用 std::vector
    std::vector<int> vec = {1, 2, 3, 4, 5};
    std::cout << "Vector elements: ";
    for (std::vector<int>::iterator it = vec.begin(); it != vec.end(); ++it) {
        std::cout << *it << " "; // 解引用迭代器以获取元素
    }
    std::cout << std::endl;

    // 使用 std::string
    std::string str = "hello";
    std::cout << "String characters: ";
    for (std::string::iterator it = str.begin(); it != str.end(); ++it) {
        std::cout << *it << " "; // 解引用迭代器以获取字符
    }
    std::cout << std::endl;

    return 0;
}
```

### 输出示例

当运行上面的代码时，输出将是：

```c++
Vector elements: 1 2 3 4 5 
String characters: h e l l o 
```

### 总结

迭代器是C++ STL（标准模板库）中非常重要的组成部分。它们提供了一种灵活和统一的方式来访问和操作容器中的元素。通过迭代器，程序员可以编写更通用的算法，适用于不同类型的容器。

## 2.2迭代器模式



在软件开发的过程中，集合内部的结构经常发生改变。对于这些集合对象（**用户其实不关心集合内部是 如何实现的**，只要能正常使用就可以了）用户希望在可以不了解（不暴露）内部结构的同时，可以让外 界透明的访问其中的元素，不管集合内部的数据结构如何变化，反正对于集合外部的访问接口都保持不 变。 

这种**“ 让外界透明的访问 ”** 为同一种接口（begin/end）可以在多种集合对象上进行同一种操作。 使用面向对象的技术，讲这种遍历机制抽象为“ **迭代器对象 **”，可以描述、表示一个元素的位置为遍历 "**变化中的集合对象**"，提供一种不变的访问接口。

设计模式中对迭代器模式的定义如下：

- 容器（集合）应该提供一种方法。顺序的访问一个集合对象中的各个元素，而又不暴露该对象的内 部表示！！！

  ```c++
  容器就是一个集合，可以理解为存储很多元素的的一个集合
  如之前所学的数组、字符串等都属于容器
  本文只讨论基本类型数组和字符串
  ```

C++的一般做法： 

​		把遍历集合使用的 “ **指针** ” ，封装成一个迭代器类型，并且迭代器类型向外提供相对应的接口（++， +=，--，*，->...），并且集合对象也应该向外提供获取迭代器的接口 ( begin/end )

```c++
class Iterator
{
 	private:
        // 指向元素的类型的 指针 ，假定为T类型
        T* m_p;
    public:
        // 构造函数
        // 析构函数
        // ...
    next(); // 让当前迭代器表示当前条目的下一个条目...
        // +=
        // ==
        // !=
        // ...
};
```

把迭代器对象完成之后，容器应该向外部提供一组获取迭代器的接口 

- **Iterator begin();** 

- **Iterator next();**

- **Iterator end();**

# 迭代器和指针

迭代器遍历和指针遍历完全相同，为什么使用迭代器而不是使用指针？
迭代器很大程度上就是对指针的封装和抽象

然而，使用迭代器而不是用指针有以下几个优势：
1.抽象性和通用型   它们都可以使用统一的迭代器接口进行遍历，使得代码更加通用和可移植。

2.安全性和封装性：迭代器隐藏了具体容器的实现细节，只暴露必要的操作接口，防止迭代器越界访问容器的内容end()

3.可迭代性

也不要滥用，在容器中使用，

基本类型的数组建议仍然使用指针遍历，如：

int arr[]

char arr[]

```c++
// 使用字符串迭代器遍历字符串，并将字符串内容大小写互换
#include<iostream>
using namespace std;
int main()
{
    string str;
    cout<<"请输入一个字符串"<<endl;
    cin>>str;
    for(string::iterator iter = str.begin();iter != str.end();iter++)
    {
        if(*iter >='a' && *iter<='z')
        {
            *iter -= 32;//小写字母ASCII值-32即为大写字母
        }
        else if(*iter>='A'&&*iter<='Z')
        {
            *iter += 32;
        }
```

# 指针注意：

```c++
#include<iostream>
using namespace std;
int main()
{
    string str = "abc";//.data()返回字符串的首地址，指针p1接收了该指针
    const char* p1 = str.data();//p1 是一个指向 const char 的指针，指向 std::string 对象 str 内部的字符数据。
    cout<<p1<<endl;//p1 传递给 std::cout 时,std::cout 识别到这是一个const char* 类型的指针,因此它将指针视为一个 C 风格字符串，并输出字符串的内容（即 "abc"）。
    cout<<str.data()<<endl;//字符串str的内容
    cout<<(char *) p1<<endl;//字符串str的内容
    // 直接用 cout 输出 char* 时，cout 会把它当作 C 风格字符串，输出它指向的内容（字符串本身），而不是地址。
    // 如果你想输出指针的地址（即内存地址），需要把 char* 转换为 void*，这样 cout 就不会把它当作字符串处理，而是按地址输出。

    cout <<(void *)p1 <<endl;//std::string 对象的地址。
    cout<<&str<<endl;//std::string 内部存储的字符数据的地址。
// &str 指向 std::string 对象的地址。
// p1 指向 std::string 内部存储的字符数据的地址。
    cout << &p1 << endl; // 输出p1变量本身的地址
    cout<<endl;

    int a = 10;
    const int *p2 = &a;//p2 是一个指向 const int 的指针，指向整数 a 的地址。
    cout<<p2<<endl;//cout将 p2 视为一个普通指针，并输出其内容,即a的地址，而不是输出指针所指向的整数值
    cout<<&a<<endl;//a的地址
    cout<<*p2 <<endl;// 解引用指针，输出指针指向的整数值输出: 10
    cout<<&p2<<endl;//指针p的地址
    cout<<endl;

    char str1[10]={"abcd"};
    char *p3 =str1;//直接将 str 赋值给 p3。str 表示数组的首地址
    cout<<p3<<endl;// 输出 p3 指向的字符串，结果是 abcd
    cout<<str1<<endl;//字符串str1的内容    
    cout<<(void*)p3<<endl;//字符串str1的首地址
    cout<<&str1<<endl;//字符串str1的首地址
// 需要注意的是，&str1 的类型是 char (*)[10]（指向一个包含10个字符的数组的指针）
// 而 p3 的类型是 char *（指向字符的指针）。这意味着虽然它们的值相同，但它们的类型不同。
    return 0;
}
```

```c++
#include <stdio.h>
#include <stdlib.h>

// 这是一个指针函数
// 返回值类型是 char* (一个指向字符的指针)
char *getHelloString() {
    // 在堆上分配内存，并返回这块内存的地址
    char *str = (char *)malloc(100 * sizeof(char));
    sprintf(str, "Hello, World!");
    return str; // 返回指针（地址）
}

int main() {
    // 调用指针函数，它返回一个指针，我们用同类型的指针p来接收
    char *p = getHelloString();
    printf("%s\n", p); // 输出：Hello, World!

    // 使用完毕后，记得释放堆内存
    free(p);
    return 0;
}
```

`str.data()` 返回一个指向字符串内容的指针（`const char*`），这个指针指向 `std::string` 内部存储的字符数组的首地址。

 `const char* p1 = str.data()`;//`p1` 是一个指向 `const char` 的指针，指向 std::string 对象 str 内部的字符数据。p1接收了这个指针

- `p1` 是一个 `const char*`，指向字符串 str的数据区域（C++标准库的字符串对象）。
- `p` 是一个 `char*`，指向动态分配的字符串 `"Hello, World!"`。

它们的相同点：

- 都是指向字符串首字符的指针。
- 都可以用作 `printf("%s", p)` 或 `cout << p1` 这样的字符串输出。

不同点：

- `p1` 指向的是 C++ `std::string` 内部的数据，且是 `const char*`，不能修改内容。
- `p` 指向的是动态分配的 C 风格字符串，可以修改内容。



- 指向字符串的指针（如 `char *p1 = "abc"`; 或 `char *p = getHelloString();`）：

  - 直接用

    `printf("%s", p);`或 

    `cout << p1<<endl；`或

    `cout<<str.data()<<endl；`或

    `cout<<(char *) p1<<endl;`

    输出，显示的是**指针所指向的字符串内容**。

  - 用

    `cout <<(void *)p1 <<endl`
    `cout<<&str<<endl;`

    输出，显示的是**指针所指向的字符串的地址**。

  - 用

    `cout << &p1 << endl;` 

    输出，显示的是**指针`p1`本身的地址。**

- 指向普通变量的指针（如 `int *p2 = &a`;）：

  - 直接用

    `printf("%p", p2)`或

    `cout<<p2<<endl;`

    `cout<<&a<< endl`

    输出，显示的是**指针本身存储的地址**（即**指针所指向变量的地址**），而不是变量的内容。

  - 用

    `printf("%d", *p)`;或

    `cout<<*p2<<endl`；

    输出，显示的是**指针所指向变量的内容**

  - 用

    `cout<<&p2<<endl；`

    输出，显示的是**指针p本身的地址**。
