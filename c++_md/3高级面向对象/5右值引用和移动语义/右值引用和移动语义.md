# 引用和指针的联系与区别

引用和指针都是C++中用于间接访问变量的机制，它们有相似之处但也有重要区别。

## 联系

1. **都是间接访问机制**：两者都允许通过一个别名来访问或修改另一个变量的值
2. **都可以作为函数参数**：都能用于函数参数传递，实现按引用传递的效果
3. **都可以避免值拷贝**：对于大型对象，使用两者都可以避免值传递时的拷贝开销

## 区别

| 特性           | 引用                                     | 指针                                       |
| :------------- | :--------------------------------------- | :----------------------------------------- |
| **初始化要求** | **必须初始化**，且**不能改变引用的目标** | **可以不初始化**(野指针)，**可以改变指向** |
| **空值**       | 不能为空，必须有明确的目标               | 可以为nullptr或NULL                        |
| **操作方式**   | 像普通变量一样使用                       | 需要使用解引用操作符(*)                    |
| **内存占用**   | 通常不占用额外存储(由编译器实现)         | 占用独立的内存空间存储地址(占8个字节)      |
| **多级间接**   | 不支持多级引用                           | 支持多级指针(指针的指针)                   |
| **算术运算**   | 不支持算术运算                           | 支持指针算术(如++, --等)                   |
| **安全性**     | 更安全，不易出现悬空引用                 | 可能出现悬空指针或野指针                   |
| **语法**       | 使用`&`声明，如`int& ref = var;`         | 使用`*`声明，如`int* ptr = &var;`          |

## 使用建议

1. **优先使用引用**：当不需要改变指向或需要保证非空时
2. **必须使用指针**：当需要动态内存分配、需要改变指向或需要表示可选参数时
3. **函数参数传递**：对于不想拷贝的大型对象，优先使用const引用
4. **返回值**：避免返回局部变量的引用或指针

## 示例代码

cpp

```c++
int main() {
    int x = 10;
    
    // 引用示例
    int& ref = x;  // 必须初始化
    ref = 20;      // 直接使用，不需要解引用
    
    // 指针示例
    int* ptr = &x; // 可以不初始化
    *ptr = 30;     // 需要解引用
    ptr = nullptr; // 可以改变指向
    
    return 0;
}
```

引用提供了更安全、更直观的别名机制，而指针则提供了更灵活的内存操作能力。在现代C++中，除非需要指针特有的功能，否则通常推荐使用引用。

## 1.1左值引用(`Lvalue Reference`)

**c++中提出引用的概念，引用本质就是给变量起别名。**

**普通的引用就是左值引用。我们平常讲的引用就是左值引用。**

- 格式

````c++
类型 &引用 = 左值;//只能引用左值
const 类型 &引用名 = 左值/右值;//常引用既可以引用左值，也可以引用右值，尽管如此，它还是左值引用
````

- 普通引用只能引用左值，也叫**==左值引用==**

- **符号**：`&`（如 `int& ref = ...`）

- **绑定对象**：只能绑定到**左值**（有名字、有持久内存位置的对象）

- **目的**：提供对现有对象的别名访问

- **特点**：

  - 可以修改被引用的对象
  - 不能绑定到临时对象（右值）

  ```c++
  int a = 10;
  int& ref1 = a;    // 正确：绑定到左值
  // int& ref2 = 42; // 错误：不能绑定到右值
  ```

  ==<!--当类类型的变量作为函数参数时-->==

## 1.2右值引用(Rvalue Reference)

所谓右值引用，就是必须绑定到右值的引用，

需要注意的,和声明左值引用一样,右值引用也必须立即进行初始化操作,且只能使用右值进行初始化

- **符号**：`&&`（如 `int&& ref = ...`）

- **绑定对象**：只能绑定到**右值**（临时对象、字面量、将亡对象）
- **目的**：
  - 支持移动语义（高效转移资源）
  - 实现完美转发
- **特点**：
  - **可以修改被引用的临时对象**
  - 延长临时对象的生命周期

```c++
int&& ref1 = 42;             // 正确：绑定到字面量
int&& ref2 = std::move(a);   // 正确：绑定到将亡值
// int&& ref3 = a;           // 错误：不能直接绑定到左值
ref2 = 43;
cout<< ref2<< endl;
```

C++语法上是支持定义**常量右值引用**的,例如： `const int&& a = 10`; //编译器不会报错

 但这种定义出来的右值引用并无实际用处**.一方面**,右值引用主要用于移动语义和完美转发，其中前者需要有修改右值的权限。**其次**，常量右值引用的作用就是引用一个不可修改的右值,**这项工作完全可以交给常量左值引用完成。**

## 1.3常量左值引用

`const 类型 &引用名 = 左值/右值;//常引用既可以引用左值，也可以引用右值，尽管如此，它还是左值引用`

- **符号**：`const &`（如 `const int& ref = ...`）

- **绑定对象**：
  - **左值**（普通变量）
  - **右值**（临时对象、字面量）
- **为什么仍是左值引用**：
  - 语法上使用`&`符号
  - 类型系统归类为左值引用
  - 但具有特殊的绑定规则
- **特点**：
  - 不能修改被引用的对象（const特性）
  - **特殊能力**：可以绑定到右值
  - 延长临时对象的生命周期（与右值引用相同）

```c++
const int& cref1 = a;     // 绑定到左值
const int& cref2 = 42;    // 绑定到右值（特殊能力！）
const int& cref3 = a + b; // 绑定到临时对象
```



## 关键区别总结

| 特性                 | 左值引用 (`T&`) | 右值引用 (`T&&`)  | 常量左值引用 (`const T&`) |
| :------------------- | :-------------- | :---------------- | :------------------------ |
| 可绑定左值           | ✓               | ✗                 | ✓                         |
| 可绑定右值           | ✗               | ✓                 | ✓                         |
| 可修改对象           | ✓               | ✓                 | ✗                         |
| 延长临时对象生命周期 | ✗               | ✓                 | ✓                         |
| 主要用途             | 别名/修改对象   | 移动语义/完美转发 | 只读访问通用接口          |

## 何时使用哪种引用？

1. 需要修改对象 → **左值引用**
2. 需要移动资源或完美转发 → **右值引用**
3. 只读访问且需兼容左右值 → **常量左值引用**
4. 现代C++最佳实践：优先使用右值引用+移动语义处理临时对象

# 2.移动语义

## 2.0为什么要使用移动语义的实例

```c++
#include <iostream>
using namespace std;
class A
{
public:
	A(int data = 0):m_data(data)
	{
		cout<<"构造函数"<<endl;
	}
	A(const A &that)
	{
		cout<<"拷贝构造"<<endl;
	}
	~A()
	{
		cout<<"析构函数"<<endl;
	}
	void print() const
	{
		cout<<"m_data = "<<endl;
	}
private:
	int m_data;
	
};
int main()
{	
    A a1(10);
    A a2(a1);
    a2.print();
    
	return 0;
}
```

定义类对象a1,类对象a2；a2用a1来初始化，调用拷贝构造函数，a1之后再也没有用过，只是作为a2的初始化，这样只用了a2但是需要占用并释放a1和a2两个资源，还多了一个复制过程。在很多情况下会发生对象拷贝的现象，对象拷贝之后就被销毁了，

在这种情况下，**对象移动**而非对象拷贝会大幅度提升性能。

对象的移动是指将一个对象的资源（如动态分配的内存、文件句柄等）从一个对 象转移到另一个对象，而不是进行复制操作。

移动操作比复制操作通常更高效，因为它避免了资源的复制和释放。

## 2.1移动语义的格式 

```c++
std::move(左值/右值)
//返回值是一个右值引用
```

```c++
#include<iostream>
using namespace std;
class A
{
public:
    A(int data = 0) : m_data(data)
    {
        cout << "构造函数" << endl;
    }
    A(const A& that)
    {
        cout << "拷贝构造函数" << endl;
        m_data = that.m_data;
    }
    ~A()
    {
        cout << "析构函数" << endl;
    }
    void print() const
    {
        cout << "m_data = " << m_data << endl;
    }
private:
    int m_data;
};
//两个函数fun1和fun2，分别接受左值引用和右值引用：
void fun1(const A&a)
{
    cout << "左值引用" << endl;
    a.print();
}
void fun2(const A&& a)
{
    cout << "右值引用" << endl;
    a.print();
}
int main()
{
	A a1(10);
    A && a2 = std::move(a1);//将 a1 静态类型转换为右值引用（A&& 类型）
    //本质是给已有对象 a1 创建一个右值引用类型的别名 a2，
    //不涉及资源移动或对象复制，仅通过类型系统提供移动语义的接入点。
    // a1 ────> [A 对象]
    //          ^
    // a2 ──────┘(指向同一个对象)
    fun1(a1);
    fun2(std::move(a1));
    
    fun1(a2);
    // fun2(a2);          // 错误，因为a2是左值（具名右值引用是左值）
    fun2(std::move(a2)); // 正确，将a2转换为右值
    return 0;
}
```

##  A && a2 = std::move(a1);

### 1.**本质：创建引用别名**

- `std::move(a1)` 只是将 `a1` **静态类型转换**为右值引用（`A&&` 类型）
- `a2` 是右值引用类型的变量，本质是 `a1` 对象的**新名字**（别名）,a2本身也是一个左值，有地址
- **不创建新对象**，不会调用构造函数/拷贝构造函数

### 2. **类型转换行为**

- `std::move` 本质是 `static_cast<A&&>(a1)`
- 仅改变编译器对 `a1` 的**值类别判断**（左值 → 右值）
- 不实际移动任何数据（类 `A` 无移动构造时尤其明显）

### 3.**关键特性**

| 特性                | 说明                                                 |
| :------------------ | :--------------------------------------------------- |
| **不触发拷贝/移动** | 仅声明引用，无新对象创建                             |
| **原对象仍有效**    | `a1` 仍可正常使用（除非后续被移动语义转移资源）      |
| **a2 是左值**       | 具名的右值引用变量 `a2` 本身是**左值**（可取其地址） |
| **生命周期**        | `a2` 作为引用，生命周期与 `a1` 绑定，不独立管理资源  |

### 使用示例对比

```c++
// 场景1：引用别名
A&& a2 = std::move(a1); 
a1.print(); // 合法：输出 10
a2.print(); // 合法：输出 10（同一对象）

// 场景2：实际移动构造（对比！）
A a3 = std::move(a1); // 调用移动构造函数（如果存在）
```

**c++移动构造函数（移动语义的具体实现）**

所谓移动语义，指的就是以移动而非拷贝的方式初始化类对象。简单理解，移动语义指的就是将其他对象(通常指的是临时对象)拥有的内存资源“移为己用”。

以前面程序中的A类为例,该类的成员都包含一个整形的指针成员,其默认指向的是容纳一个整形变量的堆 空间。当使用 getA() 函数返回的临时对象初始化a时,我们只需要将临时对象的 m_data 指针直接浅拷贝 给 ``a.m_data ，然后修改该临时对象中 m_data 指针的指向(通常另其指向 NULL),这样就完成了 a.``m_data 的初始化。

<!--思考：为什么时浅拷贝而不是深拷贝？--> 

<!--因为只有一个对象占有资源，所以直接把资源给新的对象占有即可--> 

事实上,对于程序执行过程中产生的临时对象,往往只用于传递数据(没有其它的用处),并且会很快会被销 毁。因此在使用临时对象初始化新对象时,我们可以将其包含的指针成员指向的内存资源直接移给新对象 所有,无需再新拷贝一份,这大大提高了初始化的执行效率。

### 移动构造语法

由于移动操作“窃取”资源,通常不分配资源,因此通常不会抛出异常,对于不抛出异常的函数,在新标准中应 该使用 noexcept 加以声明

```c++
类名(类&& 变量名) noexcept
{
}
```

- **参数为“&&”类型，因为是移动操作** 
- **参数不必设置为const，因为需要改变** 
- **在构造函数后添加“noexcept”关键字，确保移动构造函数不会抛出异常**

```c++
#include<iostream>
using namespace std;
class A
{
public:
    A(int data = 0) : m_data(new int(data))
    {
        cout << "构造函数" << endl;
     }
    A(const A& that)
    {
        cout << "拷贝构造函数" << endl;
        m_data = new int(*that.m_data);
    }
    A(A&& that) noexcept
    {
        cout << "移动构造函数" << endl;
        m_data = that.m_data;
        that.m_data = NULL;
    }
    ~A()
    {
        cout << "析构函数" << endl;
        delete m_data;
    }
private:
	int *m_data;
};
A getA()
{
	return A(10);
}
int main()
{
    A a = getA();
    return 0;
}
```

可以看到,在之前A类的基础上,我们又手动为其添加了一个移动构造函数.和其它构造函数不同，此构造函 数使用右值引用形式的参数,又称为移动构造函数.并且在此构造函数中, `m_data` 指针变量采用的是浅拷贝 的复制方式,同时在函数内部重置了 `that.m_data` ，有效避免了“同一块对空间被释放多次”情况的发生。

在实际开发中,通常在类中自定义移动构造函数的同时,会再为其自定义一个适当的拷贝构造函数,由此

当用户利用右值初始化类对象时,会调用**移动构造函数;**

使用左值(非右值)初始化类对象时,会调用**拷贝构造函数**。

默认情况下,**左值初始化同类对象只能通过拷贝构造函数完成**,如果想**调用移动构造函数**,则必须使用右值进行初始化。即

```c++
std::move(左值/*右值*/);
//它可以将左值强制转换成对应的右值形式,由此便可以使用移动构造函数
```

move本意为"移动",但该函数并不能移动任何数据,它的功能很简单,就是将某个左值强制转化为右值 基于move()函数特殊的功能,其常用于实现移动语义。

### ==移动构造实例==

```c++
#include<iostream>
using namespace std;
class A
{
public:
    A(int data = 0) : m_data(new int(data))
    {
        cout << "构造函数" << endl;
    }
    A(const A& that)
    {
        cout << "拷贝构造" << endl;
        m_data = new int(*that.m_data);
    }
    A(A && that) noexcept
    {
        cout<<"移动构造函数"<<endl;
        m_data = that.m_data;// that.m_data ->申请空间 // m_data ->指向申请空间
        that.m_data = NULL;//将that.m_data不再指向申请的空间,防止析构时造成double free
    }
    ~A()
    {
        cout << "析构函数" << endl; 
	//在C++中，对空指针执行delete操作是安全的。
	//当你尝试对一个空指针执行delete操作时，编译器或运行时环境会检查指针是否为空，
	//如果为空，则不会执行任何操作。因此，对空指针执行delete操作不会产生任何副作用或错误。
    }
    void print() const
    {
        cout << "*m_data = " << *m_data << endl;
    }
private:
    int *m_data; 
};
int main()
{
    A a1(10);
    A a2(a1);//注意,调用拷贝构造函数,并不影响A对象
    a1.print();
    a2.print();
    A a3 = std::move(a1);//调用移动构造函数
    //,但如果调用移动构造函数,由于函数内部会重置m_data 指针的指向为NULL
    //a1.print();//error a.m_data已经是空指针，不再拥有内部资源
    a3.print();
    return 0;
}
```

通过观察程序的输出结果,以及对比a2和a3初始化操作不难得知,

A对象a1作为左值，直接用于**初始化a2对象,其底层调用的是拷贝构造函数**.

而通过调用 **move() 函数**可以得到A对象a1的右值形式,用其初始化a3对象, 编译器会优先调用**移动构造函数**。 

移动语义只是让对象失去了原有的资源，并不影响析构。

## 2.3移动赋值函数

### 移动赋值语法

- 格式如下： 
- 参数为“&&”类型，因为是移动操作 
- 参数不必设置为const，因为需要改变
-  在函数后添加“noexcept”关键字，确保移动赋值运算符函数不会抛出异常 
- 与拷贝赋值运算符一样，函数返回自身引用 
- 在函数执行前，应该检测自我赋值的情况

```c++
类名& operator=(类名&& 对象名) noexcept
{	
    
}
```

- noexcept确保函数不会抛出异常 
- 函数执行之前先判断一下是否为自我赋值 
- 先释放自身资源，再拷贝参数that的资源，最后再将that中的指针置为空

### ==移动赋值实例==

```c++
#include<iostream>
using namespace std;
class A
{
public:
    A(int data = 0) : m_data(new int(data))
    {
    	cout << "构造函数" << endl;
    }
    A(const A& that)
    {
        cout << "拷贝构造函数" << endl;
        m_data = new int(*that.m_data);
    }
    A(A&& that)
    {
        cout << "移动构造函数" << endl;
        m_data = that.m_data;
        that.m_data = NULL;
    }
	A& operator=(const A& that)
	{
    	cout << "拷贝赋值函数" << endl;
        if (this != &that)
        {
            //释放旧资源
            delete m_data;
            //分配新资源
            m_data = new int(*that.m_data);
        }
        return *this;
     }
    A& operator=(A&& that)
    {
        cout << "移动赋值函数" << endl;
        if (this != &that)
        {
            //释放旧资源
            delete m_data;
            m_data = that.m_data;
            that.m_data = NULL;
        }
        return *this;
    }
    ~A()
    {
        cout << "析构函数" << endl;
        delete m_data;
    }
    void print()
    {
    	cout << "*m_data = " << *m_data << endl;
    }
private:
	int* m_data;
};
int main()
{
    A a1(10);//构造
    A a2(20);//构造
    //a2 = a1;//拷贝赋值
    a2 = std::move(a1);//移动赋值
    return 0;
}
```

- ==什么时候调用拷贝语义，什么时候调用移动语义？==

- 当移动、拷贝构定义了：
  - 如果涉及**临时对象或者move函数**，调用移动
  - 其他，调用拷贝

- ==默认情况下(任何构造函数都不写的情况下),编译器会为一个类生成以下函数:== 

  - 一个默认的构造函数（无参构造） X() 

  如果涉及指针成员变量，需要自定义一个深拷贝

  - 一个拷贝构造函数（浅拷贝） X(const X&) 
  - 一个拷贝赋值函数（浅拷贝） X &operator=(const X&) 
  - 一个**移动构造函数** X(X&&) 
  - 一个**移动赋值函数** X &operator=(X&&) 
  - 一个析构函数 ~X()
